# 复利

## 定义
复利是知奥ZHAO知识库中反复出现的核心投资与人生概念，指收益再投入后对本金和前期利息共同计息、随时间呈指数增长的效应。它既是投资领域的数学原理，也被迁移为一种跨越财富、健康、认知与人生的长期积累哲学。

## 在知奥体系中的位置
复利是连接投资认知系列文章的主线概念。在「醍醐灌顶的图片」系列中，它与[[现金流象限]]、[[资产配置]]、[[定投]]等共同构成理解财富增长的基础框架；材料反复强调「复利的第一原则是不要打断它」，并将这一原则从投资延伸到肌肉训练、认知积累等领域。

复利与[[巴菲特]]高度绑定，多篇文章引用巴菲特99%财富来自50岁之后这一事实，说明复利后期爆发的指数效应；同时它也关联[[长期主义]]、[[时间的朋友]]等知奥体系中的高频理念。在行动层面，复利通过[[定投]]和[[场外赚钱]]实现——场外努力赚钱提供本金，场内复利增值实现慢慢变富，两者构成知奥体系关于个人财富积累的完整路径。

复利还被用来解释健康与认知投资：材料提出肌肉是「产生复利的生产性资本」，学习投资和[[复利]]可以免疫暴富幻觉。这说明在知奥体系中，复利已经从纯粹的金融概念上升为一种通用的长期决策思维。
