# 豆包

## 定义
豆包是字节跳动推出的AI助手产品，提供文本生成、图生视频等功能。在知奥体系的文章中，它主要作为多AI协作流程中的一个功能性工具出现，承担自然语言翻译、静态图片转视频等具体环节。

## 在知奥体系中的位置
豆包在多篇文章中作为AI工具链的一环被提及，与 [[Claude Code]]、[[腾讯元宝]]、[[Napkin]]、[[DeepSeek]] 等共同构成完整的AI协作工作流。在PPT制作场景中，豆包负责将静态参观照片转为5秒展示视频，补全了从文本生成到格式转换的中间环节。

在人机协作的模式下，豆包的角色更偏向于“翻译与解说”。当 [[Claude Code]] 负责写代码时，豆包通过屏幕共享将模糊的“人话需求”翻译成可执行的程序参数，充当人与机器之间的沟通缓冲层。这种分工体现了知奥体系中“人是调度中心”的核心理念。

## 关键数据
- 图生视频功能免费，可将静态照片转为5秒展示视频
- 生成的视频带有水印，可通过图片裁剪去除
- 视频转GIF建议不超过5秒，否则文件超过20M无法插入PPT
