# 进化论

## 定义
进化论是关于生物种群在世代间性状变化与适应机制的科学理论，强调变异、选择与适应在生命演化中的作用。在知奥体系中，它被引申为一种理解学习、健身与生命态度的底层框架。

## 在知奥体系中的位置
进化论在知奥体系中常常与 [[反脆弱]] 概念并置，用来解释“越折腾越强大”的生理与认知机制。健身文章指出，主动拥抱不确定性、持续挑战自我应对新局面，才是符合进化论的做法，并将其与 [[塔勒布]] 的 [[反脆弱]]、[[过度补偿]] 关联。

在生命意义讨论中，进化论与 [[负熵]]、[[熵增定律]] 形成对照。[[薛定谔]] 提出“生命以负熵为生”，而知奥文章将学习、健身、创造视为在混乱中主动建立秩序、给熵增制造麻烦的行为。进化论由此不仅是生物学理论，更被上升为一种“天道”——面对不确定性时主动适应与成长的行动哲学。
