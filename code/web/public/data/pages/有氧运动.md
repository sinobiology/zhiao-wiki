# 有氧运动

## 定义
有氧运动（跑步、游泳、骑行）是以有氧代谢为主的持续性运动，主要锻炼身体核心底座——心肺功能，管理全身血管和循环系统。它是生命健康的基石，常见于健康长寿与体能管理领域。

## 在知奥体系中的位置
有氧运动在知奥体系中是健康管理的基础组件，与 [[心肺功能]] 直接绑定：心肺功能是有氧运动训练的首要目标，而心肺功能又被视为身体的核心底座。它与 [[无氧运动]] 构成运动策略的两极——前者打底，后者续命。

在不同生命阶段，有氧运动的优先级会变化：年轻和中年时，有氧运动重要性远大于无氧，优先打好心肺功能基础；老年时则需让位于 [[肌肉力量]] 与 [[力量训练]]，因为过长有氧反而会消耗宝贵肌肉。有氧运动也常与 [[蛋白质]] 摄入配合，形成完整的身体维护方案。

在具体执行层面，有氧运动被视为需要反馈机制支撑的长期习惯。它与 [[Keep]] 等工具结合，通过社区打卡和日程记录来对抗健康追求中的孤独感与惰性。最终落脚点指向 [[健康长寿]] 这一更高目标。

## 关键数据
- 每周推荐有氧运动量：至少5次，每次不低于30分钟
- 案例执行计划：工作日环湖跑3.6-4.0公里，周末公园跑5公里以上
- 有氧运动同时被纳入每周150分钟中等强度有氧的运动方案

- 40岁后肌肉量每十年流失约8%，老年阶段过长有氧会加速消耗肌肉
