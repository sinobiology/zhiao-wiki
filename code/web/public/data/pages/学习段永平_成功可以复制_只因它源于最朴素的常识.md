# 学习段永平：成功可以复制，只因它源于最朴素的常识

## 核心逻辑
- 成功者的非凡之处不在于精准预知未来，而在于每个岔路口凭简单常识和价值观做出"对"的选择。
- 投资的壁垒从来不是资金量，而是认知水平；市场规则普世而冰冷，不因身份而改变。
- 建立并坚守内在的"是非观"（不为清单），比追逐所有机会重要得多——成功是持续做对的事情之后水到渠成的副产品。

## 技术/管理要点
- **为成功"祛魅"**：拒绝事后诸葛亮式的叙事，段永平坦言早期"胸无大志"，重大抉择多源于"不舒服"和"被市场倒逼"，而非宏大战略蓝图
- **投资无身份之分**：不存在为"普通人"定制的投资捷径，真正的路径是从"不懂"迈向"懂"
- **不懂就买指数**：[[标普500]]的回报率是投资的机会成本基准，任何主动投资决策都应与之比较，长期无法跑赢则努力无效
- **极致的实事求是**：拒绝一切模糊，对每个概念刨根问底——"老巴讲的指数指的其实就是SNP（标普500），并不是所有的指数"
- **Stop Doing List（不为清单）**：公司少犯错的关键在于清楚什么事情不能做，决策标准基于内在"是非"而非纯粹结果导向
