# 玉米

## 定义
玉米是氨基酸发酵工业中最核心的碳源原料，在[[氨基酸]]生产成本结构中占比约60%，是决定企业成本竞争力与行业周期波动的关键变量。它既是生物制造的基础底盘，也是饲料原料体系中与[[豆粕]]、[[鱼粉]]并列的三条成本传导链之一。

## 在知奥体系中的位置
玉米贯穿知奥库中多条核心逻辑链。在《糖源之战》的材料里，它是[[淀粉]]制糖路线的起点——[[玉米湿磨]]与液化糖化工艺共同回答“怎样把一粒玉米稳定、经济地送进发酵罐”。在氨基酸成本议题中，[[玉米]]的涨价通过“玉米—淀粉—葡萄糖”链条直接传导至[[赖氨酸]]、[[苏氨酸]]、[[缬氨酸]]等发酵产品，材料里给出的敏感度数据为：玉米每涨100元/吨，赖氨酸硫酸盐成本影响约150元/吨，盐酸盐约200元/吨，苏氨酸约250元/吨。

玉米也是行业周期波动的“加速器”与“筛选器”。在《周期崩塌还是涅槃重生》与《导弹之下，饲槽之上》的材料中，玉米高价会推升成本压缩利润、有利于头部企业挤压中小厂；而它作为主要碳源的刚性地位，使企业长期受制于农产品价格周期。[[碳能解偶联]]技术正是针对这一刚性而提出的范式级突破——其目标是让玉米100%用于产品合成，理论上降低玉米单耗20%~30%，用“工业电子”替代“农业卡路里”。

在海南自贸港的语境下，玉米被列为[[氨基酸]]生物制造的可选碳源之一，与[[糖蜜]]、[[棕榈油]]并列。[[海南自贸港]]方案试图通过零关税进口替代碳源，打破玉米成本占比超60%的进项压力，为发酵企业提供8%~12%的综合竞争力提升。

## 关键数据
- 玉米在氨基酸发酵成本结构中约占60%，能源约占15%，合计约75%
- 传统异养发酵中，微生物必须“燃烧”30%~50%的葡萄糖来供能，导致玉米成本占比的刚性天花板
- 玉米每涨100元/吨，赖氨酸硫酸盐成本影响约150元/吨，盐酸盐约200元/吨，苏氨酸约250元/吨
- 2025年中国玉米产量约3.012亿吨，2026/27年度预计总产可达3.06亿吨；2025年全年进口约265万吨，占国内产量不足1%
- 玉米中亮氨酸是缬氨酸的2.5倍（12-13 vs 4-5 g/kg），过量亮氨酸会通过BCAA拮抗效应过度消耗缬氨酸
- 玉米价格受土地和气候限制长期看涨有底价，而绿电边际成本趋零
