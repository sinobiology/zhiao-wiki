# 资产配置

## 定义
资产配置是指根据投资目标、风险承受能力和时间周期，将资金在不同资产类别之间进行系统性分配的方法。它属于投资与财富管理领域，强调通过组合分散风险、追求长期回报。

## 在知奥体系中的位置
资产配置在知奥体系中是一个贯穿长期投资思维的核心概念。材料1通过美国200年资产收益全景图说明，长期持有增长型资产（如[[股票]]、[[比特币]]）是财富增长的关键，而资产配置正是实现这一目标的操作框架——把钱放在能长期跑赢通胀的资产里，而不是停留在现金或低收益资产中。

材料2从反面揭示了资产配置缺失的后果。作者第一次炒股时从未系统想过手里的钱应该如何安排、股票占多少比例、其他用途留多少，买了11只股票并不等于懂了配置。这说明资产配置不仅是选择标的，更是对整体资金结构的规划，与[[周期]]认知、[[复盘]]等能力共同构成投资基本功。

材料3将资产配置与[[比特币]]的极端波动性联系起来。BTC 十年回报率要么第一要么倒数第一，说明其更适合作为组合中的卫星配置而非核心仓位。这呼应了知奥体系中一贯的风险观：波动不是敌人，但需要通过资产配置来管理风险敞口，让[[复利]]过程不被极端回撤打断。

## 关键数据
- 股票长期年均实际收益稳定在6.5%-7%（美国200年数据，剔除通胀后），远超债券、黄金和现金。
- 现金在200年周期中从1美元贬值至5美分。
- 近十年（2015-2024）全球资产收益中，比特币几乎年年位列前茅，美股、黄金次之。
- 材料2中：39条交易记录、11只股票、高频交易的孚日股份亏损1483元占总亏损六成，只操作两次的中孚实业盈利210元为最高。
- 材料3中：BTC 过去十年年度回报率要么第一要么倒数第一；2025年排名倒数第二，为十年来首次出现中间态。
