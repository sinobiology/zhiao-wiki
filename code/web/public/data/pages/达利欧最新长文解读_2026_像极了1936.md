# 达利欧最新长文解读：2026，像极了1936

## 核心逻辑
- 国际秩序的底层逻辑不是"谁有理"而是"谁有力"，国际关系遵循丛林法则而非国际法。
- 历史存在约150年一轮的大周期（繁荣→失序→大战→新秩序），当前处于"第六阶段——巨大失序期"，危险程度约80/100。
- 真正的风险不是战争本身，而是"滑向战争的那段路"——贸易战、科技战、资本战逐步升级，最终越过军事临界点。

## 行业洞察
- 大国博弈的五种战争形态（贸易/经济战→科技战→地缘政治战→资本战→军事战）通常按顺序递进，前四种的边界模糊时军事冲突风险骤增。
- 伊朗里亚尔一夜暴跌34倍是"资本战"的现实教科书：货币崩溃对普通人的杀伤力远超导弹，物价涨72%即财富清零。
- 霍尔木兹海峡若封锁，全球20%石油受阻，通胀将向全球蔓延——地缘冲突的经济冲击波没有旁观者。

## 技术/管理要点
- **大周期运行机制：** 和平期积累财富→财富差距拉大→内部冲突→催生民粹与强人→对外扩张→大战→重新洗牌→新秩序
- **四个让国家"愚蠢地"滑进战争的原因：**
  - [[囚徒困境]]：双方都怕对方利用自己的退让先下手
  - 针锋相对的升级："胆小鬼游戏"，谁都不愿先让步
  - 衰落方不愿退让：为不显示软弱做出非理性决策
  - 误解和情绪化：媒体渲染与民间情绪导致领导人错判形势
- **普通人的风险管理框架：**
  - 死守单一资产形式或单一地理位置本身就是风险
  - "可携带的资产"（技能、知识、人脉、信誉）才是真正的避弹衣
  - 配置多元化不是炫富，是不确定世界里的底气
