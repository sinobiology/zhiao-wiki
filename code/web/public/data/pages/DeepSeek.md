# DeepSeek

## 定义
DeepSeek 是一款国产开源大语言模型，属于 AI 大模型领域。它在文本处理方面效果突出，以极高的性价比和免费/低价 API 被广泛使用，是国内文字处理类大模型中效果最好的模型之一。

## 在知奥体系中的位置
DeepSeek 在知奥体系的 AI 工具生态中处于基础模型层，常被用作免费或低成本 API 挂载模型，与 [[ChatGPT]]、[[Kimi]]、[[腾讯元宝]]、[[Gemini]] 等模型并列。

在 PPT 制作、战略调研等场景中，[[腾讯元宝]] 负责资料查询与内容提炼，[[DeepSeek]] 则作为文字处理能力最强的国产模型参与信息生成，但深度研究能力与国外模型差距较大，常被用于验证工具或挂载热点实验。

2025 年初 DeepSeek 爆火，标志着大语言模型真正融入日常的起点，与后续 [[Gemini]] 3.0、ChatGPT 5.2 Thinking 的发布共同构成认知基础设施的演进脉络。

## 关键数据
- API 费用：150 元（年度订阅复盘中的记录），性价比最高
- 深度研究能力：与国外模型差距较大，在深度研究领域的综合能力弱于 ChatGPT 5 和秘塔 AI 搜索
- 相关训练营：作者参加的「如何用好 DeepSeek」AI 课程训练营费用为 3200 元
- 角色定位：验证工具和 OpenClaw/Hermes 等热点的默认挂载模型
- 2025 年初：DeepSeek 爆火，被描述为大语言模型「入魂」一年的起点
