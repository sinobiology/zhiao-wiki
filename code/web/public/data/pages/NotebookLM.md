# NotebookLM

## 定义
NotebookLM 是 Google 推出的一款 AI 笔记与知识库工具，属于 AI 辅助内容生产与知识管理领域。它允许用户将指定资料导入封闭知识库，并基于这些资料生成思维导图、信息图、音频、视频和文章等多维产出。

## 在知奥体系中的位置
NotebookLM 是 [[知奥ZHAO]] 内容创作工作流中的核心工具之一，与 [[Gemini]] 搭配构成「精准输入→多维产出→润色输出」的三步知识消化流程。在多篇文章中被用于深度消化素材、提升内容生产效率，例如处理 [[罗胖]] 点名文章和氨基酸发酵相关行业资料。

在作者的 [[人机协作]] 写作体系中，NotebookLM 承担封闭知识库的建立与多维产出的角色，与 [[ChatGPT]]、[[Gemini]] 等大模型工具形成互补。它帮助作者从「执行者」转型为「决策者」，将低价值重复劳动交给 AI，保留判断与取舍。

## 关键数据
- 访问地址：notebooklm.google.com
- 可自动生成思维导图，并一键导出 PNG
- 可生成信息图表、播客式男女对谈音频、视频讲解、报告/博文
- 无法直接读取微信公众号分享链接，需手动复制内容
- 网页版 Gemini（gemini.google.com）已支持直接导入 NotebookLM 笔记本内容
- iPhone 手机版需美区 ID，功能稍弱，不支持导入 NotebookLM
