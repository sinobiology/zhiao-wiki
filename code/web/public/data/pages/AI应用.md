# AI应用

## 定义
AI应用指将人工智能技术落地到具体场景中的工具、系统或工作流，覆盖投资分析、编程协作、内容创作等领域。在知奥体系中，它既是技术概念，也是贯穿多篇文章的核心实践对象。

## 在知奥体系中的位置
AI应用在知奥知识库中处于技术实践的交汇点。在投资领域，[[TradingAgents]] 这类多智能体系统被用于模拟投行研究流程，通过多空辩论降低单一模型偏差，与 [[投资]] 形成深度绑定。在编程与Agent进化方面，[[Hermes]] 代表从一次性工具到自进化助手的转变，关联 [[Claude Code]] 的协作模式比较。

在创作场景中，AI应用从单图生成推进到连贯故事创作，如GPT Image2.0与Seedance 2.0配合完成分镜与短片，体现了工具进步对非专业用户的赋能。整体上，AI应用是知奥体系中连接技术能力、行业洞察与管理方法的核心枢纽。
