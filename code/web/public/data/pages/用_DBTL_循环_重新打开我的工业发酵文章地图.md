# 用 DBTL 循环，重新打开我的工业发酵文章地图

## 核心逻辑
- DBTL（Design–Build–Test–Learn）看起来像实验室方法论，实际上也是理解整个工业发酵知识体系的一把钥匙。
- **工业发酵里的 DBTL 不只发生在细胞里**——它发生在基因组里、发酵罐里、中控室里、财务报表里，也发生在价格战、专利战和全球供应链里。
- 单篇文章各是一个局部切片，放进 DBTL 循环后就不再散乱，而是连成一张图。

## 技术/管理要点
- **D（Design）设计**：提出假设、设计路线、确定靶点和系统架构。工业发酵里的 Design 不能只停在基因图谱上，至少要同时回答三类问题——细胞内部的代谢逻辑是什么？细胞外部的工程环境是什么？这条路线最后能不能落到成本曲线上？
  - 表面上是设计一株菌，**更准确地说是设计一种「细胞愿意持续工作的工业生态」**：早期「进通节堵出」设计代谢物流；动态调控设计时间节奏；抗压育种设计细胞面对大罐环境的承受能力；合成成瘾、固定化和进化鲁棒底盘设计细胞群体的博弈规则。
  - **「工业发酵里的 Design，不是画一条通路，而是写一套规则。」**
- **B（Build）构建**：实验室语境里通常指构建菌株（做载体、转化、编辑、筛选、验证），但工业发酵里要宽得多——**不只是一个基因型，还包括种子系统、无菌空气系统、压缩空气系统、搅拌传质系统、温控系统、灭菌系统、补料系统、取样系统、DCS 控制系统，以及让这一切长期稳定运行的工程秩序。**
  - 「Build 是把生命放进工业环境里，并且为它搭一套能活、能长、能产、能稳定复制的外部世界。」如果 Design 是在脑子里设计细胞工厂，Build 就是把这座工厂接上水、电、汽、风、糖、氨、碱、油，让它真正开工。
- **T（Test）测试**：不是简单测一个产量、OD、转化率，而是一整套残酷的现实拷问——小试好，5L 好不好？5L 好，50L 好不好？50L 好，500 吨好不好？这批好，下一批好不好？白天好，夜班好不好？新员工操作好不好？原料波动时好不好？夏天冷却能力不足时好不好？
  - **Test 最容易被低估**：很多人以为测试只是验证设计是否正确，但在工业发酵里，**Test 往往会反过来暴露我们根本没有设计到的问题**——摇瓶里没有混合死区，工业罐里有；实验室里没有吨级补料延迟，工业罐里有；小罐里温度容易压住，大罐里热量像一座内部自燃的锅炉；论文里的菌株没有夜班员工，工厂里的菌株有。
  - **「Test 的真正价值，不只是给 Design 打分，而是发现 Design 视野之外的变量。」**
- **L（Learn）学习**：实验室里往往是分析数据、更新模型、提出下一轮改造方案，但在产业里范围要大得多——一个批次失败是学习，一个品种价格崩塌是学习，一次专利诉讼是学习，一次反倾销调查是学习，一个企业兴衰是学习，一轮行业周期也是学习。
  - **如果说 Design、Build、Test 更像技术系统内部的循环，那么 Learn 就是把外部世界的反馈接回技术系统。**
- **各环节对应的文章群**（作为知识库导航参考）：Design 群覆盖专业地图、代谢网络、四象限细胞工厂、基因编辑、各品种（赖氨酸/苏氨酸/谷氨酸/蛋氨酸/色氨酸）、AI 辅助设计；Build 群覆盖菌种室、菌种生命保障系统系列（净化之肺/动力之心/搅拌之舞/冰火之御）、培养基灭菌史、5L 到 500 吨、成本决胜工程路线图；Test 群覆盖染菌、试车期不胜任循环、放大跨越、AI+机理混合建模、投资压力测试；Learn 群覆盖年度复盘、行业关键事件回顾、周期分析。
