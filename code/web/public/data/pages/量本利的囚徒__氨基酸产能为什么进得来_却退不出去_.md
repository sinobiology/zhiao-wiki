# 量本利的囚徒Ⅱ｜氨基酸产能为什么进得来，却退不出去？

## 核心逻辑
- 中国氨基酸企业的成本优势不只来自效率，更来自土地、信贷、社保、产业基金四条通道构成的系统性隐性补贴——补贴不写在账本上，它写在要素价格里。
- 隐性补贴最危险的效应不是让好项目更好，而是让本该亏损的项目在扭曲的要素价格下变得“可行”，导致不该扩的产也扩了。
- 企业层与地方政府层两层囚徒困境互相嵌套、自我强化，谁先动谁吃亏，均衡只能靠外部约束被强制打破。

## 行业洞察
- 2026年9月美国对中国赖氨酸征收双反税，最低组合税率121.58%。反补贴立案的本质是美方认定中国企业价格优势中有政府成分，而非纯效率差异。
- 同一套要素价格扭曲机制，在进入端改写了投资项目的NPV，抬高了表观ROIC；在退出端改变了企业生存边界，延长了产能出清周期——进来容易出去难，产能只进不出。
- 这套逻辑不仅适用于氨基酸，在光伏、新能源、钢铁等制造业同样成立：光伏组件产能已达全球需求1.6—1.8倍，产能利用率仅五成左右。

## 技术/管理要点
- 隐性补贴的四重通道：
  - **土地**：地方政府零地价或负地价出让工业用地，发酵工厂占地几百亩，前期成本被系统性抹掉。
  - **信贷**：融资平台、政策性贷款、产业引导基金提供低于市场利率的资金，使真实利率下不可行的项目变得“可行”。
  - **社保**：各地执行标准不一形成的“社保洼地”构成招商筹码，变相降低用工成本。
  - **产业引导基金**：财政出资做劣后吸引社会资本，放大投资规模的同时放大产能过剩风险。
- 东亚产业政策的三种中国式异化：
  - **规模不同量级**：日韩是“国家领航”，中国是三十几个省的“地方混战”，招商优惠包互相压价。
  - **绩效门槛退化**：日本通产省有外汇配额考核、韩国有出口创汇硬指标且完不成就断贷；中国优惠条件“写在纸上、落在抽屉里”，从鞭策变成兜底。
  - **退出节奏滞后**：日本1970年代后期减少干预，韩国1997年强制重组财阀；中国的要素价格扭曲至今未完全回归市场化。
- 内卷因果链：要素价格扭曲 → 表观WACC压低/表观ROIC抬高 → 过度进入 → 供给过剩 → 价格下行 → 亏损但固定成本沉没 → 地方就业和银行债权绑定 → 产能出清慢 → 价格战拉长。
