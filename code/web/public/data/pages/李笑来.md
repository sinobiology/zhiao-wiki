# 李笑来

## 定义
李笑来是一位长期主义教育者、投资人、作家，其思想横跨学习、写作、投资与认知升级领域。他在[[得到]]平台开设过课程，著有《通往财富自由之路》等作品，在库中常作为方法论与底层认知的源头被引用。

## 在知奥体系中的位置
李笑来在知奥体系中是一个高频引用的思想源头，尤其集中在写作与投资两条主线。写作上，他的「[[Narrow your topic]]」理念与[[写作方法论]]、[[聚焦思维]]紧密关联，被反复作为解决“迟迟无法下笔”的核心方法。投资上，他的[[定投]]、[[长期主义]]与[[场外赚钱]]思想，与[[损失厌恶]]、[[复利]]、[[现金流]]等概念相互支撑。

在更具体的学习与认知层面，李笑来强调“学习的本质是建立正确的大脑连接”，这一观点与[[得到]]、[[碎片化学习]]、[[神经连接]]以及库中多次出现的“浏览式学习”讨论直接呼应。他的“表现型人格”与“进取型人格”区分，也被用于指导[[成长型思维]]和[[过程性目标]]的实践。

同时，李笑来还作为“只有达到相似水平才会由衷敬佩”的例证型人物出现，用于说明[[达克效应]]、[[共情能力]]与[[认知偏差]]的关系。
