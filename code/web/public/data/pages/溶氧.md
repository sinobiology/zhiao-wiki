# 溶氧

## 定义
溶氧（Dissolved Oxygen, DO）指溶解在发酵液中的分子态氧浓度，是工业发酵中最关键的生理变量之一。它直接决定好氧微生物的呼吸链状态、能量代谢路径和产物合成方向，属于发酵过程三层模型中的细胞层面（生理变量）。

## 在知奥体系中的位置
溶氧是连接[[发酵罐]]操作变量与菌种生理响应的核心桥梁。在[[工业发酵]]的"三层黑箱逻辑"中，操作变量（转速、流量、罐压）必须先转化为溶氧、渗透压等生理变量，才能最终影响产量、收率等结果变量。材料6指出，控制室看到的是平均值，但菌经历的是"局部、瞬时的极端值"——溶氧的剧烈波动比平均值更致命。

溶氧的供给受[[亨利定律]]的物理约束：氧气在水中溶解度仅约8mg/L，因此[[发酵罐]]必须采用底部高压通气，利用压力和气泡上升时间为菌种"硬压"溶氧。这直接决定了空压机是发酵工厂最大的能耗设备，占全厂40%~50%能源账单。在[[菌种的生命保障系统]]框架中，溶氧控制属于"神经系统（感知控制）"的一部分，通过[[DO串级控制]]与转速、通气联动。

溶氧的剧烈下降会迫使菌体从有氧呼吸切换至低效的[[无氧呼吸]]，积累酸性副产物并导致代谢紊乱。因此，溶氧阈值常被用作[[SOP]]中的可量化触发条件，例如"当DO跌破30%，或发酵时间达12小时，立即将转速提升至600rpm"，以消灭模糊经验语言。

## 关键数据
- 氧气在水中溶解度仅约8mg/L，是溶氧供给的根本物理瓶颈。
- 500m³发酵罐液位12-15米，底部静压超0.15MPa，供气压力需达0.25~0.35MPa才能实现有效溶氧。
- 溶氧从30%骤降至10%，意味着呼吸链断裂，菌体被迫切换至无氧呼吸。
- 溶氧跌破30%被用作SOP中的转速提升触发阈值。
- 温度通过[[亨利定律]]反向影响溶氧：温度越高，氧溶解度越低，可能形成"温度失控→缺氧→厌氧代谢→有机酸积累"的死循环。
- 发酵罐每分钟吞吐250-500立方米空气，氧气从气泡到细胞有八道阻力，90%以上集中在气液界面液膜扩散。
