# "养龙虾"陷阱：只打磨金刚钻，不揽瓷器活

## 核心逻辑
- 人们容易沉迷于打磨工具（DO层）而回避真正的战略思考（BE层和CHOOSE层），这是一种"伪装性勤奋"。
- AI时代工具迭代极快，"再学一下"成为永恒的拖延借口，掌握最先进工具的人可能是最迷茫的人。
- 工具是手段不是目的，必须回到"我的瓷器活是什么"这个根本问题上。

## 行业洞察
- AI工具生态（新模型、新协议、新玩法）的爆发式更新，正在系统性地放大[[工具完美主义]]陷阱，让从业者陷入持续学习却无实际产出的循环。
- Token消耗、模型评测、工作流搭建等活动具有极强的即时正反馈，容易制造"掌控感"幻觉，掩盖价值产出的缺失。

## 技术/管理要点
- [[BE-CHOOSE-DO框架]]三层结构：
  - BE（存在层）：明确自己是谁、要去哪儿
  - CHOOSE（选择层）：判断什么事值得做
  - DO（行动层）：调用工具去完成
- 大多数人全扑在DO上，把行动层当成了全部，用工具上的精益求精填满战略上的空白
- 识别[[伪装性勤奋]]的标志：参数在调、进度条在动、对话框有反馈，但没有解决任何一个实际问题
- 破解方法：定期停下来自问"忙活这些天，它帮我解决哪怕一个实际问题了吗？"
