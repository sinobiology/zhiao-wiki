# 高峰让吉

## 定义
高峰让吉是日本生物化学家，1894 年从米曲霉中分离出真菌 α-淀粉酶并命名为 Takadiastase，建立了完整的工业化生产流程，是最早商业化微生物酶制剂的开创者之一。他的工作属于工业微生物与酶工程领域。

## 在知奥体系中的位置
高峰让吉在淀粉制糖酶工业化的历史起点上占有关键位置。在 [[糖源之战II系列]] 的叙事中，他从 [[米曲霉]] 获得 [[Takadiastase]]，证明了酶可以稳定、经济、规模化地制备——在他之前酶停留在实验室玻璃器皿和麦芽浸出液，在他之后酶变成工厂里的桶装产品。

他的贡献为后来 [[诺维信]]、[[Termamyl]] 等耐高温淀粉酶产品的出现提供了工业化前提。材料指出，1894 年高峰让吉已用米曲霉造出 Takadiastase 证明微生物生产酶的可行性，这一事实在对比工业酶与胰岛素的生产容错率时被再次引用。

他的局限也构成后续技术演进的反衬：来自真菌的 Takadiastase 最适温度仅 50–60℃，只适合做消化药片，无法满足 [[喷射液化器]] 所要求的 105–110℃ 工业液化条件。这一局限正是后来 [[地衣芽孢杆菌]] 耐高温酶与 [[蛋白质工程]] 技术登场的原因。
