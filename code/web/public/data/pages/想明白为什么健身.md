# 想明白为什么健身

## 核心逻辑
- 追逐健康长寿与追逐金钱权力不同，随着年龄增长，外部反馈机制逐渐失效，容易陷入随波逐流、得过且过的状态。
- 健身的目标不是"赖着不死"，而是健康长寿——要从现在开始为此进行长期筹划。
- 必须主动构建反馈机制（社区打卡、日程记录），用仪式感对抗孤独游戏中的惰性。

## 技术/管理要点
- 健身三要素：[[心肺功能]]、[[肌肉力量]]、[[身体柔韧]]
- 有氧运动计划：每周至少5次，每次不低于30分钟；工作日环湖跑3.6-4.0公里，周末公园跑5公里以上
- 力量训练计划：每天一次，利用[[Keep]]平台课程，胸肌腹肌交替进行
- 反馈机制设计：每次运动后发Keep社区打卡；每天运动完成后记录到手机日程，充满仪式感
- 健康管理的两个陷阱：
  - 同龄人圈层集体降低标准，将可避免的衰退视为理所当然
  - 四十岁后社交圈萎缩，六十岁后死亡率加速，健康追求变成缺乏外部反馈的孤独游戏
