# 张树政

## 定义
张树政是中国微生物生化领域的重要领军人物，中科院院士，也是中国科学院第一位生物化学领域女院士。她主导研发的黑曲霉糖化酶菌种曾为国家节约巨额资金和粮食，在中国工业酶制剂发展史上具有开创性地位。

## 在知奥体系中的位置
张树政出现在[[糖源之战II系列]]关于中国酶制剂工业与国际差距的叙述中。1993 年，她借赴欧参会之机专程访问[[诺维信]]前身 Novo 总部，这一行程的意义不在于签署协议，而在于直接看见了中国酶制剂工业与全球顶尖水平的真实差距。

她的工作为中国本土酶制剂产业提供了早期技术基础，但在[[糖源之战II系列]]的叙事框架中，她更多代表了中国从早期菌种研发到后来被迫面对表达系统、工艺嵌入和专利壁垒差距的历史起点。她与[[诺维信]]、[[Termamyl]]等实体同处一个关于工业酶国产化与追赶的讨论语境中。
