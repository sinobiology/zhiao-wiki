# 吴军

## 定义
吴军是计算机科学家、科技史作家，也是「得到」体系内以科技史与理性思维见长的课程作者。他的视角常将技术进步置于长周期历史中考察，强调科技累积的不可逆性。

## 在知奥体系中的位置
吴军与 [[万维钢]]、[[卓克]]、[[薛兆丰]]、[[李笑来]] 等人共同构成「得到」知识服务生态中的核心作者群，是知奥库中理性主义与科学思维脉络的关键节点。他在 [[科技史纲60讲]] 中提出的科技叠加效应，被用于解释 [[比特币]] 和 [[区块链]] 等新兴技术对制度体系的倒逼与重塑。

在思考生命意义与科学去魅的议题时，吴军常与 [[万维钢]]、[[卓克]] 等作者一同被引用，作为以科学视角解读世界、又不止步于虚无主义的代表。他与 [[信息即本质]]、[[熵增]]、[[负熵]] 等概念有直接关联，强调信息组织方式比物质容器更能定义价值。
