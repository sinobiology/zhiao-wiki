# 特朗普

## 定义
特朗普是美国政治人物，曾任美国总统，在知奥体系相关文章中作为影响全球市场和中美关系的关键变量出现。他的公开言论与政策取向，尤其是对华关税威胁，能直接触发加密市场剧烈波动。

## 在知奥体系中的位置
特朗普在中美关系分析中是一个高频触发事件的人物。材料1指出，[[釜山]]会晤的背景之一是美国在地缘多线受限下的现实压力，其中就包含特朗普政策遗产对[[中美关系]]的持续影响。他代表的是美国单边施压的路径，与[[习近平]]主导的对等谈判路径构成博弈的两端。
