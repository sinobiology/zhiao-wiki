# kLa

## 定义
kLa 是发酵工程中的体积传质系数，描述氧气从气相进入液相的总体传递效率。它是氧传递速率（OTR）公式中的核心参数，属于生物反应器工程与流体动力学交叉领域。

## 在知奥体系中的位置
kLa 是连接反应器硬件与细胞生理需求的关键桥梁。在 [[发酵罐]] 的“维生舱”体系中，它属于 [[搅拌系统]] 的核心输出变量——搅拌功率直接作用的对象。材料指出，搅拌功率与 kLa 之间存在“精密的能量博弈”，工程师需要用最少的能量代价换取最高的生物学产出。

在放大的语境下，kLa 是传统参数相似策略（P/V、kLa、叶尖速度）中的一项，但这种相似无法同时保持，行业正从“复制参数”转向“复制细胞经历”。kLa 因此成为一个典型例子：单点平均参数无法代表菌在局部、瞬时环境中的真实感知。

kLa 与 [[OTR]] 直接关联，公式为 OTR = kLa·(C\* - CL)，其中 a 为比表面积，kL 与液膜厚度成反比。它也与 [[双膜理论]] 紧密相关——氧传递总阻力 90% 以上集中在气液界面液膜扩散过程。

## 关键数据
- 氧传递总阻力的 90% 以上集中在气液界面的液膜扩散过程
- 500m³ 大型发酵罐搅拌功率可达数百千瓦
- 搅拌电机是仅次于空压机的第二大耗能设备
- 经典 Rushton 桨的功率准数极高，轴流桨功率准数仅为 Rushton 桨的十几分之一
- OTR = kLa·(C\* - CL)
