# 工业发酵

## 定义
工业发酵是利用微生物在大型发酵罐中进行规模化代谢生产目标产物的生物制造过程。它属于生物制造与发酵工程领域，核心是从实验室小规模验证走向工厂稳定连续生产的系统放大与成本控制。

## 在知奥体系中的位置
工业发酵是 [[生物制造]] 全链条中的工程落地环节，与 [[放大工程]] 紧密衔接——实验室探寻科学上限，工厂构建工程底线。在知奥体系中，它既是技术轴（[[发酵罐]]、[[DCS控制系统]]、[[连消系统]] 等装备如何稳定运行）的研究对象，也是竞争轴（成本曲线持续下移）的载体。

理解工业发酵不能停留在化学烧杯视角，而必须切换到 [[微观物理约束]] 视角：细胞代谢响应是秒级的，大罐物质均一化是分钟级的，这种数量级错配是工艺放大失败的真正根源。关键约束包括 [[平方-立方定律]]（罐体放大后产热增长远超散热增长）和传质效率瓶颈。

在管理维度上，工业发酵企业被描述为“能量系统”：先通过 [[战略选品]] 攒势能，再通过选址减阻力，最后靠技术转动能。[[能源成本]] 在这一体系中占结构性地位——汽轮机梯级利用可将热效率显著提升，而 [[新疆]]、东北等能源成本洼地的布局本质是借地理的势。

## 关键数据
- 发酵罐每分钟吞吐250-500立方米空气，空气净化需达到工业无菌标准（<1 CFU/m³）
- 空压机消耗全厂40%-50%能源
- 汽轮机梯级利用可将热效率从40%提升至70%以上，能源账单比竞争对手少30%
- 罐体放大10万倍时，产热增长10万倍，但散热仅增长2000倍，产热跑赢散热50倍
- 灭菌技术从121℃罐内灭菌进化到 [[UHT灭菌]]（140℃/3-5秒）
- 细胞周围营养分子储备量级为10⁹，转运蛋白每秒处理量级为10⁶，瓶颈在转运而非供给
- 氧气从气泡到细胞有八道阻力，90%以上集中在气液界面液膜扩散
