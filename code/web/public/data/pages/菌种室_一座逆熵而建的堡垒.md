# 菌种室：一座逆熵而建的堡垒

## 核心逻辑
- 菌种室的本质是在熵增的环境中，用压力梯度、气流物理和热力学边界硬性维持一块局部秩序，其防御核心不是"拦截"，而是"断掉脏空气进入的驱动力"。
- 小决定大：几百毫升摇瓶中的起始菌种，决定了几百立方米发酵大罐的产出，这是发酵工业最本质的杠杆。
- 维持无菌是防守，精准捕捉对数生长期中后期的接种窗口才是进攻，两者缺一不可。

## 行业洞察
- 菌种室在工厂中占地极小（万分之一级别），但它是整座发酵工厂代谢引擎的起点，体现了发酵工业"源头控制"的核心逻辑。
- 菌种室的洁净服逻辑与医院手术室相反——不是保护人，而是保护菌，人本身才是最大的污染源。
- 经验丰富的操作员通过泡沫质地、液体黏稠感等"体感指标"辅助仪器判断接种时机，这种隐性知识在工业发酵中仍不可替代。

## 技术/管理要点
- **四层嵌套防线（由外到内）**：
  - 十万级/万级区域：分级过滤，换气次数逐级增加，所有直角圆弧化处理以消除气流死区
  - 百级超净工作台：层流空气以0.3–0.5 m/s均匀扫过台面，定向带走颗粒
  - 酒精灯火焰周围5cm：热对流形成最后的物理屏障，无需过滤器和传感器
  - 正压梯度贯穿全程，让外部空气在物理上"挤不进来"
- **三条渗透通道的隔离逻辑**：
  - 人流：连体洁净服→规定穿戴顺序→空气淋浴房（30秒高速气流吹扫）→操作区内动作慢速化以避免涡流破坏层流
  - 物流：耐热物料走双扉灭菌锅（121°C / 20min，互锁双门）；不耐热物料走传递窗（紫外+表面消毒，互锁双门）
  - 信息流：无纸化操作（纸张是纤维碎屑源），防腐蚀触摸屏录入，数据是唯一不需要灭菌即可双向穿越边界的流向
- **接种窗口的精准捕捉**：
  - 目标：对数生长期中后期，窗口仅几小时
  - 判断依据：OD值（分光光度计）+ 镜检（细胞形态）+ 体感指标（泡沫细密度、液体黏稠感）
  - 培养基配方需平衡：营养过丰富菌种会"懒"，过贫瘠则进入应激自保
  - 摇床转速控制溶解氧水平，溶解氧是好氧菌代谢速率的限速步骤之一
