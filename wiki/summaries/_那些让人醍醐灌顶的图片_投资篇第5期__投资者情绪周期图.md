# 《那些让人醍醐灌顶的图片》投资篇第5期——投资者情绪周期图

## 核心逻辑
- 投资的真正难点不在认知，而在人性：损失厌恶让亏损产生与身体受伤一致的痛苦信号，靠理智战胜情绪几乎不可能。
- 情绪的解法不在场内而在场外：持续的场外赚钱能力为投资账户提供心理安全垫，决定你能否"拿得住"的不是信仰，而是现金流。
- 越是不需要靠投资赚钱的人，越可能通过投资赚到钱。

## 技术/管理要点
- **投资者情绪周期**：乐观 → 兴奋 → 狂喜 → 否认 → 焦虑 → 恐惧 → 沮丧 → 惊慌 → 投降 → 绝望 → 怀疑 → 希望 → 放松 → 乐观，每个投资者都会经历这条完整的心路
- **仓位管理保护心态**：只用非生活必需的钱投资，以"即使亏完也能睡得着觉"作为投入标准，投资结果不威胁生活才能真正理性
- **提高场外赚钱能力**：每月有新收入流入，就能看淡账面波动；收入越稳定，情绪波动越小；外部赚钱能力持续增长，过去的冲动 All in 都会显得无足轻重
- **定投的逻辑**：定时、定额、长期、分散，主动放弃择时幻想，用时间平滑风险
- **不要全职做投资**：买定离手后静待时间回报，等待过程中的多余动作都在打断复利增长，一定要找别的事做
- **投资24字箴言**：场外努力赚钱，场内复利增值，长期只买不卖，享受慢慢变富
