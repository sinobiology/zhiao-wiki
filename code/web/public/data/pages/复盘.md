# 复盘

## 定义
复盘是事后对决策过程、操作行为与结果进行系统性回顾与反思的方法，核心目的是把经历转化为可复用的经验与认知。在知奥体系中，它既被应用于投资交易，也被视为管理与组织能力提升的关键动作。

## 在知奥体系中的位置
复盘是连接个人认知与组织机制的核心环节。在投资场景中，它帮助人看清哪些操作有问题、以后该避开什么，与[[资产配置]]、[[周期]]判断共同构成从亏损到认知升级的路径。在管理场景中，它与[[认知对称]]、[[根因分析]]深度关联，用来把一线工程师与管理者之间的信息差转化为对系统问题的共同理解。

复盘也与[[德鲁克]]所说的“管理得好的工厂单调乏味”形成互补：真正有效的机制不是制造激动人心的事件，而是通过复盘让异常越来越少、系统越来越稳定。在[[量本利的囚徒]]等结构性困局中，复盘不是解决外部约束，而是先让人看清自己在系统里能改变什么、不能改变什么。
