# 产能过剩

## 定义
产能过剩指行业实际产量显著低于总产能、产能利用率长期处于低位，但仍持续扩产的状态。在氨基酸发酵行业中，它表现为结构性失衡与逆周期扩张并存，是行业整合与价格战的核心背景。

## 在知奥体系中的位置
产能过剩是贯穿[[缬氨酸]]、[[色氨酸]]、[[赖氨酸]]等多个氨基酸品种的共性困境。在不同品种中，它通过[[囚徒困境]]与[[纳什均衡]]机制持续强化：头部企业在“谁先收缩谁先丢份额”的结构性压力下，选择维持或扩产以建立威慑，导致集体陷入价格战。

在[[赖氨酸]]的产业史中，产能过剩与[[大成生化]]的崩塌紧密相关。大成生化在2011年行业高点将赖氨酸产能翻倍至80万吨，叠加中国氨基酸产能“西进运动”带来的低成本竞争，最终因财务错配与治理失控走向不可逆衰落。这一案例说明，产能过剩不仅压缩利润，也会放大企业的财务与治理风险。

在[[色氨酸]]和[[缬氨酸]]领域，产能过剩还受到[[影子产能]]与[[柔性产线]]的掩盖，传统供需分析框架面临失效。价格一有起色就被潜在产能压回，形成持续低价均衡。外部规则力量如[[欧盟反倾销]]也在介入，但并不能根本改变产业转移与集中度提升的长期趋势。

## 关键数据
- 2025年全球缬氨酸产能36.8万吨，实际产量19.1万吨，产能利用率仅52%
- 2025年缬氨酸均价13.71元/kg，同比跌4.79%
- 欧盟初裁对中国缬氨酸征收32.2%-53.9%临时反倾销税，中国出口量10.1万吨占全球产量过半
- 2025年全球色氨酸产能22.6万吨，产量仅14.8万吨，产能利用率65.5%
- 2026年全球色氨酸产能预计再增22.1%
- 2026年1月饲料级色氨酸报价28.5-30元/kg，较2025年初跌近40%
- 中国企业占全球色氨酸产能超60%
- 大成生化营收从2011年峰值144亿港元萎缩至2022年的3.72亿港元，跌幅97.4%
