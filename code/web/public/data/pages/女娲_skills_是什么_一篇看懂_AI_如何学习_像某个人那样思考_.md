# 女娲 skills 是什么？一篇看懂 AI 如何学习"像某个人那样思考"

## 核心逻辑
- AI 的真正分水岭不是"回答问题"vs"做事"，而是有没有 Skill 赋予它稳定的思维方式和工作流，Agent 的能力上限取决于背后接了什么技能。
- 女娲 skills 的本质不是复制一个人说过什么，而是提炼其思维框架——HOW they think，将分散的、只能"看"的学习改造成可以"调用"的学习。
- 真正有价值的认知蒸馏必须通过跨域复现、预测能力、排他性三重验证，不够独特和稳定的观点不配进 Skill。

## 行业洞察
- 用户需求正从"让 AI 提升效率"转向"让 AI 临时借给我一种更强的思考方式"，从效率工具走向认知工具。
- [[OpenClaw]] 等自主 Agent 生态升温，围绕 Skill 的讨论随之爆发，因为 Agent 能力上限不取决于模型本身，而取决于背后的技能和工作流。
- `nuwa-skill` 发布5天获得约 6.4k stars、942+ forks，说明"思维方式蒸馏"踩中了真实需求拐点。

## 技术/管理要点
- **入口分流设计**：区分"明确型"（直接蒸馏某人）和"模糊型"（先做需求诊断再反推适合蒸馏谁），本质上是一个"思维顾问入口"
- **6 个并行 subagent 架构**：
  - 著作 Agent：书籍/论文/长文，找反复出现的核心论点
  - 对话 Agent：播客/访谈/AMA，找即兴反应和被追问时的回答方式
  - 表达 Agent：社交媒体/短文，分析高频词、句式、争议立场
  - 他者 Agent：他人评价/书评/批评，补盲区
  - 决策 Agent：重大决策/关键转折，验证"说的"和"做的"是否一致
  - 时间线 Agent：生平与最近动态，防止 Skill 过时
- **三重验证机制**：跨域复现 → 预测能力 → 排他性，三项全过才升级为"心智模型"，否则降级或丢弃
- **SKILL.md 标准结构**：心智模型、决策启发式、表达 DNA、价值观与反模式、智识谱系、诚实边界、回答工作流（Agentic Protocol）
- **Agentic Protocol 是关键差异**：不是让 AI 用某人语气说话，而是遇到具体问题时先分类、再判断是否需要研究、最后按该人思维方式输出判断
