# 别人怎么对你，都是你允许的

## 核心逻辑
- 别人对你的态度，本质上是你自己一点点"教"出来的——你的每一次无底线退让，都在教对方如何轻视你。
- 真正舒服的关系不是靠妥协和讨好换来的，而是靠你先守住自己的边界，别人才会学着尊重你。
- 你想要别人怎么对你，得先自己做出示范；你有能力重新教会别人如何尊重你。

## 技术/管理要点
- 处处迎合奉承会向对方传递"别人比你重要"的讯息，导致对方予取予求
- "卤蛋效应"：长期无条件给予会被视为理所当然，一旦停止反而被指责（室友卤蛋的例子）
- 在亲密关系中，无底线的包容不等于爱，牺牲和让步不应成为关系的默认模式
- 改变路径：先把自己当成独立个体 → 建立并守住边界 → 对让你不舒服的关系说不 → 重新定义他人对待你的方式
