# 色氨酸（Tryptophan）

## 定义
必需氨基酸，饲料中继赖氨酸、苏氨酸、蛋氨酸后的第四限制性氨基酸。通过[[大肠杆菌]]直接发酵生产，技术路线中 yddG 基因（氨基酸外排泵）的调控是关键节点，也因此成为[[味之素]]对[[CJ集团]]专利战的核心争议对象。

## 在知奥体系中的位置
色氨酸是知奥体系中**专利壁垒最高、竞争格局最典型**的氨基酸品种：

- **技术壁垒**：色氨酸发酵菌株的构建复杂（多步代谢改造）、产物毒性高，头部企业的菌株专利形成有效壁垒
- **味之素vs CJ的战场**：[[味之素]]'373和'655两项专利保护 yddG 基因在色氨酸生产中的功能，2016年在美国ITC发起337调查，最终颁发排除令禁止CJ进口，2022年和解
- **中国竞争格局**：CJ集团价格暴跌（2025年毛利率从28.9%跌至16.9%）一定程度源于中国色氨酸产能的持续扩张
- **血色遗产**：1989年L-色氨酸污染事件（昭和电工）导致37人死亡，历史上给整个色氨酸行业蒙上了安全阴影，此后监管要求大幅提高
