# 基因编辑

## 定义
基因编辑是对生物体基因组进行定点修饰的技术，通过递送、定位、切割、修复等步骤实现对DNA序列的精确改写。在知奥体系中，它主要被放在发酵工程与合成生物学的交叉语境下讨论，是氨基酸菌种改造的核心技术手段。

## 在知奥体系中的位置
基因编辑在知奥体系中是连接[[合成生物学]]与[[发酵工程]]的枢纽技术。多篇文章反复强调，发酵工程师学习基因编辑是从“宏观过程控制”跃入“微观序列精确操作”的必经之路，也是从“菌株使用者”升级为“菌株创造者”的关键能力。

在氨基酸产业语境下，基因编辑与[[菌种工程]]、[[氨基酸育种]]深度绑定。[[给菌种「换芯」：十八个字讲透氨基酸发酵基因编辑]]一文将其翻译为工程师语言“进得去、找得准、切得开、缝得上、检得出、消得掉”，与[[谷氨酸棒杆菌]]等工业菌株的改造直接相关。[[一位发酵工程师的基因编辑初体验]]则从尺度感、无菌概念、时间感知等维度对比了基因编辑与传统发酵的差异。

基因编辑还被置于更宏观的认知框架中。[[从智子到基因编辑：微观改变与生命意义的思考]]将其作为“微观改变驱动宏观质变”的例证，与[[三体]]中的[[智子]]并置；[[氨基酸育种70年：从「进通节堵出」到四象限细胞工厂]]则把它放在七十年育种技术演进脉络中，作为跨象限协同的工具之一。

## 关键数据
- 基因编辑完整链条包括六个环节：递送、定位、切割、修复、检出、工程收口（材料4、材料9）
- 十八字框架：进得去、找得准、切得开、缝得上、检得出、消得掉（材料9）
- 关键验证步骤序列：菌落PCR → 质粒PCR → 酶切验证 → 测序（材料5）
- 相关技术工具：[[CRISPR]]、[[Cas12a]]、[[碱基编辑]]、[[先导编辑]]（材料9）
