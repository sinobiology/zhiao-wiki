# Anthropic

## 定义
Anthropic 是一家人工智能公司，专注于大语言模型与 AI 智能体的研发，其代表模型为 Claude 系列。它在 AI Agent 生态和基础设施标准建设中扮演关键角色，与 OpenAI、Google 并列为行业重要竞争者。

## 在知奥体系中的位置
Anthropic 在知奥体系中被视为 Agent 时代的关键基础设施提供者之一。它发起了 [[MCP]] 协议，使 [[OpenAI]] 和 [[Google]] 相继跟进，三大竞争对手在基础设施标准上罕见达成共识，说明行业判断这是下一代 AI 的必备基础层。

其官方插件市场是 [[Superpowers]] 等 Agent 工作流插件的重要分发渠道——该插件在 Anthropic 官方插件市场安装量达 23 万、排名第二，GitHub 上获得 11 万 Star。这表明 Anthropic 的生态不仅包含模型本身，也正在成为开发者社区围绕 [[Claude Code]] 等工具构建工作流规范的中心。

在模型能力上，Anthropic 与 [[OpenAI]] 处于竞争关系，但其模型可被 [[OpenClaw]] 等本地 Agent 平台作为多家可选模型 API 之一接入，形成“模型中立”生态位的一部分。[[Dario Amodei]] 确认 AI 正在写 Anthropic“大部分的代码”且逐月加速，说明其在内部工程中也在实践 AI 参与自身创建。
