# 味精战争：从200家到3巨头的四十年绞杀史

## 核心逻辑
- 中国味精工业经历了四十年从200多家混战到3巨头寡占的残酷收敛，驱动力是技术迭代、成本绞杀、环保门槛与政策管控的叠加效应。
- 味精工业不只是一个调味品行业，它是中国整个工业发酵产业的"黄埔军校"，为氨基酸、有机酸、酶制剂等后续赛道输送了方法、人才和组织经验。
- 行业终局的寡头定价权（阜丰、伊品同日同幅涨价）是高度集约化产业的必然结果，而非偶然。

## 行业洞察
- 1960年代微生物发酵法替代水解法是第一次技术革命，将吨耗小麦从30吨降至6吨、成本减半，直接打开产业扩张闸门。
- 1987年FAO/WHO取消味精摄入量限制的国际安全背书，与国内市场放开形成历史性交汇，引爆消费需求（1987年产量增速45.7%）。
- 1989—1994年的大洗牌是行业分水岭：原材料暴涨、能源紧缺、国务院64号文禁建千吨以下小厂，三重绞杀将200多家企业清洗至约60家，为巨头崛起腾出真空。
- 中国企业走"资源—地方—规模"路线，日本[[味之素]]走"技术—专利—品牌"一体化路径，两种模式的差距不在于能否生产，而在于能否建成长期可控的工业体系。

## 技术/管理要点
- **发酵法革命**：1965年投产的微生物发酵法取代小麦面筋水解法，原料消耗从30吨小麦/吨味精降至6吨，成本降低50%
- **生物素限制诱导**：第一代核心技术原理——生物素缺乏导致细胞膜结构松弛、谷氨酸外排；门槛低但控制精度差，适合乡镇企业粗放复制
- **莲花的成本杀招**：液氨代替尿素、硫酸代替盐酸、玉米代替大米，逆势将吨成本降低1200元
- **李怀清的"借梯上楼"策略**：聘请大专院校和科研机构专家组建智囊团，引进高生物素发酵技术，从全国第77位起步实现指数级跃升
- **行业淘汰标准"三高一低"**：生产能力低、粮耗高、能耗高、成本高的企业在1989—1994年成批死亡
