# 以太坊

## 定义
以太坊是一个开源、去中心化的智能合约区块链平台，其原生加密货币为以太币（ETH）。在知奥体系内，它通常与[[比特币]]一起被归为具有明确稀缺性、适合长期持有的“抗稀释”加密资产。

## 在知奥体系中的位置
在知奥的资产配置逻辑中，以太坊是“硬资产尺子”视角下的核心标的之一。材料中把它与[[比特币]]并列，视为在美元实际利率上升、法币长期贬值的环境下，适合通过定投持续置换的稀缺资产。

在币圈投资方法论里，以太坊同样扮演主仓角色。[[老猫]]的币圈安全原则明确将“主仓应为比特币和以太坊”列为第一条，说明在知奥体系的早期投资教育中，以太坊被定位为与[[比特币]]同等重要的基础资产。

此外，以太坊在稳定币生态中作为底层结算网络出现。材料涉及[[DAI]]这类加密资产超额抵押型稳定币，以及整个稳定币市场成为全球金融基础设施的过程，其中以太坊是承载大量稳定币发行与流转的公链基础设施。

在风险事件中，以太坊也作为受影响资产出现。[[Mixin Network]] 平台被攻破后，以太坊债务按事发时币价折算，占比高达70%，但追偿仍无明确日期，说明以太坊在用户资产结构中占比高，也暴露了中心化托管对加密资产的敞口风险。
