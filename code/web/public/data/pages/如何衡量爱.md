# 如何衡量爱

## 核心逻辑
- 爱的衡量标准是八个字："很有时间，不怕麻烦"——时间与麻烦是生命中最有限的资源，愿意将二者慷慨赠予，即是爱的最高礼赞。
- "没有时间"本质上是价值排序的结果，不是客观事实；怕不怕麻烦，暴露的是内心的优先级。
- 责任若缺乏爱作为根基，便易沦为负担甚至怨怼；真正的爱是心甘情愿，而非不得不尔。

## 技术/管理要点
- **时间分配法则**：一天24小时对谁都公平，"没时间"只是将某人某事排在后面的托辞。观察一个人如何分配有限时间，即可见其爱的真实含量。
- **麻烦容忍度测试**：对不相干的人抬眼皮都嫌费劲，对心爱之人却甘之如饴。麻烦不再是麻烦，反成了表达心意的途径。
- **责任与爱的辨别**："我为你付出这么多"表面是爱，内里可能藏着计较与交换。区分标准在于：心甘情愿还是不得不尔。
- **亲疏悖论**：人常把最充沛的时间、最少的麻烦留给陌生人，把残剩的精力留给最亲近的人。
- **时代反衬**：在一切关系都被"优化""高效化"的时代，愿意为你花费时间、不避麻烦的人愈发珍贵。
