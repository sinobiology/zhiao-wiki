# 公众号配图是怎么做的？我的 ChatGPT Image2.0 实操教程

## 核心逻辑
- **公众号配图不是单独写提示词，而是让 AI 沿着文章上下文继续工作。**
- 核心不是把某一句提示词写得多漂亮，而是**让模型真正理解文章**：如果它没读过文章，提示词再复杂也很容易生成一张「好看但无关」的图。
- **AI 负责把想法快速推到现实里，人负责判断什么是对的。**

## 行业洞察
- **公众号文章最缺的从来不是装饰图，而是把复杂内容讲清楚的图。** 过去写专业文章常有的尴尬是：文字写了很多，但读者还是很难在脑子里形成结构。AI 图像模型的价值正在这里——**它可以把一段文字变成图，把一个概念变成结构，把一个流程变成路径，把一个抽象判断变成读者能看见的东西。**
- Image2.0 最强的地方不是「画得更漂亮」，而是**它可以在理解文章以后，把文章里的概念、结构和情绪变成图片**。
- 局限也很明确：**它会犯错，会自信，会把不存在的结构画得像真的一样。**
- 此前实测结论（《生物绘图对决》）：GPT Image 2.0 在工程制图、科学图表、工艺流程图等**结构化任务**上已经非常适合做专业内容配图。

## 技术/管理要点
- **工具口径澄清**：在 ChatGPT 里叫 **ChatGPT Images 2.0**（2026 年 4 月 21 日发布说明明确其为 ChatGPT 里的新图像生成模型）；可直接在对话中创建和编辑图片，也可上传已有图片后用自然语言描述修改，支持不同宽高比。通过 API 调用时开发者文档当前写的是 `gpt-image-2`。
- **访问前提**：官网 https://chatgpt.com （已有账号可直接 /auth/login）。ChatGPT 并非在所有国家和地区都能正常使用——OpenAI 帮助中心有支持国家和地区列表，若所在地区不受支持可能无法注册、登录或访问。**「如果你在国内打不开官网，或者注册登录时提示地区不支持，这不是你操作错了，而是访问环境和服务支持范围的问题。」** 建议只使用官方入口，不要相信所谓「国内镜像站」「代充账号」「共享账号」。
- **顺序很关键：第一步不是做图，而是写文章**。文章写完后先把草稿粘给 ChatGPT 让它审核——不是简单改错别字，而是从读者角度看五件事：① 文章逻辑有没有断裂；② 哪些地方表达不够清楚；③ 哪些段落太啰嗦；④ 标题和开头有没有吸引力；⑤ 专业表述有没有明显问题。
  - **这一步已经为配图打基础**：因为审核过程中 ChatGPT 已读过全文，知道主题、结构、重点、情绪和读者对象——**它不是在完全不了解文章的情况下凭空画图，而是在已经理解文章的基础上给出配图方案。**
- **文章先定稿，再考虑配图**：文章还在改、逻辑还在变时，配图也很容易跟着变。顺序是：草稿 → ChatGPT 审核 → 自己修改 → 基本定稿 → 再做配图。定稿后的指令可以很简单（「给这篇文章做一组适合公众号的配图建议」），因为前面它已读过审过、对上下文有记忆。
- **先看配图建议，不急着生成**：ChatGPT 一般会先给出一组方案（封面图用什么主题表达什么情绪、正文第一张放在开头概括全文、第二张解释核心概念、第三张展示流程结构或对比关系、结尾图强化结论）。若建议偏了就直接指出，例如「第二张图太概念化了，我希望更像信息图，不要做成氛围图」或「这篇文章偏专业，不要生成太科幻的图」。
- **完整五步流程**：① 把文章草稿粘贴给 ChatGPT；② 让它审核文章、提出修改建议；③ 根据建议把文章改到基本定稿；④ 让它根据定稿提出配图建议；⑤ 建议没问题后让它直接生成一组图。最后由人来挑选、校对和决定用不用。
- **两点「技巧」**：第一，**不要一上来就让它画图，要先让它读懂文章**；第二，**不要把第一版图直接当最终结果**——要自己判断是否符合文章、是否适合手机端阅读、是否存在专业错误。
- 「不要把配图当成一个孤立任务，而要把它放进写作流程里」——从草稿审核开始 ChatGPT 就已在理解文章，到定稿后让它给配图建议只是顺着这条上下文继续往下走。这比单独写提示词省事。
