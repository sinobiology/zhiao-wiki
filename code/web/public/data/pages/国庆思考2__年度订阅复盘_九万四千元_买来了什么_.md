# 国庆思考2——年度订阅复盘：九万四千元，买来了什么？

## 核心逻辑
- 两年近十万元的订阅支出中，92.8%投向了"自我成长"和"资产增值"，本质上是用消费的形式做投资。
- 学习的意义不在于掌握选择技巧，而在于扩大选择范围——你不是没能力做好，而是不知道还可以这么做。
- "纸上得来终觉浅，绝知此事要躬行"，践行迈出的第一步实际上决定了对此事的绝大部分认知。

## 技术/管理要点
- **订阅分类框架**：将个人订阅分为娱乐休闲（1,344元）、效率工具（3,180元）、学习成长（31,012元）、加密投资（56,469元）、基础设施与生活（1,252元）、工作协作（1,176元）六大板块
- **赛道聚焦**：个人投资和学习高度集中于 [[AI]] 和 [[Crypto]] 两个前沿赛道
- **效率工具选择逻辑**：[[Get笔记]] 因AI加持和与得到内容打通提升了使用率；[[WPS]] 胜在跨平台和十年文档积累；[[腾讯文档]] 胜在微信生态协作和AI功能
- **密码安全管理**：不同平台使用同一密码极其危险，应使用 [[1PASSWORD]] 等专业工具，用一个主密码管理所有密码
- **AI工具实战**：选择最好的大模型是用好AI的第一步；[[沉浸式翻译]] 的中英对照模式和多引擎选择使翻译质量接近免修改直接使用
- **付费信息差策略**：在信息过载时代，付费进入优质信息圈层是突破认知边界的有效手段
- **践行方法论**：加入社群（如 [[上行部落]]）通过外部监督强制完成学习和践行，覆盖读书、健身、直播、AI、理财投资等领域
