# 自我认知

## 定义
自我认知是个体对自身定位、能力、价值取向和思维模式的识别与理解，属于个人成长与认知心理学领域。它既包括“我是谁、拥有什么、想要什么”的定位能力，也涵盖对自身认知水平和局限的觉察。

## 在知奥体系中的位置
自我认知是知奥体系中连接个人成长与认知科学的关键节点。在 [[四十不惑什么]] 的框架中，它与 [[价值判断力]] 共同构成成熟人生的核心，明确“能干什么不能干什么”，使个体不被社会竞争和他人价值观裹挟。在 [[百岁人生]] 的背景下，自我认知从某个年龄节点转变为持续更新的起点。

在认知偏差的语境中，自我认知与 [[邓宁-克鲁格效应]]、[[元认知]] 密切相关。材料指出，能力越差的人越倾向于高估自己，而高认知者能够将个人价值与观点分离，这本质上是对自我认知准确性的考验。避免陷入低认知陷阱的方法——如建立 [[反图书馆]] 意识、主动寻求负面反馈——都依赖更强的自我认知能力。

在哲学与 AI 应用层面，[[AI对话]] 被描述为一种“认知镜像”，能够映射用户的思维模式与价值取向。这意味着自我认知不再只是内省行为，也可以通过外部工具获得反馈，与 [[存在主义]] 强调的行动中定义自我形成互补。
