# DCS

## 定义
DCS（Distributed Control System，分布式控制系统）是工业发酵过程中用于集中监控和分散控制的自动化系统。它通过采集温度、溶氧、pH、压力等关键参数，协调执行机构实现发酵过程的自动调节，属于发酵工程自动化控制领域。

## 在知奥体系中的位置
在知奥发酵工程相关文章中，DCS 是连接"宏观操作"与"微观生理"的技术枢纽。材料1指出，操作员容易迷信 DCS 仪表盘上的平均值，但这些值只是设备指标，局部瞬时的极端值才是细胞的真实状态——这构成了发酵工程师从"看罐"到"微生物同理心"的认知分水岭。

DCS 与 [[SOP]] 共同构成车间执行的底层技术基础。材料3强调，研发人员应将 [[呼吸商]]、[[溶氧]] 等微观生理变量翻译为 DCS 自动控制逻辑，例如尾气 CO₂ 浓度超设定值时自动调节补糖速率，从而把工艺确定性固化进控制系统，而非依赖操作者个人经验。DCS 也是 [[补料控制]]、温度连锁控制等闭环调节的执行平台。

在放大生产的热力学瓶颈中，DCS 承担对 [[发酵罐]] 温度、[[溶氧]] 等参数的多回路协调监控。它无法突破 [[平方-立方定律]] 的物理极限，但可以在换热能力边界内优化控制策略，辅助系统工程决策。
