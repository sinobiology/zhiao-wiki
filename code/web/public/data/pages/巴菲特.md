# 巴菲特

## 定义
沃伦·巴菲特是价值投资理念的标志性人物，伯克希尔·哈撒韦公司的长期掌舵者。在知奥体系中，他主要作为投资认知、复利效应与长期主义的参照系出现，用于说明普通人如何理解并实践价值投资，而非简单模仿其具体操作。

## 在知奥体系中的位置
巴菲特在知奥知识库中反复出现，核心作用是承载对[[价值投资]]、[[复利]]与[[长期主义]]的阐释。在多篇投资认知系列文章中，他被用来支撑一个关键结论：真正的财富增长不是靠智商或技巧，而是“复利+时间”的指数效应。例如，材料中多次提到“巴菲特99%的财富来自50岁之后”，并由此推导出普通人唯一公平的竞争变量是时间。

同时，知奥对巴菲特的态度并非盲目推崇。在《巴菲特谢幕留下的人生算法》中，作者明确区分了“看懂他的智慧”与“模仿他的操作”——巴菲特拥有廉价保险[[浮存金]]、顶级CEO人脉等不可复制的优势，而当下资本过剩的时代背景也已改变。因此，普通人应转向[[趋势投资]]，以“长期定投，逢跌加仓”的八字诀来吸收其精神内核。

在更广的投资哲学框架中，巴菲特与[[段永平]]、[[查理·芒格]]、[[格雷厄姆]]等实体共同构成价值投资的思想谱系。他频繁出现在关于[[市场先生]]、[[能力圈]]、[[安全边际]]、[[标普500]]等概念的讨论中，成为衡量投资机会成本的基准之一。
