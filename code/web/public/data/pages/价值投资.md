# 价值投资

## 定义
价值投资是一种以企业内在价值为导向的投资理念，主张买股票就是买公司，强调安全边际、能力圈与长期持有。在知奥体系中，它既是投资方法论，也被视为一种在不确定性中追求确定性的生存哲学。

## 在知奥体系中的位置
价值投资是知奥内容矩阵中“投资认知”主线的核心概念，与 [[长期主义]]、[[复利效应]]、[[安全边际]] 等共同构成投资哲学框架。它频繁与 [[巴菲特]]、[[段永平]] 等人物关联，用于说明从“术到道”的认知跃迁。

在实践层面，知奥文章反复强调价值投资并非简单模仿 [[巴菲特]] 的操作，而是理解其背后的[[能力圈]]、[[市场先生]]等原则，并转化为普通人可执行的“趋势投资”路径，如“长期定投，逢跌加仓”。

价值投资也与行业分析形成呼应。例如 [[氨基酸]]发酵行业研究中提到的成本控制与护城河思维，本质上是价值投资中“企业持续创造财富能力”的产业侧映射。
