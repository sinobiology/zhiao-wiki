# 徐周文

## 定义
徐周文是[[大成生化]]的创始人之一，中国[[赖氨酸]]产业崛起过程中的关键人物。他具有产业经验与自主研发决心，与刘小明、孔展鹏的香港资本及国际视野形成互补，被称为“产业狂人+资本推手”组合中的产业侧核心。

## 在知奥体系中的位置
徐周文与[[刘小明]]、[[孔展鹏]]共同构成[[大成生化]]的创始团队互补结构。在[[赖氨酸]]战争系列材料中，他代表的是中国企业在技术积累与产业经验上的自主突破意愿，区别于单纯依赖外部资本或技术引进的路径。

[[大成生化]]的崛起依赖“技术积累+工程放大+资源禀赋+资本组织”四轮驱动，徐周文在其中对应技术积累与产业执行的环节。他与[[长江实业]][[李嘉诚]]的战略入股、与[[嘉吉]]的合资等资本运作之间，是一种产业能力先导、资本随后赋能的关系。

徐周文的个人命运深度绑定了[[大成生化]]的组织稳定性。材料显示，2012年徐周文病逝后，大成生化三年内连换三任总经理，战略执行力和危机应对能力出现断层，企业丧失了纠错窗口期，这成为大成后续财务崩塌的重要内部诱因之一。

## 关键数据
- 2012年，徐周文病逝。
- 徐周文去世后三年内，[[大成生化]]连续更换三任总经理。
- 在[[大成生化]]崛起阶段，徐周文以产业经验和自主研发决心与[[刘小明]]、[[孔展鹏]]的资本视野形成互补。
- [[大成生化]]曾将国际[[赖氨酸]]价格从3000美元/吨砸至约1200美元/吨，徐周文是这一阶段的产业侧主导者之一。
