# 与重力共舞：关于跑步，你所知道的一切可能都是错的

## 核心逻辑
- 跑步的本质不是"用腿蹬地推动身体"，而是通过身体前倾破坏平衡，将重力从阻力转化为前进动力，腿只是被动维持平衡的工具。
- 大多数人跑步受伤的根源在于"自以为是"地认为跑步不需要学习，错误跑姿导致膝盖承受不必要的冲击力。
- 任何看似简单的技能背后都有学问，关键心态是承认"这里面肯定有学问"，然后像学一门学科一样去研究它。

## 技术/管理要点
- **启动机制**：好的跑姿从第一步就不同——通过身体前倾破坏重力与地面反作用力的平衡，腿本能伸出落在重心投影正下方，跑步主角是躯干而非腿。
- **落地位置**：脚应落在重心正下方，地面反作用力垂直向上仅支撑体重，不产生制动力；过度前伸会产生向后的制动力，抵消前进动力并延长触地时间。
- **避免刻意蹬地**：刻意蹬地会产生过大向上反作用力，导致垂直振幅增大，浪费体能，还会过度消耗小腿体力、增加心脏负担。
- **关节状态**：支撑脚落地时髋关节与膝关节微屈，重心经过支撑腿后要有髋关节伸展意识；保持重心高且挺拔，不能含胸驼背"坐着跑"。
- **整体动作**：双脚呈滚动画圈状态，慢跑画小椭圆，快跑画大圆；支撑腿在重心后方时快速拉起。
- **摆臂要领**：向后幅度大（助力前进），向前离躯干近（不抢戏）；发力在肘，小臂始终放松；不过中线，沉肩不耸肩。
- **跑姿口诀**：身不动腿不动动力在前倾 / 提重心压振幅核心收紧两头松 / 不前伸不拖腿步幅靠腾空 / 快落地快拉起重心后滚动 / 后掣肘前送胸顶膝送髋冲冲冲。
