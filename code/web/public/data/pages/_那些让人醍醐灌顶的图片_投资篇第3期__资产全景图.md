# 那些让人醍醐灌顶的图片·投资篇第3期——资产全景图

## 核心逻辑
- 财富的增长来自长期持有增长型资产（股票、比特币），而非持有货币本身——200年数据显示股票1美元变70万，现金1美元贬值至5美分。
- 真正的风险不是波动，而是不投资：我们以为"安全"的现金和低收益资产，正在被通胀悄悄掏空。
- 风险是收益的"门票"，时间是复利的燃料——至少以10年为周期看待投资，短期波动只是噪音。

## 行业洞察
- 美国200年（1802-2002）资产收益全景图显示：剔除通胀后，股票长期年均实际收益稳定在6.5%-7%，远超债券、黄金和现金。
- 2015-2024年近十年全球资产收益排名：[[比特币]]几乎年年位列前茅，美股、[[黄金]]次之，房价、国债、汇率等"安全资产"长期原地踏步。
- 大众认知中的"高风险"资产反而藏着长期回报，"安全"资产实则被通胀侵蚀。

## 技术/管理要点
- **认知升级**：风险 ≠ 敌人，没有波动就没有回报，风险是收益的"门票"
- **时间为王**：任何小于10年的波动都只是噪音，唯有在时间中趋势才会显现
- **复利信仰**：1万元20年100倍变100万，关键是不打断复利过程
- **从"存钱"到"建资产"**：钱是手段，资产才是目的；"落袋为安"不是安全，是财富缓慢消失的开始
- **两张关键地图**：一张跨越200年看资产类别的长期规律，一张聚焦近10年看现实收益排名，两者结论一致
