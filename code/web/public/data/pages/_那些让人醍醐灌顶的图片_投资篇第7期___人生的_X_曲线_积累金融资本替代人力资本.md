# 人生的"X"曲线：积累金融资本替代人力资本

## 核心逻辑
- 人力资本（技能×剩余工作时间）注定随年龄衰减，依靠工作获得的"安全感"是幻觉，真正的安全感来自用金融资本完成对人力资本的替代。
- 人生存在一个"X"型交叉点：金融资本产生的现金流超过人力资本产出的那一刻，就是财务自由时刻。
- 投资的终极意义不是赚钱，而是"自救"——在人力资本耗尽之前，建立起足够强大的金融资本。

## 技术/管理要点
- **人力资本衰减的数学铁律**：人力资本 = 技能 × 时间，即使技能提升，剩余可工作时间每天都在减少，如同放射性元素的半衰期
- **投资 = 能量转移**：把"人力资本"（黑色柱子）搬运到"金融资本"（灰色柱子）上，本质是将劳动能量封存进金融资产容器
- **定投是机械化的能量转移SOP**：每月从工资中切下一块人力资本，买入[[指数基金]]，为"金融分身"持续输血
- **场外多赚钱的意义**：只有场外收入足够高（黑色柱子粗），才有更多余量填充灰色柱子
- **忽略短期波动**：目标是长达20-30年的替代过程，中间几年的波动只是噪音
- **高收入群体破产的根因**：赚得多但花得也多，没有足够快地将[[人力资本]]转化为[[金融资本]]，职业生涯结束时灰色柱子空空如也
