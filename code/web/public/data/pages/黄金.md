# 黄金

## 定义
黄金是一种贵金属资产，在全球资产配置中被归类为无息、防御性资产，不产生现金流，长期作为价值储存和避险工具存在。

## 在知奥体系中的位置
黄金在知奥知识库中多次作为对照资产出现。在与 [[比特币]] 的长期收益比较中，黄金在近十年全球资产收益排名中次于比特币但优于多数传统「安全资产」，处于资产谱系的中间位置。

在宏观定价框架中，黄金与 [[实际利率]] 紧密关联。当实际利率攀升时，作为无息资产的黄金持有成本上升，吸引力下降；当美元信用扩张、长期购买力下降时，黄金又成为「硬资产尺子」下对抗贬值的选项之一。

在以身体与财富为题的讨论中，黄金被视作被动防御性资产，其功能单一且无法对冲健康风险，因此被拿来与「囤肌肉」这种主动生产性资本对照，强调 [[生命资本]] 与金融资本的区分。同时，在财富认知图谱中，黄金与科技巨头、加密货币并列，被描述为人类信任与时代趋势的共识凝聚。
