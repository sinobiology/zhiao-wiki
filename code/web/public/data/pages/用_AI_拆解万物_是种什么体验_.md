# 用 AI 拆解万物，是种什么体验？

## 核心逻辑
- 通过结构化的分层描述提示词，AI 图像模型可以生成任何复杂物品的"解构式"视觉拆解图，将原料、层次与最终形态直观地"解剖"呈现。
- 这套提示词方法论具有高度可迁移性——从美食领域（佛跳墙）到生物实验领域（培养基成分与菌落形态），核心框架不变，只需替换领域内容。
- 关键在于提示词的结构设计：固定视角（45°）、纯色背景、分层漂浮、统一光线、中英双语标注，这些要素共同构成了可复用的"拆解万物"模板。

## 行业洞察
- AI 图像生成正在从"画一张好看的图"进化为"结构化知识可视化工具"，对科研、教育、产品展示等领域有直接应用价值。
- 生物实验领域（如培养基成分拆解）验证了该方法跨行业迁移的可行性，暗示任何需要"分层展示内部结构"的场景都可以套用。

## 技术/管理要点
- **模型选择**：使用 [[Gemini]] 的 [[Nano Banana Pro]] 模型，擅长生成结构清晰的解构式图像
- **提示词框架要素**：
  - 固定拍摄角度（45°商业摄影）
  - 纯黑背景，无底座无平台
  - 多层结构自由漂浮排列
  - 统一影棚戏剧性光线与超逼真材质
  - 每层食材/成分的细节描述（色泽、纹理、质感）
  - 底层放置完整成品
  - 中英双语箭头标注，左右错落分布
- **迁移方法**：保留框架结构，替换具体领域的层级内容与专业术语即可复用
