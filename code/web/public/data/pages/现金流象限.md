# 现金流象限

## 定义
现金流象限是财商教育中的核心概念，将个人或家庭的收入来源分为 E（雇员）、S（自由职业者/小企业主）、B（企业主）、I（投资者）四个象限。它用于区分不同收入结构的本质差异：E 和 S 靠个人时间和能力挣钱，B 和 I 靠系统和资产替自己工作。

## 在知奥体系中的位置
现金流象限是知奥投资认知框架的基础模型之一，常与 [[富爸爸穷爸爸]] 的财商启蒙一起出现，用于解释为什么勤奋本身不足以改变财务状况——关键在于收入来源结构，而非努力程度。

在「醍醐灌顶的图片」系列中，现金流象限图被列为理解收入结构本质差异的核心图片；它被用来解释从靠亲自劳动挣钱到让系统和资产工作的跨越方向。[[人力资本]] 向 [[金融资本]] 的转化，本质就是象限跨越的过程。

该概念与 [[复利]]、[[定投]]、[[法币贬值]] 等认知工具共同构成知奥体系中“从提桶者变为修管道者”的底层逻辑。它强调的是方向选择优先于努力程度，与 [[长期主义]] 和 [[可控试错]] 的主张相互支撑。

## 关键数据
- 四个象限：E（雇员）、S（自由职业者/小企业主）、B（企业主）、I（投资者）
- 象限跨越方向：从 E/S 象限（为钱工作）跨越到 B/I 象限（钱为你工作）
