# 百年味之素：凭什么穿越四个时代

## 核心逻辑
- 如果只把味之素理解成一家调味品公司，就很难解释它为什么能活过 117 年。
- 它真正值得研究的不是「味精」这个产品本身，而是**一家公司如何把一种基础科学能力持续转化为产业能力**：从谷氨酸钠到发酵工程，从厨房调味到烹饪解决方案，从氨基酸化学到 ABF 芯片封装材料。
- 七篇讲的是同一条主线：**理解氨基酸，利用氨基酸。**

## 行业洞察
- **最深的护城河，往往不是一开始就设计好的，而是在一次次危机、转型和长期积累中慢慢长出来的。**
- 百年历程中穿越的关口：1907 年池田菊苗从一碗普通海带汤中发现「鲜味」，1909 年世界第一瓶味精上市；此后经历关东大地震、战争与更名、战败后的废墟重建、发酵法技术冲击、味精安全争议、赖氨酸卡特尔案、印尼清真危机，最后在一个看似不起眼的材料研究方向上走进全球高端芯片封装供应链。

## 技术/管理要点
- **系列七篇的结构**（本篇为合订本索引）：
  1. 看全局——一家味精公司为什么能穿越四个时代
  2. 回到起点——一碗海带汤如何催生世界第一瓶味精
  3. 讲地震——一场灾难为什么反而加速了帝国成型
  4. 讲战争——更名、军需、战败之后，味之素如何重新回到餐桌
  5. 讲技术——发酵法危机如何逼出厨房革命
  6. 讲治理——科学、法律与信仰的三次暴击如何重塑一家全球化企业
  7. 讲破圈——从味精副产品到 ABF 材料，一家食品厂如何站上 AI 芯片供应链
- 这不是一部简单的企业史，更像一部关于**长期主义、技术复利、危机治理和产业跃迁**的案例集。
