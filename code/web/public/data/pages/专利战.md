# 专利战

## 定义
企业通过发起或应对专利侵权诉讼来影响竞争格局的战略行为。在氨基酸发酵领域，专利战的特殊性在于：产品形态（白色晶体）无法被专利保护，但"怎么造出来"（工艺方法、菌株基因）可以被保护，形成隐形壁垒。

## 在知奥体系中的位置
专利战是氨基酸行业"从成本竞争进入规则竞争"的标志，贯穿多条核心叙事线：

- **日美价格卡特尔→专利武器**：1990年代赖氨酸卡特尔崩塌后，[[味之素]]转向专利武器重划竞争边界
- **多法域组合拳**：[[味之素]]对[[CJ集团]]的6年专利战横跨美国ITC + 德国杜塞尔多夫 + 日本东京，三战场功能分工：速度（ITC排除令）+ 强度（德国禁令）+ 确定性（日本主场）
- **中国企业新战场**：[[梅花生物]]（2025年，味之素起诉，2.6亿）、[[凯赛生物]]（15年知产战争）
- **"付费共存"均衡**：高技术原料行业的专利战极少以"消灭对手"告终，更常见的是和解金=追溯性技术许可费，形成"先发者威慑，后发者付费入场"的纳什均衡
- **菌株是活的，专利是死的**：被告方通常采取"绕道设计"（密码子随机化、替换功能相似基因）策略，而原告用"等同原则"反制
