# 查理·芒格

## 定义
查理·芒格是美国投资家、伯克希尔·哈撒韦公司副主席，沃伦·巴菲特的长期合作伙伴。他以强调长期主义、复利思维和跨学科认知模型著称，属于投资与价值投资领域。

## 在知奥体系中的位置
查理·芒格在知奥体系中主要作为[[沃伦·巴菲特]]的长期搭档与[[伯克希尔·哈撒韦]]的核心人物出现。他与[[巴菲特]]共同代表了以[[长期投资]]和[[复利]]为核心的价值观，在关于资产全景图和巴菲特财富增长图的材料中，芒格被列为与[[复利]]、[[时间价值]]、[[资产配置]]等概念紧密相关的关联实体。

在关于巴菲特最后一封致股东信的材料中，芒格被明确提到是[[奥马哈]]社区内支撑巴菲特长期主义环境的关键人物之一。材料指出，[[唐·基奥]]、[[斯坦·利普西]]、[[小沃尔特·斯科特]]等关键人物与芒格一样来自同一社区，地理邻近催生了深度信任网络。这说明芒格不仅是投资理念的共创者，也是[[巴菲特]]扎根[[奥马哈]]、构建长期信任关系的重要节点。
