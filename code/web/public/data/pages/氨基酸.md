# 氨基酸

## 定义
氨基酸是工业发酵领域的核心产品类别，涵盖饲料级、食品级、医药级氨基酸及衍生产品。它属于生物制造与发酵工业交叉领域，在知奥ZHAO知识库中常被作为观察中国制造成本竞争、产业周期与全球化整合的典型案例。

## 在知奥体系中的位置
氨基酸是知奥ZHAO公众号长期深耕的行业主线之一，围绕其展开的内容覆盖产业周期、[[成本决胜]]方法论、并购整合与前沿技术。它连接[[发酵法]]、[[碳能解偶联]]、[[sCO2]]等降本路径，也与[[微利时代]]、[[供需错配]]、[[规模效应]]等产业规律紧密相关。

在产业链层面，[[梅花生物]]折价收购[[协和发酵]]被视为氨基酸企业从规模扩张转向全球化整合的标志事件；[[味之素]]对[[梅花生物]]发起专利诉讼，则揭示价格战之后专利战成为新竞争维度。技术层面，AI驱动的过程控制、混合建模、基因编辑等正改变菌种与工艺优化的传统路径。

氨基酸与[[味精]]、[[赖氨酸]]、[[色氨酸]]等具体品类形成细分关系，其中[[杰文斯悖论]]被用于解释效率提升反而扩大氨基酸总需求的逻辑。它也延伸关联[[生物制造]]、[[十五五规划]]等国家战略语境。
