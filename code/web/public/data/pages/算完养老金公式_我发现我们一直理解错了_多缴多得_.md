# 算完养老金公式，我发现我们一直理解错了“多缴多得”

## 核心逻辑
- 养老金不是一笔存款，而是一套跨代运行的分配制度——今天工作的人在供养今天退休的人。
- 基础养老金拿多少不取决于你交了多少的绝对值，取决于你的缴费基数相对于社平工资的“排名”。
- 计发公式中藏着二次分配调节器，它会压缩高低缴费指数之间的待遇差距，使“多缴多得”并非线性成立。

## 行业洞察
- 体制内与体制外退休金差距的根源，不在于制度身份，而在于缴费基数和连续性的系统性差异——体制外大量按最低档缴费，指数长期挂在0.6附近，几十年累积形成巨大差异。
- 人口老龄化和出生人口下降对养老金体系的压力来自现收现付的结构性缺陷：交钱的年轻人减少，领钱的老人增多。
- 退休地的选择对养老金待遇影响显著——同样按当地社平工资缴费38年，北京退休比山东退休每月多约3000元（按2025年口径）。

## 技术/管理要点
- **基础养老金计发公式**：`基础养老金 = 退休时社会平均工资 ×（1 + 本人平均缴费指数）÷ 2 × 缴费年限 × 1%`
- **缴费指数**：每年缴费基数 ÷ 当年社平工资，取几十年平均值。最低档0.6，社平档1.0，封顶档3.0。
- **调节器机制**：公式中的 `(1 + 指数) ÷ 2` 会将指数向1.0压缩。3.0倍缴费的计发系数被削至2.0，0.6倍被抬至0.8。5倍缴费差距被砍成2.5倍计发系数差距，最终待遇差距约3.4倍。
- **个人账户养老金**：账户余额 ÷ 计发月数。计发月数随退休年龄增大而减少（60岁=139个月，63岁=117个月），退休越晚，每月个人账户养老金越高。
- **个人可操作杠杆**：①延长缴费年限（线性收益，不被压缩）；②避免长期低基数缴费；③提前规划退休地（受养老保险关系和当地累计缴费年限约束）。
