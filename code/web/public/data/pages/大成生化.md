# 大成生化（Changchun Dacheng Biochemical）

## 定义
曾是中国乃至全球最大的赖氨酸生产商，依托吉林玉米带的原料优势崛起，高峰时期赖氨酸年产量超过100万吨。其兴衰是中国大宗发酵产业"规模扩张→成本竞争→利润消失"路径的经典案例。

## 在知奥体系中的位置
大成生化是知奥体系中**产业周期兴衰**的最典型案例：

- **崛起逻辑**：1990年代抓住赖氨酸价格战机遇，利用吉林廉价玉米和充足劳动力，以比日美企业低得多的成本快速扩张，打破了[[味之素]]等企业的寡头定价权
- **巅峰期**：2000年代初，大成生化的赖氨酸产量位居全球第一，直接逼迫ADM、[[味之素]]、[[CJ集团]]在赖氨酸产品上大幅降价
- **陨落过程**：过度依赖赖氨酸单一产品，缺乏向上游（菌种）和下游（品牌）延伸；玉米价格上涨、环保压力加剧、新进入者蜂拥；持续亏损→资产重组→退出赖氨酸主战场
- **历史意义**：大成生化的崛起，证明了规模效应是颠覆日美行业格局的武器；其陨落，则证明了规模效应本身没有护城河
