# 发酵产业（Fermentation Industry）

## 定义
以微生物发酵为核心生产手段的工业体系，包括氨基酸、有机酸、抗生素、维生素、酶制剂等多个细分领域。在知奥体系中，发酵产业主要指**大宗氨基酸发酵**：赖氨酸、苏氨酸、色氨酸、缬氨酸、谷氨酸（味精）等以葡萄糖为碳源、通过[[谷氨酸棒杆菌]]或[[大肠杆菌]]工业发酵生产的品种。

## 在知奥体系中的位置
发酵产业是知奥知识库的**核心赛道**，涵盖技术、竞争史、企业、个人从业感悟四个维度：

- **中国的主导地位**：中国是全球最大的氨基酸生产国，赖氨酸占全球70%+、谷氨酸占80%+，代表着工业发酵规模效应极致化的胜利
- **行业周期规律**：高利润→大量扩产→产能过剩→价格战→行业洗牌→新的技术门槛重新分层（二十年一个轮回）
- **竞争模式演变**：成本战（1980-2010）→专利战（2010+）→规则战（全球化壁垒+反倾销）→技术代际战（合成生物学颠覆传统发酵）
- **从业者视角**：知奥作者本人是20年发酵从业者，知识库中大量文章兼具产业分析和一线现场感
