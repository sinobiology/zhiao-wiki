# 极速调研秘籍：AI如何帮我1天完成新品战略规划？

## 核心逻辑
- 面对陌生领域的紧急战略调研任务，通过多AI工具接力协作（深度研究→内容提炼→视觉呈现），可在1天内完成从零到专业PPT的全流程输出。
- 一个清晰的战略框架型提示词（如"五看三定"），远胜于一百个零散的问题——让AI像专家一样思考的关键是给它结构化的思维骨架。
- AI是工具而非替代者，人的专业判断和主导思考才是最终成果质量的决定因素。

## 行业洞察
- AI深度研究工具已形成明显梯队：[[ChatGPT]] 5在深度研究领域综合最优（33页/33000字/116次搜索/19分钟），国产工具中[[秘塔AI搜索]]速度与质量平衡最佳（5分钟/259个来源），[[Kimi]]质量高但速度过慢（3小时+），[[DeepSeek]]深度研究能力与国外模型差距较大。
- 国产与国外AI大模型在"深度研究"模式上的核心差距体现在：搜索广度、信息溯源能力和输出深度三个维度。

## 技术/管理要点
- **三棒接力工作流**：
  1. 第一棒（信息收集）：多AI并行深度研究，同一提示词投喂5个工具，获取多视角素材
  2. 第二棒（内容提炼）：用擅长长文本分析的工具（如[[腾讯元宝]]）精炼核心观点，面向PPT场景提问
  3. 第三棒（视觉呈现）：用[[Napkin AI]]将数据和逻辑关系快速转化为专业图表
- **高效提示词设计三要素**：明确角色（"XX公司研究员"）、限定范围（具体技术领域）、提供框架（"五看三定"方法论）
- **[[五看三定]]框架**：看行业、看客户、看竞对、看自己、看机会 → 定控制点、定目标、定策略
- **i人使用AI的心理突破**：不怕提复杂问题、接受不完美的首次回答通过追问迭代、组合使用胜于单一依赖
