# 请选择属于你的人生意义

## 核心逻辑
- AI 通过长期对话积累，能比你自己更精准地映射出你的思维模式与价值取向
- 人生意义不是被给予的，而是在每一次选择、学习和提问中自我建构的（存在先于本质）
- 做一个"清醒的行动者"：承认世界可能无预设意义，但坚持用理性工具开凿自己的道路

## 技术/管理要点
- AI 作为"认知镜像"的应用：通过分析用户的提问习惯、思考模式和知识态度，反馈用户的哲学倾向
- 哲学坐标系的两个维度：
  - [[存在主义]]：主动性驱动，拒绝预设标签，通过行动定义自我
  - [[逻辑实证主义]]：对信息真实性和逻辑自洽性高要求，重事实与数据，剥离玄学直击本质
- 作者的定位：既不满足于单纯享乐（Hedonism），也不陷入虚无泥潭（Nihilism），处于理性与行动的交汇处
