# 认知变现

## 定义
认知变现是指将个人对世界的判断、信息和洞察转化为实际经济收益的过程。在预测市场语境下，它体现为"认知差即利润差"；在投资语境下，它被概括为"财富是认知的外在映射"。

## 在知奥体系中的位置
认知变现是连接 [[预测市场]] 与投资哲学的核心概念。在 [[预测市场]] 中，认知变现通过 [[事件资产]] 的买卖实现——合约价格即市场共识概率，买入被低估的结果就是对自身认知的定价，[[Polymarket]] 等平台为这种变现提供了交易场所。

在投资领域，认知变现与 [[财富与认知匹配]] 构成一对镜像关系：正向上，认知优势转化为利润；反向上，认知缺陷通过亏损暴露。材料3将其表述为一种"社会纠偏机制"——当财富超出认知时，社会会通过多种方式将其重新分配，直到两者重新匹配。

认知变现的质量高度依赖 [[Skin in the Game]] 原则。不愿为观点下注往往意味着并不真正相信它，真金白银的参与倒逼信息质量提升，这是认知得以变现的前提。
