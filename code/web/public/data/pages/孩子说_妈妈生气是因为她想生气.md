# 孩子说，妈妈生气是因为她想生气

## 核心逻辑
- 当被问"妈妈为什么那么生气"，孩子的回答是："妈妈生气，是因为她想生气啊。"——这不是狡辩，而是纯真地戳穿了"你惹我生气"这个情绪借口的本质。
- 三层递进的启示：①情绪是一种选择（不是被迫的，是"我选择生气"）②课题分离（作业写得慢是孩子的事，要不要发火是你的事）③责任回归（"你让我生气"→"我选择了生气"，中间差着整个人生的主动权）。
- 孩子无意间道破了阿德勒心理学的核心：我们可以不被外界牵着鼻子走。

## 行业洞察
- 亲子冲突中的"情绪归因"误区：大人习惯说"要被你气死了"，仿佛怒气是孩子按下的开关——但实际上生气从不是唯一的反应，只是选了一条最熟悉的路。
- 课题分离在实际亲子互动中的应用：分清哪些是孩子的课题（作业、成绩），哪些是自己的课题（情绪反应方式）。

## 技术/管理要点
- 在发火之前问自己三个问题：①我现在的情绪，真的是因为孩子做了什么，还是因为我选择了这个反应？②这个问题是谁的课题？③如果我现在不生气，还有什么其他方式可以回应？
- 承认"我选择了生气"一开始有点难堪，但紧接着是自由——"原来我可以不按这个按钮"。

## 金句归纳
> "'你让我生气'和'我选择了生气'，中间差着整个人生的主动权。前者把自己当成受害者，后者把自己迎回主人的位置。"
