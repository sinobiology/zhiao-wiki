# 特斯拉

## 定义
特斯拉是一家全球领先的智能电动汽车与可持续能源公司，业务覆盖电动汽车、辅助驾驶系统和能源存储。在知奥知识库中，它既是科技产品与出行行业的观察对象，也是企业管理和投资认知的经典参照案例。

## 在知奥体系中的位置
特斯拉在库中主要作为三类材料的连接点出现。其一，它是管理方法论的案例来源，[[国庆思考1——从特斯拉的一次更新想到的]] 通过其辅助驾驶系统从方向盘触碰检测升级为摄像头注意力监测，引出从 [[行为监督]] 到 [[状态洞察]] 的管理哲学。其二，它作为机构投资案例出现在 [[比特币白皮书发布17周年]] 中，[[特斯拉]] 与 [[MicroStrategy]] 并列，因将 [[比特币]] 纳入资产负债表而被写入机构化进程。其三，它在多篇摘要里作为关联实体出现，与 [[SpaceX]]、[[AI]]、[[自动辅助驾驶]] 等共同构成前沿科技与投资组合的参照系。
