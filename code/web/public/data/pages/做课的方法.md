# 做课的方法

## 定义
《做课的方法》是[[得到]]推出的一门线下培训课程，聚焦课程设计与知识输出方法论。它主张课程的本质不是传递知识，而是让学员的认知与行为发生具体改变。

## 在知奥体系中的位置
《做课的方法》是[[知奥ZHAO]]知识体系中「知识输出方法论」的核心来源之一。作者在2025年10月参加了该课程的线下培训，并将其原则直接转化为公众号写作方法，尤其是在《糖源之战》系列的改写中：[[做课的方法]]强调「内容不是分享我知道的，而是帮助读者完成一次认知变化」，这一原则指导作者将第八篇从「半干法制糖综述」重写为「旧答案—新答案」结构。

在内容合规与表达方式上，《做课的方法》与[[宣明栋]]、[[编码者-解码者模型]]、[[预防性创作]]等概念共同构成作者的创作风险控制框架。课程中关于避免冒犯、控制密度、小步快跑等「工装打磨」原则，也直接回应了行业人士做内容输出时「思考深入、表达开放」的需求。

## 关键数据
- 课程设计起点：从学员听完之后会怎么想、怎么做倒推内容，而非从「我知道什么」出发。
- 三段式结构：问题（真实痛点）→ 旧答案（习惯但错误的做法）→ 新答案（具体可操作的新方法）。
- 课程四要素：问题、旧答案、新答案、案例故事。
- 《糖源之战》第八篇借用其原则改写六版：最长版本近两万字压到一万多字，配图从8张减到5张，表格从3张减到1张。
- 行动三步法：①想清楚学员具体改变什么 ②找出旧答案及其错误原因 ③拆细节让小白一看就会用。
