# 为什么说投资第一步是"先套住，再研究"？

## 核心逻辑
- 投资的第一步不是学习理论，而是用真金白银下注入场——"出来混最重要的是出来"。
- 小白被套是大概率事件，因为你是被上涨吸引进来而非基于认知做决策，当小白也入场时往往已是牛市末尾。
- "套住"带来的痛感是认知跃迁的起点，求生欲驱动的学习远比纸上谈兵有效。

## 技术/管理要点
- **入场即学习**：买入第一手股票的过程（开户、银证转账、看K线）本身就甩开了90%的"嘴炮型投资者"
- **逐步拓展投资边界**：A股 → 美股（科学上网、境外银行卡、汇款结汇） → 数字货币（交易所KYC、私钥助记词、链上Gas费），每一步折腾都是能力圈的扩展
- **被套后的两种错误反应**：死扛（炒股变股东）和割肉跑路（从此远离市场），本质都是"进场靠消息，离场靠情绪"
- **被套后的正确姿势**：反思亏损原因、研究买点逻辑、学习仓位管理、评估标的价值，构建属于自己的认知系统
- **可控试错原则**：用5%-10%的闲钱试错，即使亏了不伤筋动骨，但能提前理解"流动性枯竭""项目方跑路""市场恐慌"等真实场景
- **反脆弱思维**：风险无法消除，只能被"预演"；被痛感磨出来的反应力，才是穿越周期的底气
