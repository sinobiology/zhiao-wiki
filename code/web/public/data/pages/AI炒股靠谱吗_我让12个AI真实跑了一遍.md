# AI炒股靠谱吗？我让12个AI真实跑了一遍

## 核心逻辑
- 多智能体系统的核心价值不在于给出答案，而在于"辩论机制"——强制让AI从对立角度审视同一标的，避免单一模型的确认偏差。
- 工具越强，人的判断框架就越重要：当AI能做任何事时，"做什么"成了决定性问题。
- 语音输入在AI协作中的效率优势：说话速度是打字的3-5倍，且自然提供更丰富的上下文。

## 行业洞察
- **TradingAgents项目**：GitHub 19.8万Star，模拟华尔街投行研究流程，12个智能体5支团队（技术分析师+情绪分析师+新闻分析师+基本面分析师+辩论+研究主管+风控+投资组合经理）。
- **部署成本**：用DeepSeek V4 Flash+Pro分析一只股票，约42万token，成本不到1元人民币（GPT-4o约高一个数量级）。
- **CRCL样本分析结论**：SELL，基于多空辩论中看空方在毛利率、估值两个维度论据更扎实（看多方对三个追问沉默），而非拍脑袋。

## 技术/管理要点
- **三大实用价值**：信息聚合（15分钟完成团队几天的数据收集）+ 对抗性思维（多空辩论暴露推理盲点）+ 结构化起点（作为深度研究起点非终点）。
- **部署关键经验**：Mac/zsh环境下pip安装含方括号的包需加引号；国内部署时pip装包关代理用镜像源，程序调API开HTTP代理，永远不设all_proxy SOCKS代理。
- **两种AI协作模式**：Claude Code（被动诊断，分析贴过来的报错）vs 豆包共享终端（主动观察，能发现操作者自己没意识到的问题如Windows/Mac语法混用）。
