# 原生家庭

## 定义
原生家庭指一个人出生并成长的家庭环境。在知奥体系中，它被视为影响个人潜意识信念、行为模式和人生选择的重要源头，尤其关联于金钱观、归属感与自我认知的形成。

## 在知奥体系中的位置
原生家庭在库中作为一个根源性概念出现，它不直接属于技术或管理方法，而是解释个体行为与心理模式的关键变量。在 [[2B人生]] 中，原生家庭与 [[归属感]] 的建立相关，过强的归属需求可能源于早期家庭环境的影响，进而与 [[持续成长]] 形成张力。

在金钱与财富主题下，原生家庭的作用更为直接。[[金钱恐惧症]] 被解释为包含"恐惧背叛[[原生家庭]]"的深层动因——维持贫穷成为一种扭曲的忠诚。同时，[[不配得感]] 的形成路径也强烈关联家庭中的物质匮乏与父母教育方式，这种模式通过 [[代际传递]] 延续到下一代。

## 关键数据
- 露易丝·海在 [[生命的重建]] 中列出 25 种"与钱过不去"的潜意识观念，其中包含家庭和社会文化中被动继承的限制性信念。
- 材料中提到"金钱恐惧症"的三层深因之一为"恐惧背叛[[原生家庭]]"。
- [[不配得感]]的形成路径被描述为：童年"好东西不属于自己" → 青少年"金钱等于痛苦" → 成年"享受即罪恶"。
- 文中提到"怕花钱"作为决策标准的具体表现：选有补贴的学校、选提供住房的小城市公司、选彩礼少的伴侣。
