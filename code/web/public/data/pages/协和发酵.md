# 协和发酵（Kyowa Hakko Kirin / Kyowa Fermentation）

## 定义
日本发酵与医药企业，全称协和发酵麒麟（Kyowa Kirin）。在氨基酸领域的历史地位极为关键：1956年率先完成谷氨酸直接发酵法工业化，打破了[[味之素]]对味精生产工艺近50年的垄断。2023年，[[梅花生物]]完成对协和发酵中国氨基酸业务的收购，标志着协和在中国市场的战略退出。

## 在知奥体系中的位置
协和发酵在知奥体系中扮演**技术颠覆者**的角色：

- **1956年技术突破**：协和发酵拥有更深厚的抗生素发酵背景，利用生物素限制条件筛选到能大量分泌谷氨酸的菌株，成功实现直接发酵法工业化，逼迫[[味之素]]放弃水解法、历时9年追赶转型
- **赖氨酸卡特尔**：1990-1995年，协和发酵与[[味之素]]、ADM、韩国CJ等五家企业共谋操控全球赖氨酸价格，最终因FBI调查全线崩塌。协和发酵作为合谋参与方，向美国司法部认罪并支付罚款
- **多田专利之争**：1950年代至1970年代，围绕谷氨酸直接发酵法基础权利的专利博弈，两家公司最终以交叉许可协议（1962年）结束对抗
- **中国退出**：2025年梅花生物折价收购协和发酵中国业务，说明中国本土企业的成本竞争力已彻底超越日本企业，协和选择聚焦医药高附加值业务
