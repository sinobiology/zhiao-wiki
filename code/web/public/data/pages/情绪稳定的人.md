# 情绪稳定的人

## 核心逻辑
- 情绪稳定是对一个人最好的评价，因为它意味着可预期、可理解、容易相处。
- 情绪不稳定本质上是一种操控他人的工具——用愤怒制造畏惧，用不快索取关注，用不可测度的情绪制造人际阶级差。
- 成为情绪稳定的人的路径：做自己的事，体验自己的生命，习惯和自己待着，不期待别人能带来什么。

## 技术/管理要点
- [[情绪不稳定]]的四种操控模式：爆发性愤怒（制造畏惧与服从）、爆发性不快（索取关注与让步）、情绪隔离（中断正常沟通）、阴阳怪气（制造压抑与不安）
- "刑不可知，威不可测，则民畏上也"——情绪不稳定者用不可预测性在人群中制造权力不对等，实现自我特殊化
- 应对情绪不稳定者的策略：将其视为"舞台表演"，保持观众心态，不爬上舞台试图解决；没有人鼓掌，表演落幕更快
- [[情绪稳定]]的人的特征：言辞和行为可预期、可解释、可理解；打算和所有人平等相处，不用手段操控他人
- 情绪稳定的人具有"力场效应"——身边的人会被感染，变得沉静松弛，内心苦恼自行崩解
