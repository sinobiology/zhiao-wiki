# 《那些让人醍醐灌顶的图片》第2期——法币贬值图

## 核心逻辑
- 钱不是财富，购买力才是——法币体系是一个被设计用来贬值的系统，存钱并不等于保值。
- 最大的风险不是投资亏损，而是货币在不知不觉中贬值，让储蓄者持续"失血"。
- 理财的目标不是赚更多法币，而是将现金转换为能抵御贬值的优质资产。

## 技术/管理要点
- **法币贬值的历史事实**：美元百年购买力从1.00跌至0.05，人民币近30年购买力下降约80%
- **贬值三大驱动力**：
  - 央行量化宽松导致货币供给指数级增长，实物财富增速跟不上
  - 债务驱动的信用体系必须"持续放水"维持增长
  - 1971年金本位脱钩后，法币完全脱离实物约束，仅靠信用支撑
- **通胀的财富再分配效应**：富人用资产抵御、穷人用工资对抗、中产被两头挤压
- **关键历史节点**：1913年[[美联储]]成立、1933年黄金禁令、1971年[[尼克松]]宣布美元与黄金脱钩
- **应对策略**：将现金逐步换成优质资产（房地产、优质股票、[[ETF]]、[[比特币]]等稀缺资产），让资产随货币放水一起上升
