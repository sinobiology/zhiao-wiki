# 去中心化

## 定义
去中心化是一种将控制权、信任或依赖从单一中心节点分散到网络多个节点或规则体系中的技术与社会组织方式。它常见于区块链与加密货币领域，也泛指互联网等系统中不依赖单一权威的架构。

## 在知奥体系中的位置
去中心化在知奥体系中被反复提及，但并非作为单纯的正面概念，而是常被置于批判性视角下审视。[[基础设施]] 相关论述指出，所谓去中心化只是把依赖从人转移到了物，例如 [[比特币]] 并未消除依赖，只是将依赖从央行/银行转移至电力系统、通信网络、计算设备和全球节点运转。因此去中心化与 [[尺度]] 紧密相关：每一层“自由”都踩在下一层基础设施之上。

另一方面，在关于 [[比特币]] 的多篇材料中，去中心化被视为其核心机制与价值基石。比特币作为基于密码学和分布式网络的去中心化价值存储系统，依赖全球数万节点和矿工共同维护，无 CEO、无董事会，靠代码自动运行。[[中本聪]] 在白皮书中提出的去中心化账本、[[工作量证明]] 与双重支付解决方案，实现了无需中介的点对点价值转移，也构成了一场“货币去国家化”实验的基础。
