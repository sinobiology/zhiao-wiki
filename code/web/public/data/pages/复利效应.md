# 复利效应

## 定义
复利效应是指收益在时间作用下不断累积、以指数级增长的现象。它广泛用于投资、个人成长与生命管理领域，被视为长期主义和技术/管理决策中的核心底层逻辑。

## 在知奥体系中的位置
复利效应在知奥知识库中横跨投资与生命管理两个维度。在投资领域，它被用来解释[[巴菲特]]长期持有和价值投资成功的关键：材料3指出“巴菲特的奇迹是坚持78年”，并将其列为[[时间杠杆]]的三要素之一。在材料1中，它关联[[长期主义]]与[[价值投资]]，说明优质资产在垃圾时间中仍需在场等待复利爆发。

在个人成长与生命管理中，复利效应与[[加速度管理]]紧密相连。材料2引用[[德鲁克]]的观点，提出“有复利效应时猛干，效率下降/身体报警时必须停下转为休息学习”，使复利效应从财务概念延伸为一种动态的生命节奏管理原则。它与[[定投]]、[[上行部落]]等实体同属于对抗人性、实现长期收益的方法体系。
