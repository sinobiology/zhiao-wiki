# 宁夏中科生物

## 定义
宁夏中科生物（ST 宁科）是一家从事生物发酵法生产长链二元酸相关业务的公司，核心产品为月桂二酸（DC12）。2017 年，该公司与中科院微生物所签订月桂二酸技术转让合同，获得生产菌株、发酵、提取和精制全套技术，目前处于凯赛生物提起的技术秘密诉讼之中。

## 在知奥体系中的位置
宁夏中科生物位于凯赛生物与中科院微生物所长达十余年的[[长链二元酸]]技术争议链条的重要节点。凯赛生物主张的技术传播链为：凯赛前员工 → [[山东瀚霖]] → [[中科院微生物所]] → 宁夏中科生物及中科新材。在这一链条中，宁夏中科生物被指控通过微生物所获取并使用了凯赛的[[技术秘密]]。

2017 年，中科院微生物所与宁夏中科生物签订[[月桂二酸]]技术转让合同，包含专利申请权、专有技术和技术秘密。这笔交易成为判断微生物所是否有权向第三方转让相关技术的关键事实之一。微生物所称该技术为中科院「十二五」部署项目成果，不侵犯任何第三方知识产权；但凯赛在 2026 年的诉讼中，将宁夏中科生物列为被告之一，主张其实际使用的技术与凯赛技术秘密高度相似。

宁夏中科生物的本体是上市公司 [[ST宁科]]。凯赛生物诉请的赔偿总额约 9.67 亿元中，宁夏中科生物与其余九方被告承担连带责任。本案的核心争议不在于[[月桂二酸]]这个产品名称，而在于 2017 年转让的具体技术信息是否与凯赛主张的秘密点相同或实质相同，以及是否经过[[山东瀚霖]]这条传播路径。

## 关键数据
- 2017 年与中科院微生物所签订月桂二酸技术转让合同，含生产菌株、发酵、提取和精制全套技术
- 2026 年 7 月被凯赛生物及凯赛（金乡）列为技术秘密诉讼被告之一
- 凯赛索赔经济损失 96,587.25 万元及合理开支 100 万元，合计约 9.67 亿元，按 5 倍惩罚性赔偿计算
- 凯赛主张宁夏中科生物与中科新材通过[[山东瀚霖]]获取涉案技术并对外转让
- 凯赛称 2024 年受邀为中科新材提供技术咨询服务期间，发现其实际使用技术与凯赛技术秘密高度相似
