# 伊品生物

## 定义
伊品生物是中国氨基酸发酵行业的大型民营企业，主要产品涵盖赖氨酸、苏氨酸、谷氨酸等大宗氨基酸品种。公司于2022年被国有上市平台广新控股收购，成为“反向混改”的典型案例，后装入上市公司星湖科技。

## 在知奥体系中的位置
伊品生物在知奥知识库中是理解中国氨基酸产业格局与国企民企融合的关键节点。它既出现在[[赖氨酸]]、[[谷氨酸]]等产品维度的产业分析中，与[[梅花生物]]、[[阜丰集团]]、[[大成生化]]共同构成大宗氨基酸竞争格局；也出现在[[混合所有制改革]]、[[组织能力]]、[[激励机制]]等管理维度，作为[[星湖科技]]吸收民营主体的代表性样本。

伊品与[[星湖科技]]的关系是库中反复出现的核心线索。2022年[[广新控股]]收购伊品，2023年9月完成重组，2025年10月原伊品总裁[[闫晓林]]接任星湖科技总经理，标志着从财务并表进入管理与文化深度融合阶段。这一融合被库中文章视为检验“混的是股权，改的是机制”命题的现实案例。

在产业竞争层面，伊品被描述为凭借西北区位布局（低价玉米+煤电成本）建立成本护城河的典型企业之一。[[赖氨酸战争]]系列材料提到，2014年[[梅花生物]]曾拟以38.22亿元收购伊品，后因[[希杰]]专利诉讼阻击而流产；伊品也被列入2025年九雄产能格局中，以星湖科技（伊品）名义拥有82万吨赖氨酸产能。

## 关键数据
- 2014年，梅花生物拟38.22亿元收购伊品生物，被希杰专利诉讼阻击而流产
- 2022年，广新控股收购伊品生物
- 2023年9月，完成收购重组
- 2025年10月，原伊品生物总裁闫晓林接任星湖科技总经理
- 2025年赖氨酸产能格局中，星湖科技（伊品）产能82万吨，位列第二，仅次于梅花生物100万吨
- 伊品在大庆布局45万吨新增产能
- 2010年后，伊品与梅花集团、阜丰集团一起将谷氨酸温度敏感调控体系推向极致，实现可编程化稳定高产
