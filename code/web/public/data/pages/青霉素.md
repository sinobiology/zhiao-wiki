# 青霉素

## 定义
青霉素是人类最早大规模工业化生产的抗生素，也是发酵工业从实验室走向产业化的重要推动产品。它属于制药与生物技术领域，是抗生素发酵体系的核心代表。

## 在知奥体系中的位置
青霉素在现代中国淀粉工业的起源中具有特殊地位。正如 [[糖源之战系列]] 所述，中国淀粉工业的起点不是粉条，而是青霉素——新中国成立初期青霉素高度依赖进口，1 瓶 20 万单位的盘尼西林价格相当于 0.9 克黄金。要建立自主的抗生素发酵体系，就必须先解决稳定淀粉原料供给，进而通过淀粉水解制备 [[葡萄糖]]，所以青霉素的需求直接倒逼出 [[华北制药厂]] 和 [[玉米湿法工艺]] 的落地。

在发酵工艺层面，青霉素是 [[抗生素]] 发酵的典型代表。其培养基成分复杂、染菌代价极高，因此 [[培养基灭菌]] 往往采用混合策略：可溶性组分连续灭菌，固体组分罐内灭菌。这一特性使青霉素在现代发酵工程中被反复作为高要求、高附加值的案例引用。

青霉素还与发酵能源体系密切相关。大型青霉素发酵罐需要底部高压通气并使用 [[离心式空压机]] 提供洁净无油的压缩空气，驱动方式上常与 [[汽轮机]]、[[梯级利用]]、[[热电联产]] 等动力方案结合，以降低全厂能源成本。

## 关键数据
- 1949 年，1 瓶 20 万单位的盘尼西林仅重 0.12 克，价格相当于 0.9 克黄金。
- 二战后，葡萄糖从甜味剂升级为青霉素发酵、氨基酸发酵、医用输液的核心底物。
- 青霉素发酵因培养基复杂、染菌代价高，多采用可溶性组分连续灭菌、固体组分罐内灭菌、无菌条件下混合的策略。
