# 又到国庆：订阅费再复盘

## 核心逻辑
- 这份年度账单本质上是一份试错记录：AI 工具从"要专门上课去学的东西"变成了"每天都在用的东西"。
- 消费重心从"买资格"移到了"买能力"——去年花钱买的是"知道"，今年花钱买的是"能做"。
- 跟上 AI 最快的方式只有一个：不断用最新的工具，去啃自己手头真在做的项目。工具会过时，项目会留下。

## 行业洞察
- 国产开源 AI 模型（如 Kimi、DeepSeek）正在以极高的性价比快速追赶 ChatGPT，Agent 集群、万字报告输出等能力一度形成不可替代性。
- AI 工具生态的竞争正从"比模型能力"转向"比入口集成"——腾讯 WorkBuddy 不做大模型、做大模型集成工具的思路，等于在抢上游入口，直接取代了单点工具的付费价值。
- AI Agent 热潮（OpenClaw"小龙虾"、Hermes"爱马仕"等）退潮后，其核心理念已被 WorkBuddy、Kimi Work 等产品吸收，工具更迭速度极快。

## 技术/管理要点
- **ChatGPT**：唯一从未断订的工具，20 美金/月。ChatGPT-5 幻觉减少、写作风格读取能力最强，Image 2 作图不可替代（文章封面图必须回到 ChatGPT 做）；Codex 桌面帮作者一天完成 590 条笔记迁移。
- **Kimi**：199 元/月 × 5 期。Agent 集群功能支持并行调研线，26 天完成八篇调研稿（此前需三个月）；输出万字报告能力是其不可替代期。后被 WorkBuddy 取代。
- **WorkBuddy**：腾讯出品，不做自有大模型，做多模型集成入口。自由切换模型、签到送积分、手机电脑无障碍打通，已承载公众号写作排版工作流和个人账单自动记账。
- **Claude Code**：通过 AICodewith 中间商使用（约 1,867 元），主要用于 AI Agent 冲突时的仲裁角色；Claude 模型 token 消耗大。
- **DeepSeek API**：150 元，性价比最高，验证工具和 OpenClaw/Hermes 等热点的默认挂载模型。
- **月抛策略**：凡口碑好的 AI 工具至少订一个月实试。自己掏钱用一遍与看评测的判断不在一个量级。"渣男策略"——不绑定、不忠诚，哪个好用用哪个。
- **GetDraft（得到大脑）**：AI 类最大单笔 7,448 元，核心价值在于将得到学习资产与个人知识库打通，从"记笔记"走向"用知识库代写"。
