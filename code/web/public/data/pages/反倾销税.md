# 反倾销税

## 定义
反倾销税是进口国对认定为倾销的外国商品征收的一种附加关税，旨在抵消出口价格低于正常价值造成的竞争扭曲。在氨基酸发酵行业语境中，它是中国出口企业面临的核心贸易救济壁垒之一。

## 在知奥体系中的位置
反倾销税是氨基酸发酵行业从成本竞争转向合规竞争的标志性变量。它与[[反补贴税]]共同构成针对中国制造的“双反”关税体系，直接影响[[赖氨酸]]、[[缬氨酸]]、[[苏氨酸]]等主力产品的出口利润结构，并成为[[梅花生物]]、[[阜丰集团]]等企业出海建厂、实施原产地置换的核心动因。

在规则技术层面，反倾销税的计算以[[正常价值]]与出口价格的差额为基础，牵涉[[倾销幅度]]的认定、成本证据链的构建，以及[[欧盟委员会]]、[[美国商务部]]等调查机关对财务数据和生产成本的现场核查。因此，它不仅是贸易政策问题，也是企业财务规范度、数据治理和应诉能力的考验。

从行业周期看，反倾销税放大了全球供给过剩与需求线性增长之间的错配——欧盟对华赖氨酸征收47.7%–58.2%、美国对[[L-赖氨酸]]加征最高80.37%等税率，直接压制出口端利润，加剧周期底部的深度与持续时间。同时，它也驱动头部企业通过哈萨克斯坦等成本洼地和原产地置换路径规避壁垒，重塑全球氨基酸产能布局。

## 关键数据
- 欧盟对中国赖氨酸征收反倾销税：47.7%–58.2%（2024–2025年）
- 欧盟对[[缬氨酸]]征收反倾销税：31.3%–53.8%（2026年Q1）
- 美国对华赖氨酸反倾销税率：73.55%–139.83%（2026年9月16日生效）
- 美国对[[L-赖氨酸]]反补贴税：最高80.37%
- 美国申诉的倾销幅度曾高达198%
- 印尼对华赖氨酸反倾销税：33.2%
- 欧盟强制进口登记机制支持对登记期内已清关货物追溯补税
- 反倾销税与反补贴税共同构成对华赖氨酸双重关税，合计最高可达约220%
