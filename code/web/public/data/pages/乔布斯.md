# 乔布斯

## 定义
乔布斯是苹果公司联合创始人，以其极致的产品哲学和独特的思维方式著称。在知奥体系中，他既是被「思维蒸馏」技术尝试提炼认知框架的代表性人物之一，也常被引用为产品与工艺降维设计的参照对象。

## 在知奥体系中的位置
乔布斯在 [[女娲skills]] 的材料中被列为可蒸馏思维框架的典型人物之一，与 [[马斯克]]、[[芒格]]、[[费曼]]、[[Paul Graham]] 等并列，属于「如何像某个人那样思考」这一认知蒸馏场景中的高频对象。女娲 skills 所强调的「提炼思维框架而非复制言论」，正对应乔布斯那种难以简单模仿、但可通过跨域复现与预测能力来验证的独特心智模型。

在 [[发酵工程]] 的降维哲学材料中，乔布斯与 [[苹果]]、[[iPhone]] 一起被提及，作为「把复杂留给自己、把简单交给用户」这一产品与工程理念的象征。这与发酵工程师将微观复杂性降维为车间可执行指令的思路形成呼应——研发端承受复杂度，使用者只接触简单、稳定的界面。

在 [[邓宁-克鲁格效应]] 的讨论中，乔布斯出现在关联实体列表中，暗示其被纳入关于认知层次、自信与谦逊关系的思考语境。这与他作为高认知者常被讨论的「现实扭曲力场」及对产品判断的极端自信形成某种对照。
