# AI最可怕的，不是快，而是开始像项目经理一样工作

## 核心逻辑
- AI真正的威胁不在于速度，而在于它开始具备项目经理的核心能力：任务拆解、异常处理、中间产物管理和结构化复盘。
- AI替代的不是"劳动"本身，而是知识工作中最消耗心智的"协调成本"——收集、整理、对齐格式、补失败任务、追踪中间结果。
- 人的不可替代价值在于"定义问题"和"专业判断"，AI负责在框架内穷举细节和保证鲁棒性。

## 行业洞察
- 对话界面是AI的"演示模式"（接待大厅），可编程接口才是"生产模式"（车间），大多数普通用户尚未跨过这道门槛。
- AI首次让单个知识工作者同时扮演研究员、项目经理、执行者、复盘者四个角色成为可行，个体的执行能力正在逼近小团队水平。
- 115篇专利从信息提取到5篇发明专利初稿，传统2-3人团队需两三周，AI协作仅需一下午+70元API费用，但问题定义能力和专业判断仍是真正稀缺资源。

## 技术/管理要点
- **四阶段流水线设计**：PDF预检 → 信息提取 → 空白分析 → 初稿撰写，每阶段有明确的可验证中间产物（CSV/MD/DOCX）
- **断点续跑机制**：每处理完一个文件结果立即落盘，下次运行自动跳过已处理文件，支持随时中断和失败重跑
- **系统性防御而非逐个修补**：编码问题在第一行代码就封装 `encode('gbk', errors='replace')`；token限制拆成两次API调用而非盲目加大
- **AI复盘的三层结构**：踩坑记录（现象+根因+改进）→ 方法论反思（约束探测、分阶段验收、环境兼容）→ 假设修正（不是"哪里错了"而是"原始假设哪里错了"）
- **人机分工原则**：人负责需求定义、关键决策、质量验收；AI负责架构设计、代码实现、故障排查、复盘总结
- **"验收"而非"检查"**：AI产出的初稿不能直接用，但骨架已搭好，专业人士只需精修，比从零开始快10倍
