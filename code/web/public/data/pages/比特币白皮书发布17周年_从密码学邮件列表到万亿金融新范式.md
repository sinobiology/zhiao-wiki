# 比特币白皮书发布17周年：从密码学邮件列表到万亿金融新范式

## 核心逻辑
- 2008年金融危机为比特币提供了完美的诞生时机，中本聪以9页白皮书回应了传统金融体系的信任危机，提出去中心化的点对点价值转移方案。
- 17年间比特币完成了从极客实验到万亿级全球资产的跃迁，核心驱动力是机构资金入场、合规通道打通（现货ETF）和通缩模型的持续验证。
- 比特币的本质已从"数字现金"演进为多元化金融基础设施，其抗审查、无需许可、全球可访问的价值主张是持续吸引力的根源。

## 技术/管理要点
- **白皮书核心机制**：去中心化账本、工作量证明（PoW）、双重支付解决方案，实现无需中介的点对点价值转移
- **关键里程碑时间线**：
  - 2009年创世区块 → 2010年首次实物交易（10,000 BTC买披萨） → 2013年突破100美元 → 2017年突破2万美元 → 2021年达69,000美元历史高点 → 2024年现货ETF获批与第四次减半
- **技术演进**：[[闪电网络]]等Layer2方案提升交易效率，[[Stacks]]等智能合约侧链扩展功能边界
- **机构化进程**：[[MicroStrategy]]、[[特斯拉]]将比特币纳入资产负债表；[[美国证监会]]批准[[比特币现货ETF]]打通合规入金渠道
- **当前规模**（截至2025年10月）：市值突破2.3万亿美元，全球前十大资产，超1.5亿用户持有
- **未解挑战**：价格波动性、能源消耗争议、监管不确定性
