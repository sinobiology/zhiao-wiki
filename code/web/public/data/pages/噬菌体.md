# 噬菌体

## 定义
噬菌体是一类以细菌为宿主的病毒，粒径约 0.02–0.1 μm。在工业发酵中，它因能裂解生产菌、导致发酵批次突然失败而被称为最致命的隐形威胁；在合成生物学中，它又被作为 AI 设计生命体的模型对象。

## 在知奥体系中的位置
在知奥体系中，噬菌体同时出现在两条战线上。在 [[合成生物学]] 方向，[[Evo-2]] 生成的噬菌体 DNA 序列可以在实验中成功复活并完成感染循环，使噬菌体成为验证「AI 设计生命」闭环的关键载体，与 [[φX174]]、[[φ69]]、[[φ2483]] 等具体噬菌体变体直接关联。

在工业发酵方向，噬菌体是 [[氨基酸发酵]] 和 [[发酵工程]] 中最严峻的生物安全风险之一。它不消耗培养基中的营养物质，而是直接裂解 [[谷氨酸棒杆菌]] 等生产菌，使产酸曲线突然崩塌。因此，噬菌体防御能力正在成为评估菌株工业价值的隐性指标，并与 [[无菌空气系统]]、[[PTFE膜滤芯]] 等实体构成完整的生物安全防线。

## 关键数据
- 噬菌体粒径约 0.02–0.1 μm，单靠 0.2 μm 过滤器无法拦截，需采用 0.01 μm PTFE 双层膜进行终端过滤。
- [[Evo-2]] 生成约 1 万个新噬菌体序列，经筛选后合成 285 个，其中 16 种在实验中成功复活并完成感染循环。
- 部分 AI 设计噬菌体效率超越天然模板：[[φ69]] 复制速度提升 16–65 倍，[[φ2483]] 杀伤效率是模板 [[φX174]] 的三倍。
- 噬菌体污染在工业发酵中被描述为「死刑判决」，可直接导致整罐发酵失败。
