# 投资者情绪周期

## 定义
投资者情绪周期是描述市场参与者在投资过程中情绪波动的循环模型，从乐观到兴奋、狂喜，再经否认、焦虑、恐惧、沮丧、惊慌、投降、绝望，最终经怀疑、希望、放松回到乐观。它属于行为金融学与投资认知领域，用以解释市场情绪对人决策的深层影响。

## 在知奥体系中的位置
投资者情绪周期是「[[知奥ZHAO]]」投资认知系列的核心概念之一，出自公众号文章《那些让人醍醐灌顶的图片》投资篇第5期，与 [[现金流象限]]、[[法币贬值]]、[[复利]] 等图形并列，共同构成理解市场与财富本质的认知框架。

该概念在知奥体系中主要与两个方向关联：其一，在《2025年10月总结》中作为“醍醐灌顶的图片”投资认知系列的关键图例被列出，用于揭示市场情绪的钟摆效应；其二，在《为什么说投资第一步是“先套住，再研究”？》中作为关联实体出现，用以说明被套后情绪驱动的错误反应及其反面——通过 [[仓位管理]] 与 [[可控试错]] 建立理性。

在操作层面，投资者情绪周期的化解路径并不在情绪本身，而是通过场外赚钱能力与 [[现金流]] 提供心理安全垫，配合 [[定投]] 和长期持有，减少情绪波动对决策的干扰。这与 [[损失厌恶]]、[[行为金融学]] 密切相关。

## 关键数据
- 投资者情绪周期完整链条包含 14 个阶段：乐观 → 兴奋 → 狂喜 → 否认 → 焦虑 → 恐惧 → 沮丧 → 惊慌 → 投降 → 绝望 → 怀疑 → 希望 → 放松 → 乐观
- 材料提出“投资24字箴言”：场外努力赚钱，场内复利增值，长期只买不卖，享受慢慢变富
- 材料建议用 5%-10% 的闲钱进行可控试错，以提前理解市场恐慌等真实场景
- 材料指出“牛市总是在悲观中诞生，在怀疑中成长，在乐观中成熟，在兴奋中死亡”
