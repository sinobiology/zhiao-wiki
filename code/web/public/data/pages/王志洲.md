# 王志洲

## 定义
王志洲是山东凯赛原副总经理，后成为山东瀚霖相关技术转移与商业秘密侵权链条中的核心自然人被告。他因离职前后将凯赛生物部分商业秘密带入瀚霖并用于工业化生产，在多份刑事、民事生效裁判中被认定构成侵犯商业秘密罪或共同侵权。

## 在知奥体系中的位置
王志洲是凯赛生物与山东瀚霖、中科院微生物所之间长达十六年知识产权与技术秘密纠纷的关键连接点。他曾在凯赛任职期间掌握相关技术，离职前后即代表瀚霖向设计院提交与凯赛商业秘密高度吻合的项目实施方案，把他与[[山东瀚霖]]、[[葛明华]]、[[曹务波]]等人的行为连成一条从[[凯赛生物]]向外部传播[[技术秘密]]的路径。

在最高法(2022)最高法知民终445号判决中，法院认定王志洲与葛明华、曹务波、山东瀚霖共同侵犯凯赛部分技术秘密；刑事终审裁定同样确认山东瀚霖和王志洲均构成侵犯商业秘密罪。他在技术转让合同、专利权属及署名权纠纷中也反复出现，是理解[[中科院微生物所]]与[[凯赛生物]]之间“原始技术权利”与“企业产业化改进成果”争议的重要人物节点。

## 关键数据
- 2008年7月30日：从山东凯赛副总经理职位辞职。
- 离职前后：以瀚霖代表身份向设计院提交了与凯赛商业秘密高度吻合的项目实施方案。
- 2012年：作为被告之一被诉侵犯发明人署名权；一审认定侵犯署名权成立，王志洲等5人需在《科技日报》刊登声明赔礼道歉，二审维持原判。
- (2019)鲁08刑终5号刑事二审裁定：认定山东瀚霖和王志洲均构成侵犯商业秘密罪。
- (2022)最高法知民终445号判决：最高法经技术比对认定瀚霖生产线使用了凯赛主张的75个秘密点中的13个；王志洲、葛明华、曹务波、山东瀚霖被认定共同侵犯凯赛部分技术秘密，判令停止侵权并赔偿。
- 2026年7月：凯赛生物及凯赛（金乡）以侵害技术秘密为由，将王志洲等十方诉至北京高院，请求连带赔偿经济损失96,587.25万元及合理开支100万元，合计约9.67亿元。
