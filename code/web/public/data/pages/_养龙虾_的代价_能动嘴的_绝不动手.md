# "养龙虾"的代价：能动嘴的，绝不动手

## 核心逻辑
- 培养人（或调教AI）的真正代价不是金钱，而是那份愿意"容错"的耐心——我们舍得付50块Token费，却舍不得给人一次犯错成长的机会。
- AI的学费是一次性的（学会即永久），人的学费要反复交（遗忘、离职、重头再来），但两者的底层逻辑一致：你必须忍住不动手，才能让对方真正学会。
- 培养的本质不是让别人变成你，而是让你接纳那个需要通过外界反馈不断修正的自己。

## 行业洞察
- AI Agent（如[[OpenClaw]]）的调教过程，本质上复刻了管理者培养新人的全部困境：听不懂需求、反复试错、成本不可控。
- AI协作时代，"能动嘴绝不动手"从管理修养变成了硬性要求——AI不会主动揽活，你不问它不说，不逼它不想，迫使管理者必须把需求想清楚。

## 技术/管理要点
- **容错成本 vs Token成本**：传统培养人的代价是时间和情绪（不可量化），AI的代价是迭代调试费用（可量化）。152次对话、50.24元换一张截图，但换来的是"以后永远不用再教"。
- **控制权转换原则**：强迫自己只动嘴不动手，把动手机会留给对方（人或AI）。动手是本能，动嘴是修养。
- **自己动手的隐性代价**：效率高、结果可控、有成就感，但代价是"别人永远没有机会成长"。
- **AI纠错的一次性特征**：技能写进记忆后不会丢失、不会离职带走，与人的反复遗忘形成对比。
- **培养人三层境界**：
  - 把工作交出去，看着他搞砸还能心平气和——培养人
  - 手把手教他做对，不给犯错机会——锻炼自己
  - 貌似交出去却要求按你的方式做——自我虐待与虐待他人
- **育人前提**：育人之道先有育人之心，育人之心先有容人之意。
