# A股

## 定义
A股是中国内地发行、以人民币计价并在境内证券交易所上市交易的股票，是中国资本市场最主要的股票投资市场。属于投资与证券行业，是境内投资者最基础、最可及的权益类资产配置入口。

## 在知奥体系中的位置
A股在知奥的知识体系中常作为投资能力圈的起点出现。在[[可控试错]]与[[认知升级]]的路径中，[[A股]]是投资者从理论走向真金白银入场的第一站，之后才逐步拓展到[[美股]]和[[比特币]]等更复杂的市场。

在市场分析层面，[[A股]]常与[[沪深300]]一起被用来观察中国资产的长期收益特征。它与[[实际利率]]、[[美联储]]和[[美元]]等全球定价因素相关联，说明A股并非孤立市场，而是受到全球流动性和风险偏好变化的影响。在[[价值投资]]和[[长期主义]]的讨论中，A股的波动与“垃圾时间”概念也被用来检验[[巴菲特]]式的持有策略是否适用于中国环境。

## 关键数据
- 过去18年，[[A股]]中[[沪深300]]总收益的71.4%来自仅10个关键交易日，占比0.23%。
- 与全球资产同步下跌相关的是美元实际利率攀升，A股作为风险资产之一，在此环境中吸引力下降。
- 材料中提到，被套是A股小白投资者的大概率事件，因为多数人是在上涨行情末尾、基于情绪而非认知入场。
