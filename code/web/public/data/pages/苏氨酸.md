# 苏氨酸（Threonine）

## 定义
必需氨基酸，畜禽饲料中继赖氨酸之后第二重要的限制性氨基酸。通过[[大肠杆菌]]直接发酵生产，中国是全球最大生产国，产能约100万吨/年以上，技术路线以"原子经济性闪电战"著称——从葡萄糖到苏氨酸的代谢路径短、转化率高。

## 在知奥体系中的位置
苏氨酸是知奥体系中**成本最低、技术壁垒相对较低**的大宗氨基酸：

- **知奥定位**：苏氨酸是规模效应极致化竞争的典型案例，与[[赖氨酸]]并列为产能过剩最严重的两大品种
- **价格敏感度**：玉米每上涨100元/吨，苏氨酸成本增加约250元/吨（高于赖氨酸），对原料波动更敏感
- **中国主导**：华恒生物等专注苏氨酸的企业以技术差异化（厌氧发酵低能耗路线）开辟出细分竞争优势
- **供应链韧性**：与[[蛋氨酸]]不同，苏氨酸发酵的原料（玉米/糖蜜、氨氮）高度本地化，不受海外供应链中断影响
