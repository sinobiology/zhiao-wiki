# 谷氨酸（Glutamic Acid / Glutamate）

## 定义
20种天然氨基酸之一，其钠盐（谷氨酸钠，MSG）即味精，是全球消费量最大的氨基酸。1908年由日本化学家池田菊苗从昆布汤中分离，发现其为"鲜味"（Umami）的化学本质。工业上通过[[谷氨酸棒杆菌]]发酵葡萄糖生产，全球年产量超过350万吨。

## 在知奥体系中的位置
谷氨酸是知奥体系的**历史起点**——[[味之素]]百年史的起源，也是整个氨基酸发酵工业的母领域：

- **历史起点**：1908年池田菊苗发现谷氨酸→1909年味之素商业化→引发此后百年的全球氨基酸产业格局
- **技术演进**：水解法（麦面筋盐酸水解）→1956年直接发酵法（[[协和发酵]]首先实现）→[[谷氨酸棒杆菌]]成为主力工业菌株
- **市场格局**：中国是全球最大生产国，[[梅花生物]]、[[阜丰集团]]双寡头，味精国内均价6000-8000元/吨区间波动
- **专利战场**：[[味之素]]起诉[[梅花生物]]（2025年，2.6亿元）涉及谷氨酸生产核心工艺路线专利
