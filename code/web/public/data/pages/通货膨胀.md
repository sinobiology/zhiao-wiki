# 通货膨胀

## 定义
通货膨胀指货币购买力下降、物价水平普遍持续上涨的经济现象。在知奥体系中，它被视为法币体系的系统性特征，也是驱动资产配置与长期投资决策的核心宏观变量。

## 在知奥体系中的位置
通货膨胀是连接宏观货币政策与个人财富策略的关键节点。在材料中，[[美联储]]通过调节[[联邦基金利率]]直接应对通胀：经济过热时加息抑制通胀，经济过冷时降息刺激经济。[[费雪方程式]] M×V=P×T 则从货币数量论角度解释了通胀的成因——当货币供给量 M 增加而交易总量 T 不变时，物价 P 必然上涨。

在资产配置语境下，通货膨胀被反复强调为持有现金和低收益资产的隐性成本。美国200年资产全景图显示，剔除通胀后股票长期年均实际收益稳定在6.5%-7%，而现金1美元贬至5美分。这使通胀成为从「存钱」转向「建资产」的直接推动力，将[[比特币]]、[[黄金]]、优质股票等资产与抗通胀目标绑定。

通胀还与[[量化宽松]]、[[法币体系]]等概念紧密关联。材料指出，央行量化宽松导致货币供给指数级增长，债务驱动的信用体系必须持续放水，1971年金本位脱钩后法币完全脱离实物约束——这些结构性因素使通胀成为现代信用货币体系的常态化现象，而非偶发事件。

## 关键数据
- 1802-2002年美国200年资产数据：剔除通胀后，股票长期年均实际收益稳定在6.5%-7%
- 200年间现金1美元贬值至5美分，购买力损失95%
- 美元百年购买力从1.00跌至0.05
- 人民币近30年购买力下降约80%
- 2025年9月18日美联储下调联邦基金利率25个基点至4.00%-4.25%，为2024年12月以来首次降息，背景之一是通胀从高点回落、货币政策从紧缩转向宽松
- 费雪方程式 M×V=P×T：M增加而T不变时，P上涨即通胀
