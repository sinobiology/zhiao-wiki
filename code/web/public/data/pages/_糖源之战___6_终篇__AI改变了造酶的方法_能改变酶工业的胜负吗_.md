# AI改变了造酶的方法，能改变酶工业的胜负吗？

## 核心逻辑
- AI真正重写的只是工业酶开发五道关中的“找起点”和“改分子”前两道关，后三道（表达系统、发酵放大、客户验证）一道也绕不过。
- AI越强，候选生成越快，验证通量就越变成整条链的瓶颈——这次瓶颈不在计算机里，在实验台上。
- AI把竞争的重心从“谁拥有更多菌株和试错经验”转移到“谁的设计-构建-测定-反馈回路转得更快”。

## 行业洞察
- 诺和新元真正的护城河不是10万株菌种，而是几十年与客户攒下的“工艺账”——表达系统、客户工艺绑定、批次稳定性记录，AI只能辅助分析，不能替代。
- 百斯杰的AI投入已经反映在毛利表上：耐热植酸酶和高温淀粉酶单品毛利率分别提升7%和6%以上；但毛利率升、亏损也扩，说明AI效率收益尚未覆盖全部成本。
- 换道窗口比看起来窄：前两道关的护城河在变薄，但后三道关的积累只能靠时间和客户熬出来，新进入者难以跨越。

## 技术/管理要点
- AI在酶设计上切了三刀：
  1. **看结构**（AlphaFold）：输入序列输出结构，把结构解析从数月数年压缩到分钟级；边缘是“长什么样”不等于“好不好用”。
  2. **改序列**（ProteinMPNN、ESM-2）：在已知骨架上做组合精修或从序列语言学规律预测有利位点；典型案例是TEV蛋白酶催化效率提高26倍（活性位点被固定）、植酸酶活性提高26倍（不到500个变体、四轮四周）。
  3. **造骨架**（RFdiffusion + LigandMPNN + PLACER）：从零生成自然界不存在的折叠方式；2025年《Science》报道的设计丝氨酸水解酶kcat/Km达到2.2×10⁵ M⁻¹s⁻¹，已落入天然酶催化效率分布范围。
- 工业酶五道关：找起点 → 改分子 → 建表达系统 → 发酵放大 → 客户验证。
- 百斯杰的经营数据：AI多属性优化使阳性率翻倍，最快两轮突变体设计、约150个突变体达标；2026年预计交付6～7个项目，是2025年两倍、2024年三倍；lab-in-the-loop平台将交付周期再缩短20%。

## 金句归纳
> “AI设计的终点，仍然是150个突变体要一个一个做出来、测一遍。机器把‘找到候选’压缩到了几天，但‘验证候选’那一步，一步都没少，而且成了新的卡口。”

> “在屏幕上设计一支酶，比在摇瓶里做出这支酶，便宜太多了。这个差距，才是接下来竞争的真正场地。”
