# 牧原股份

## 定义
牧原股份是中国生猪养殖龙头企业，以“自繁自养”一体化模式为核心，覆盖饲料、育种、养殖、屠宰等环节。它属于农牧养殖行业，是中国饲料和养殖产业组织形态升级的代表性公司。

## 在知奥体系中的位置
牧原股份在知奥体系中主要出现在养殖业组织形态变革的语境中。与[[温氏股份]]的“公司+农户”模式并列，牧原的“自繁自养”模式被视为推动[[精准营养]]数据产业化落地的重要土壤，让“精准减豆”从冒险变为科学减费。

在薪酬讨论中，牧原股份作为民企代表，其董事长[[秦英林]]持有5.2亿股，体现了民企负责人“现金薪酬只是零花钱、股权才是真正财富”的逻辑。它所在的养殖赛道在薪酬梯队中处于中等位置，反映了农牧养殖在市场化薪酬体系中的定价水平。

在氨基酸赛道五年投资压力测试的材料中，牧原股份作为下游养殖环节的代表企业被列入关注标的，与[[梅花生物]]、[[阜丰集团]]等上游氨基酸发酵企业形成产业链上下游关系。
