# 为什么说"有氧"打底，"无氧"续命？｜不同年龄的运动终极答案

## 核心逻辑
- 运动习惯是对一生影响最深远的单一生活方式，曾经锻造的肌肉和体能基础会在未来持续回馈。
- 运动策略应随人生阶段切换：年轻和中年时有氧优先打心肺底座，老年时力量训练优先守肌肉铠甲。
- 运动不是盲目自律，而是基于身体阶段的智慧选择。

## 技术/管理要点
- **有氧运动**（跑步、游泳、骑行）锻炼的是身体核心底座——[[心肺功能]]，管理全身血管和循环系统，是生命健康基石
- **无氧（力量）训练**主要锻炼[[肌肉]]，肌肉是老年人维持行动力、防止跌倒的关键资本
- **年轻/中年策略**：有氧运动重要性远大于无氧，优先打好心肺功能基础
- **老年策略**：力量训练优先级高于有氧，核心目标是守住肌肉、防止[[肌少症]]
- 老年人长时间散步（一两小时）并非最优解，过长有氧反而消耗宝贵肌肉
- 充足的[[蛋白质]]摄入是配合力量训练、促进肌肉生长的必要条件
