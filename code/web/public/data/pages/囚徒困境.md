# 囚徒困境

## 定义
囚徒困境是博弈论中的经典模型，指在特定约束下，每个参与者从自身利益出发做出的“理性”选择，最终导致集体层面的非最优结果。在知奥体系中，它被用来解释寡头市场中的产能过剩、价格战以及国际关系中的对抗升级。

## 在知奥体系中的位置
囚徒困境是知奥ZHAO用于分析行业竞争与战略决策的核心框架之一。在氨基酸发酵行业中，它直接解释了为什么[[缬氨酸]]、[[赖氨酸]]等产品在集中度已高的情况下仍然陷入价格战：[[梅花生物]]、[[阜丰集团]]等头部企业都将“不减产”或“扩产”作为占优策略，最终形成[[纳什均衡]]，集体陷入低利润均衡。

这一概念也与[[影子产能]]、[[柔性产线]]密切相关。由于氨基酸产线可以在不同品种间低成本切换，产能“不消失，只冬眠”，任何短暂的价格回升都会刺激潜伏产能瞬间切回，从而放大了囚徒困境的持续时间，使传统供需出清机制失效。

在国际关系层面，[[达利欧]]的[[大周期理论]]也用囚徒困境解释国家如何“愚蠢地”滑向冲突——双方都怕对方利用自己的退让先下手，最终走向升级。这一机制与[[核威慑]]逻辑并行，说明囚徒困境不仅是市场竞争模型，也是理解宏观秩序失序的工具。

- ADM牵头的全球赖氨酸卡特尔仅维持三年即崩坏
