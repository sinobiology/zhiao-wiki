# 赢创

## 定义
赢创（Evonik）是一家全球性特种化工企业，在饲料级氨基酸领域占据重要地位，尤其以蛋氨酸和赖氨酸等产品闻名。公司属于化工与动物营养交叉领域，是全球蛋氨酸产能高度集中的核心厂商之一。

## 在知奥体系中的位置
赢创在全球[[蛋氨酸]]市场中与[[安迪苏]]、[[新和成]]、[[诺伟司]]、[[住友化学]]并列为产能高度集中的头部企业，其生产基地主要集中在欧洲和亚洲（新加坡），原料高度依赖中东石化链，这使其在[[霍尔木兹海峡]]地缘冲突中面临结构性供应脆弱。在2026年氨基酸涨价周期中，赢创因原料断供风险实施固蛋提价10%，成为成本传导链条上的关键节点。

在[[赖氨酸]]领域，赢创的角色更为复杂。它曾与美国[[ADM]]、[[CJ集团]]旗下CJ Bio America共同组成「赖氨酸公平贸易联盟」，于2026年7月推动美国商务部对中国产L-赖氨酸作出反倾销和反补贴肯定性终裁。这一举动是跨国巨头从成本竞争转向规则竞争的典型样本——当无法在成本曲线上与中国企业对抗时，赢创选择诉诸贸易保护。与此同时，赢创也在收缩自身赖氨酸品类，2024年底实施业务精简，显示其在大宗氨基酸领域逐步退守的战略姿态。

从更长周期看，赢创是[[味之素]]、[[希杰]]、[[梅花生物]]、[[阜丰集团]]等围绕赖氨酸白色粉末展开半世纪角逐的全球巨头之一，在这场从日本起步、经欧美放大、最终由中国产能重构的产业迁移中，它代表了欧美化工资本在发酵氨基酸领域的传统力量。

## 关键数据
- 赢创在2026年地缘冲突引发的氨基酸涨价中，对固体蛋氨酸提价10%
- 赢创与ADM、CJ Bio America共同组成「赖氨酸公平贸易联盟」，作为2026年美国对华赖氨酸双反调查的申请方
- 赢创的美国赖氨酸生产基地设于内布拉斯加州布莱尔
- 赢创于2024年底实施赖氨酸业务精简
- 材料中提及赢创为全球蛋氨酸产能CR5超80%的核心厂商之一
- 材料中提及2024年11月中石化与新和成建成全球最大单套液体蛋氨酸装置，蛋氨酸产能格局中赢创仍属主要化工法阵营
