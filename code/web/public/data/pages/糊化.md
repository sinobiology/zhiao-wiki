# 糊化

## 定义
糊化是淀粉制糖和淀粉加工中的物理前提步骤：通过加水加热，使淀粉颗粒吸水膨胀、破坏半结晶结构，让蜷缩的分子链进入水相伸展。它属于淀粉深加工与工业酶法转化领域。

## 在知奥体系中的位置
糊化是[[液化]]阶段的物理任务，与[[α-淀粉酶]]的化学切断共同构成液化双任务。在[[糖源之战II系列]]的叙事中，糊化解决「酶进不去」的问题，[[液化]]解决「料液流不动」，[[糖化]]才解决「葡萄糖放不出来」。

糊化是[[喷射液化器]]要处理的第一次剧烈物性变化：淀粉乳从颗粒悬浮体系转变为糊化并开始水解的高分子溶液。1942 年托马斯·肖克的[[直链淀粉]]与[[支链淀粉]]分离方法，也正是利用加热条件下糊化淀粉与正丁醇接触后冷却的分步沉淀差异。

糊化暴露了淀粉制糖工业的核心矛盾：糊化需要 >95°C，而传统中温[[α-淀粉酶]]活性在 <70°C 才能维持。这一「高温与生命不可兼得」的矛盾，直接推动了[[耐高温淀粉酶]]和喷射液化工艺的出现。

## 关键数据
- 糊化需要 >95°C；工业经典工艺在 105–110°C 经历数分钟热处理，随后迅速降到约 95°C 完成液化。
- 温度不足时，未拆封的淀粉颗粒会残留并直接报废。
- 淀粉主链由 α-1,4 糖苷键构成约 95%，α-1,6 糖苷键形成约 5% 的分支点。
- 直链淀粉占比约 25–30%，支链淀粉占比约 70–75%。
- 液化目标通常为 DE 10–20。
- 1942 年美国玉米产品精炼公司的托马斯·肖克利用糊化淀粉分离直链与支链组分。
