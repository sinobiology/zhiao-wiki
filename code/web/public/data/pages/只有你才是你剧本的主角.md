# 只有你才是你剧本的主角

## 核心逻辑
- 你以为别人时刻关注你的生活，实际上你只是别人信息流里偶尔刷到的一个片段——没有人真正在乎你。
- 你的生活在自己眼里是连续剧，在别人眼里只有高光或狼狈的切面。
- 不必为别人活着，不必向别人证明什么，为自己负责、为自己而活，因为只有你才是你剧本的主角。

## 技术/管理要点
- 公众号运营者容易陷入"自我中心偏差"：精心经营的内容，对读者而言只是可有可无的调剂
- 日更与周更对大多数读者无感知差异，内容只在被算法推荐时才偶尔触达
- 认清"别人不在乎你"这一事实，反而能释放心理压力，回归内容创作本身
