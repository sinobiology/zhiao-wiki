# 私钥

## 定义
私钥是比特币等加密货币体系中用于证明资产控制权的核心秘密数据，通常是一个符合 secp256k1 规则的 256 位随机数。它属于密码学与去中心化资产安全领域，是用户对比特币行使排他性处置能力的唯一凭证。

## 在知奥体系中的位置
在知奥的比特币认知体系中，私钥被反复强调为“所有权的本质”。[[比特币]] 的文章指出，拥有比特币不是拥有交易所余额或虚拟硬币，而是拥有由私钥带来的绝对控制权。[[冷钱包]]、[[硬件钱包]] 和 [[脑钱包]] 都是围绕私钥生命周期管理展开的保管方案，材料中明确区分了三者在抗审查性、持久性和安全性上的差异。

私钥与 [[UTXO]] 模型直接相关：链上并不登记“谁拥有多少币”，私钥只是网络用于验证签名的那把“钥匙”。在 [[Crypto]] 与 [[AI Agent]] 的讨论中，私钥被提升为区分法币体系与加密体系的结构性门槛——法币体系为有身份的人设计，Crypto 为有私钥的逻辑设计。因此私钥不仅是一个技术组件，更是知奥体系中理解[[去中心化]]控制权、[[控制权]]与[[抗审查]]能力的枢纽概念。

## 关键数据
- 私钥是符合 secp256k1 规则的 256 bit 随机数，可以用骰子离线生成
- 重复概率接近于零，无法通过地址反推
- 私钥丢失则资产永久不可恢复
- BIP39 助记词中，12 词对应 128 bit 熵 + 4 bit 校验，24 词对应 256 bit 熵 + 8 bit 校验
- 私钥不是网络发出的账户凭证，而是用户自己创造的随机数
- 硬件钱包的核心价值被视为管理私钥的完整生命周期：生成、保存、派生、签名
- 材料提到“私钥在手，天下我有。丢了私钥，神仙也救不了”
