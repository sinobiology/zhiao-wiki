# 提示词工程

## 定义
提示词工程是设计、优化与结构化描述输入内容，以引导大语言模型或图像模型产出高质量结果的方法论。它属于 AI 应用技术领域，核心在于通过明确的任务定义、约束条件与结构框架，将人的意图高效转化为模型可执行的指令。

## 在知奥体系中的位置
在知奥的文章体系中，提示词工程是 [[人机协作]] 的关键技术支撑。材料1《氨基酸进化》系列创作手记把"会提问题、会定义任务"视为 AI 时代写作的核心能力，这直接指向提示词的策划与系统设计，而非简单使用工具。材料2《别被AI喂养》进一步提出"不要试图自己成为提示词专家，直接问 AI：'如何像专家一样使用你？'"，体现出对提示词工程的递归式应用思路。

在具体应用层面，材料3《用 AI 拆解万物》展示了 [[结构化提示词]] 的完整范例——固定视角、纯色背景、分层漂浮、双语标注等要素共同构成可复用模板，并借助 [[Gemini]] 的 [[Nano Banana Pro]] 模型生成解构式图像。这与 [[AI图像生成]] 和 [[解构式可视化]] 直接关联，证明了提示词工程不仅服务于文本生成，也延伸至视觉知识表达。

提示词工程还与 [[ChatGPT]]、[[认知卸载]] 等概念相互关联。材料中强调的"四阶段创作流程""递归法用 AI"等方法，本质上是把提示词作为系统级接口，让人把精力留给判断与取舍，而非重复性劳动。

## 关键数据
- 材料1提出四阶段创作流程：策划 → 深度调研 → 人工校准 → 风格转化
- 材料1采用两个大模型（ChatGPT 与 Gemini）做同题调研实现交叉验证
- 材料2提出"四象限精力分配模型"，其中"AI解放区"建议"狠狠用 AI，付费用 AI"
- 材料2提到递归法万能模板："请将以下提示词改良为最好的版本：[你的问题]"
- 材料3的提示词框架要素包括：45°商业摄影视角、纯黑背景、多层自由漂浮、统一戏剧性光线、中英双语标注、底层放置成品
- 材料3使用的模型为 Gemini 的 Nano Banana Pro
