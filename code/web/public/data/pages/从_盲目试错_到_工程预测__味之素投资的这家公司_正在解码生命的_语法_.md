# 从"盲目试错"到"工程预测"：味之素投资的这家公司，正在解码生命的"语法"

## 核心逻辑
- Cellular Intelligence（原 Somite AI）构建了首个通用虚拟细胞信号基础模型，用 Transformer 架构学习 f(初始细胞状态, 信号序列) → 未来细胞状态，将细胞命运调控从"手艺活"变为"预测工程"。
- 自研胶囊微流控平台实现百万级信号组合实验，数据获取速度比传统方法快 1000 倍，配合主动学习闭环持续提升模型精度。
- 该技术在氨基酸发酵领域的价值不在于替代底盘改造（造车），而在于通过信号控制实现工艺极限优化（训练赛车手），两者深度协同才是通往物理极限的路径。

## 行业洞察
- [[味之素]]参投 A 轮释放明确信号：发酵工业巨头已开始押注"AI 驱动的过程控制"作为下一代竞争力。
- 生物制造下半场竞争维度从单一的"底盘构建能力"升级为"底盘构建 + 过程系统能力"的深度融合。
- 掌握"海量动态数据 + 预测模型"的公司将在碳中和与成本战博弈中占据先机，数据成为核心工业资产。

## 技术/管理要点
- **基础模型架构**：采用 Transformer 深度学习架构建模细胞信号序列，类比 GPT 学习语言语法的方式学习细胞的"信号语法"
- **胶囊微流控平台**：从早期 2.7 万种信号组合扩展至超过 100 万种顺序刺激条件，数据获取效率提升 1000 倍
- **主动学习闭环**：模型对不确定区域自动指挥微流控平台补做实验，边训练边实验持续迭代
- **Neural ODEs 架构**：支持动态时序控制，可在精确时间点调节温度、诱导剂浓度等参数，解决生长与合成阶段冲突
- **发酵应用路径**：代谢工程（内部布线）决定产量上限，CI 信号控制（外部驾驶）决定上限兑现程度
- **闭环进化范式**："以车定人"——用模型为已有底盘找最优驾驶策略；"以人促车"——用模型推演极端工况反向指导底盘加固设计
- **局限性**：野生型细菌无"天然潜能"过量产酸，传统代谢工程（敲除旁路、过表达合成酶）仍是不可绕过的第一步
