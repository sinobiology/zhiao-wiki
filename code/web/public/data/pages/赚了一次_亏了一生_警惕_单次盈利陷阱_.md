# 赚了一次，亏了一生：警惕'单次盈利陷阱'

## 核心逻辑
- 最大的风险不是亏了一次，而是"第一次赚了"——成功给你发了一张假文凭，上面写着"你懂了"。
- 牛市里的投资者就是庄子说的"夏虫不可语冰"——没见过冬天，你跟它说冰它不会信。
- 真正毁灭一个人的不是失败，而是第一次成功带来的路径依赖和自信膨胀。

## 行业洞察
- **牛顿南海公司案例**：1720年，牛顿第一次抛售南海公司股票赚了7000英镑（大半辈子积蓄），然后看到股价继续涨，以高出两倍价格全仓杀入，泡沫破裂后亏了20000英镑（约300万英镑）。他说："我能计算天体的运动，却算不出人类的疯狂。"
- **中国地产行业**：连续二三十年只涨不跌，连行业自己都信了，结果全行业齐刷刷倒下——是同一类"夏虫"结构。
- **"单次盈利陷阱"的核心结构**：第一次成功→发"我懂了"假文凭→拿着去All in→每一扇门都推得开因为自己信了→然后归零。

## 技术/管理要点
- 打破"单次盈利陷阱"的关键是保持对"运气 vs 能力"的清醒区分——一次成功不能证明方法论正确，只是统计样本中的一次。
- 投资中避免路径依赖的最佳方法是写交易日志，记录每笔决策的逻辑，事后复盘"我当时为什么觉得我懂了"。

## 金句归纳
> "赚了一次的人，都觉得自己懂了。而这句话，就是整个陷阱的入口。"

> "不是他不懂数学。是他没算到后面那个变量——他自己。"
