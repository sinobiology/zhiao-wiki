# 认知偏差

## 定义
认知偏差是指人在判断、评价自身或外部事物时，因缺乏足够信息、实践经验或元认知能力而产生的系统性失真。它广泛存在于自我能力评估、职场价值判断、对他人成就的理解等领域，是认知心理学与行为科学的核心概念。

## 在知奥体系中的位置
认知偏差在库中主要作为底层认知框架出现，连接多个具体概念。在《只有达到相似水平，才会由衷敬佩一个人》中，它与[[达克效应]]、[[刻意练习]]、[[共情能力]]并列，指向“未入局者容易低估他人成就”这一评价失真；在《我爸说得对：要像驴一样，不但会干活，还得会叫》中，它被用来描述职场中将“实干vs溜须”视为二元对立的错误认知，并与[[PIE模型]]、[[向上管理]]、[[个人品牌]]等概念关联；在《越弱越牛逼，越强越谦虚？》中，它直接关联[[邓宁-克鲁格效应]]、[[自我认知]]、[[元认知]]、[[反图书馆]]，是理解“低认知者高估自己、高认知者保持谦虚”现象的总纲。

这些文章共同揭示：认知偏差的矫正通常依赖[[实践祛魅]]、主动寻求负面反馈、以及将个人价值与观点分离。它不是一个孤立概念，而是贯穿个人成长与职场发展的底层障碍。
