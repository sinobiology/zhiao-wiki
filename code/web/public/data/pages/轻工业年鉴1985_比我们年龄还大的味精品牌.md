# 轻工业年鉴1985：比我们年龄还大的味精品牌

## 核心逻辑
- 1965年味精生产从"水解法"升级为"发酵法"，原料消耗从30吨小麦产1吨味精骤降至6吨，是味精走进千家万户的关键技术革命。
- 1983年中国味精年产量已达6.1万吨，年出口约2000吨销往新加坡、法国、澳大利亚等国，老国货在40年前就已具备国际竞争力。
- 红梅牌、双桥牌等品牌早在1979年就斩获国家级金质奖章，是当年的"顶流国货"，其品牌生命力远超多数人认知。

## 行业洞察
- 1983年味精行业已形成明确的头部格局：[[沈阳味精厂]]以4800吨/年产能稳居行业第一。
- 味精出口在1980年代初已形成稳定渠道，年出口量约2000吨，覆盖东南亚和欧澳市场，说明中国发酵工业的国际化起步远早于大众认知。
- 品牌延伸已有雏形：红梅品牌同时覆盖味精和麦乳精品类，双桥品牌在广州深耕味精市场，区域品牌格局在计划经济时代就已成型。

## 技术/管理要点
- **水解法（1965年前）**：以小麦面筋和大豆粕为原料，约30吨小麦才能生产1吨味精，成本极高，产量受限
- **发酵法（1965年后）**：原料消耗降至约6吨产1吨味精，成本大幅下降，产能释放，是味精产业规模化的技术拐点
- 1979年国家轻工产品金质奖章评选机制，是早期国货品质认证体系的重要组成部分
- [[沈阳味精厂]]同时拥有味精和咖啡厂（生产麦乳精），体现了当时轻工企业多品类经营的产业组织模式
