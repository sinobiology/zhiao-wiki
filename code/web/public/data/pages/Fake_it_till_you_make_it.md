# Fake it till you make it

## 核心逻辑
- 你想成为什么，不要等准备好了再开始；先开始，你就已经在成为。
- "Fake it till you make it"不是假装厉害，而是先以目标身份做事：持续输出、持续迭代、持续校准。
- 实现目标的最短路径往往不是获取某个资格，而是直接去做那件事本身。

## 技术/管理要点
- 职业规划三段论：
  - 第一段：刚出社会，去最能锻炼人的地方，不计较得失
  - 第二段：有能力后，去薪资待遇最好的地方，快速积累资本
  - 第三段：走到一定阶段，做最能体现价值的事，把经历和所学传给需要的人
- 知识输出不必依赖体制身份（如高校编制），公开写作本身就是"成为老师"的方式
