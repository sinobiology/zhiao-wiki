# API

## 定义
API（Application Programming Interface）是应用程序编程接口，指软件系统之间进行数据交换和功能调用的标准化通道。在知奥体系中，API 同时出现在两个截然不同的语境中：一是 AI 工具链中的编程接口，二是医药行业中的原料药（Active Pharmaceutical Ingredient）。

## 在知奥体系中的位置
在 AI 与编程语境下，API 是连接大模型能力与具体生产流程的底层通道。[[Claude]] 等模型通过 API 被嵌入到 [[Python]] 脚本和流水线中，使 AI 从“对话界面”转入“生产模式”。[[OpenClaw]] 的诞生正是基于对这一层的突破——传统 AI 只能通过 API“用嘴皮子工作”，而 OpenClaw 则进一步获得系统级执行权限，走向 [[AI Agent]] 的执行层入口。

在医药语境下，API 指原料药，是药物制剂中的核心活性成分，与 [[cGMP]]、[[DMF]] 等质量管理体系直接相关，处于创新药研发与供应链的关键位置。两种含义在知奥库中并存，体现了跨领域知识图谱的典型特征。
