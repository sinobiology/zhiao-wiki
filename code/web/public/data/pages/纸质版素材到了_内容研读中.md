# 纸质版素材到了，内容研读中

## 核心逻辑
- 本文为"赖氨酸战争"系列第六篇的预告，聚焦2014—2024年间赖氨酸行业的格局重塑，核心线索是"新王登基"与"群雄逐鹿"
- 系列文章完整复盘了全球赖氨酸产业从日美垄断、中国崛起、国际贸易战到帝国陨落的全周期演变
- 2014—2024年间，猪瘟冲击叠加行业洗牌，赖氨酸产业竞争格局被彻底重塑

## 行业洞察
- 全球赖氨酸产业经历了从日美合谋定价（卡特尔分赃）→ 中国企业（大成生化）依托吉林玉米带资源优势崛起为全球第一 → 遭遇美国337调查与欧洲市场滑铁卢 → 大成生化财务轨迹恶化直至帝国陨落的完整产业周期
- 2014年后进入新阶段：猪瘟对下游饲料需求的冲击成为行业洗牌的外部催化剂，新的产业王者在此轮洗礼中诞生
- 赖氨酸作为饲料添加剂的核心品种，其产业竞争史折射出中国精细化工/生物发酵行业从追赶到超越再到内部整合的典型路径
