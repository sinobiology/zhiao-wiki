# 那些让人醍醐灌顶的图片·投资篇第6期——巴菲特的财富增长图

## 核心逻辑
- 巴菲特99%的财富来自50岁之后，财富增长的本质不是智商或技巧，而是"复利+时间"的指数效应。
- 复利公式（本金×(1+利率)^时间）中，时间是唯一对所有人公平的变量，也是普通人最大的杠杆。
- 复利最大的敌人是归零（追高踩坑），而非低收益；耐心是普通人唯一可靠的竞争力。

## 行业洞察
- 投资领域中，市场长期只奖励耐心者而非聪明人，短期暴富心态是复利的最大障碍。
- 普通人与富人之间，本金和收益率存在天然差距，但时间维度是唯一真正公平的竞争要素。

## 技术/管理要点
- **复利三要素拆解**：
  - **本金**：通过提升能力增加收入、克制欲望减少支出来积累，收入增长但支出同步增长等于无效积累
  - **收益率**：核心不是追求高收益，而是通过学习、阅读、提升认知来远离骗局，避免归零风险
  - **时间**：越早开始、越稳住不卖，越能触发指数级爆发；头几年无感，十年后惊为天人
- **复利难以坚持的原因**：前期增长极慢，与当下"30分钟外卖送达、3天财富翻倍"的即时满足文化相悖
- **普通人行动路径**：不拼背景智商，不求暴富，坚持长期持有，让时间站在自己这一边
