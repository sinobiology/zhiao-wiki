# 财富资产

## 定义
财富资产是「人生复利飞轮」体系中四种核心资产之一，指个人拥有的可投资资源与财富缓冲。它的核心意义不在于购买力，而在于把认知转化为选择权、把资源转化为时间和自由。

## 在知奥体系中的位置
财富资产与 [[认知资产]]、[[健康资产]]、[[关系资产]] 共同构成 [[人生复利飞轮]] 的四大支柱。在分工上，认知决定方向，财富提供资源，健康延长复利时间，关系放大复利效应。财富资产不是孤立目标，而是系统经营的一环。

在具体路径上，财富资产的积累与 [[财富阶梯]] 的层级框架密切相关——只有先清楚自己站在哪一级，才能判断哪些理财建议真正适用于自己。[[长期主义]] 是贯穿财富资产经营的基本立场，没有财富缓冲的人容易被短期压力裹挟。

## 关键数据
- 财富阶梯按净资产分六级，相邻两级差 10 倍，从 Level 1（<1 万美元）到 Level 6（>1 亿美元）。
- 美国收入最低 20% 人群的必需消费支出已超过税后收入的 100%，处于 Level 1 时几乎没有可节省空间。
- 财富资产的意义被概括为「买时间」而非买东西，本质是选择权。
