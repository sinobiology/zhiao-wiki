# ABF（Ajinomoto Build-up Film，味之素积层膜）

## 定义
用于高性能处理器封装基板（FC-BGA）的核心绝缘材料，每层厚度约10微米（约头发丝的1/8）。由[[味之素]]精细技术公司（AFT）研发生产，1999年开始量产，全球市占率约95%，是AI服务器和数据中心芯片封装不可或缺的材料。

## 在知奥体系中的位置
ABF是知奥体系中"**副产物变成核心资产**"和"**认证曲线 vs 成本曲线**"命题的极致案例：

- **来源**：1990年代，[[味之素]]味精生产副产物（含氯中间体）→开发树脂材料→磷酸酯路线→环氧固化剂路线→三路汇聚成ABF（1999年）
- **关键时刻**：1996年芯片厂商主动找上味之素（4个月出原型）；1998年项目差点被砍；1999年量产；2010年代确立全球垄断格局；2023年AI算力爆发→ABF需求暴增
- **四层壁垒**：工艺复杂度 + 客户深度绑定（从设计阶段介入）+ 2-3年认证壁垒 + 专利网络
- **对行业的启示**：ABF的战略价值在于它早于需求出现几十年就埋下了根——1990年代对副产物的技术追问，在2023年AI时代兑现。"成本曲线会被追平，认证曲线把时间变成壁垒"
