# 一个地球，十万个地球：人类是选择做园丁，还是做星舰文明？

## 核心逻辑
- 人类文明是一个"早产儿"，在上世纪太空黄金时代刚迈出摇篮就缩回了脚，从"走出摇篮"的豪情退化为"在摇篮里过得更舒服"的算计。
- 环境保护被视为文明唯一出路，但其技术难度和成本实际上比太空探索更高，而上限却肉眼可见——我们正为"芝麻"放弃"西瓜"。
- 资源的瓶颈本质上是科技的瓶颈：一种物质算不算资源，不取决于存量，而取决于我们有没有驾驭它的科技。

## 行业洞察
- 全球70亿人若要达到欧美生活水平，需要4.5个地球的资源，在现有模式下是无解死结，唯有向太空索取增量资源才能打破天花板。
- 环保投入与太空探索投入严重失衡（中国"十二五"环保超3万亿 vs 太空仅300亿），反映出人类文明整体的战略短视。
- 太空中蕴含相当于十万个地球的资源，一个能进行星际采矿的文明，其解决地球环境问题的能力远超画地为牢的文明。

## 技术/管理要点
- **文明早产儿隐喻**：人类顶着原始人的大脑和本能闯进原子能与信息时代，认知能力与技术能力严重不匹配
- **环保的"上帝级"工程本质**：真正稳住地球生态需要太空遮阳伞（300万平方公里）、全球海洋蒸发站等，技术奇幻程度远超登陆火星
- **资源的信息论本质**：人类所需资源绝大多数只是已有元素的不同排列组合，关键不在物质存量，而在排列组合的技术（信息）
- **两种文明路径对比**：
  - [[园丁文明]]：向内卷曲、风险高度集中，能维持但经不起风浪
  - [[星舰文明]]：外向发散、充满风险但拥有无限可能性
- **西蒙定律的启示**：几乎所有资源的价格长期下降，不是矿变多了，而是技术让开采和利用效率持续提升
