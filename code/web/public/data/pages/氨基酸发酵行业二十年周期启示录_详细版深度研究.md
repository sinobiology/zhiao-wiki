# 氨基酸发酵行业二十年周期启示录：详细版深度研究

## 核心逻辑
- 氨基酸发酵行业周期性的根本矛盾是**供给端的爆发式集中释放与需求端的渐进式线性增长之间的时间错配**，反复上演"价格上涨→企业扩产→产能滞后释放→价格下跌→整合出清→新一轮上涨"的循环。
- 中国企业已占据全球饲用氨基酸产能主导地位（2023年产量约433万吨，占全球70%），行业格局从分散走向寡头集中，头部企业凭借成本和规模优势主导供给节奏。
- 每轮低谷都是行业出清的契机，落后产能退出后龙头集中度持续提升（赖氨酸前三集中度从48%回升至50%+，苏氨酸前三达84%），未来周期波动幅度有望收窄。

## 行业洞察
- 赖氨酸行业20年内经历至少三轮完整的"扩张-过剩-出清"周期（2010-2015、2016-2020、2021-2023），每轮周期约4-5年。
- 新建产能从立项到投产需1-2年的滞后期，这一投资滞后效应是供需错配的结构性根源。
- 中国厂商的大举扩张逐步淘汰了许多海外竞争者，全球产能重心已从日本、韩国、欧美转移至中国。
- 苏氨酸行业集中度始终高于赖氨酸，2020年前三家份额达84%，呈现更明显的寡头格局。
- 龙头企业在低谷期仍逆势扩产抢占份额（如星湖科技2022年收购伊品80万吨赖氨酸产能），"以量换价"加速尾部出清。

## 技术/管理要点
- **饲料四大氨基酸**：赖氨酸（猪第一限制性）、蛋氨酸（禽第一限制性）、苏氨酸（猪第三限制性）、色氨酸（猪第四限制性），缬氨酸为新兴第五大品种
- **产能周期关键节点**：
  - 2013年：全球赖氨酸产能峰值，厂商数量最多，前三集中度降至56%
  - 2014-2015年：总产能从368万吨降至320万吨，首轮大规模出清
  - 2018年：产能反弹至389万吨，前三集中度降至48%
  - 2019-2020年：第二轮出清，前三集中度回升至50%
  - 2022年：落后产能基本出清完毕
- **龙头扩产路径**：梅花生物（新疆→吉林白城60万吨新项目）、阜丰集团（齐齐哈尔20万吨+技改12万吨）、星湖科技（收购伊品80万吨）
- **国际并购趋势**：梅花生物2024年收购日本协和发酵资产，获取高附加值医药级氨基酸产品线
- **成本竞争力**是穿越周期的核心壁垒，华恒生物以合成生物技术切入小品种氨基酸实现差异化
