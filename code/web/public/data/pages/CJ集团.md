# CJ集团（CJ CheilJedang Corp.）

## 定义
韩国最大的食品与生物制造集团之一，旗下CJ Bio是全球最大饲料氨基酸生产商之一。主要产品涵盖赖氨酸、苏氨酸、色氨酸、缬氨酸，全球布局在印度尼西亚、巴西、欧洲、中国等多地设有产能。

## 在知奥体系中的位置
CJ集团代表亚洲氨基酸产业**成本曲线vs认证曲线**分岔路的另一端：

- **市场扩张**：2010年代依托大规模产能和成本优势快速蚕食[[味之素]]在色氨酸、味精市场份额，成为后者最强挑战者
- **专利战被告**：2016-2023年，[[味之素]]在美、德、日三地对CJ发起6年专利战（涉及L-色氨酸和MSG生产工艺专利），CJ采取"菌株迭代+绕道设计"策略，最终支付和解金结案
- **2025年战略分化**：赖氨酸/苏氨酸/色氨酸价格战+产能过剩，CJ Bio 2025年Q4营业利润同比跌99.1%，几乎归零；对比[[味之素]]同期利润增长91.6%，成为[[成本曲线]]vs[[认证曲线]]两种路径分化的最鲜明案例
- **三轨转型**：绿色（大宗氨基酸）+白色（PHA生物可降解材料）+红色（营养食品），方向正确但调头需要时间
