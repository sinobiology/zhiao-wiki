# 根据卡帕西的建议，我把前天的文章做成了视频

## 核心逻辑
- 卡帕西提出理解 AI 输出的四级阶梯：受控文字 → 画图 → 网页 → 视频，其中视频一级已"开始跑通"。
- AI 越强，人的工作越向上迁移为"监督"和"理解"——判断"要不要"而非"怎么做"。
- 形式越漂亮越有说服力，但核实永远是人自己的事。

## 行业洞察
- 内容生产正从"一句话生成视频"转向"AI 写程序、逐帧渲染"的精确路线——文字、数字、公式完全可控，改一行即可迭代，成本近零。
- "又大又定制、看完就扔"的内容成为新常态：以前不值得做的单人定制视频，现在用一天就能产出。
- 工具链已经便宜到可以全部跑在本地笔记本上，一分钱不花。

## 技术/管理要点
- 文字层：用 ASD-STE100 受控语言（一句一件事、操作句≤20词、主动语态、一词一义），可折中做到 80%。
- 视频生成链路：拆文章为集 → 拆集为旁白句 → 配音并测时长 → 按时长定帧停滞 → 程序逐帧绘制 → 渲染拼接 → 对齐音画。
- 量化"别扭"：AI 写脚本量每一段文字的容器边界，溢出则报错；音频按停顿切分，数每节字数/秒，发现语速不均在 3.3~7.7 字/秒之间波动。
- 工具不可盲信：检查脚本本身会漏检（只查中心点是否在框内），规则错了查一百遍也白查。
- 改"呼吸"不改内容：旁白语速不均是标点问题，在"计发系数"后加逗号、改句号，语速即摊平。
- 审美判断是人兜底：AI 两轮迭代解决"箭头不穿行"，正确答案却是"去掉箭头"——"要不要"它答不了。
