# 为什么正确的事，总是很难坚持？

## 核心逻辑
- 正确的事难以坚持，是因为其**成本发生在今天，收益却属于未来**；突破原则的风险是隐性的，而坚守原则的代价是显性的。
- **难，不能证明正确**。真正的坚持不是重复同一做法，而是守住方向的同时，用阶段性证据不断修正路径。
- 清醒的坚持必须区分"正确的低谷"与"错误的深渊"，核心是**守住未来的选择权**，节奏可以调整，原则不能失守。

## 行业洞察
- 工业技术领域存在"快与慢"两条路：引进成熟技术短期指标占优但丧失底层积累；自主开发成本高、见效慢，却沉淀了数据、方法与迭代能力。
- 企业用当下结果评价面向未来的决定，是长期主义在组织层面难以落地的根本原因——成功叫战略眼光，未成功叫低效固执。
- 新和成、比亚迪的案例表明，长期主义的兑现往往发生在外部环境最恶化、质疑声最大的时期之后。

## 技术/管理要点
- **成本与风险的不对称**：坚持原则的成本可以精确计算，但避免的知识产权纠纷、技术断供、市场准入障碍"看起来价值为零"。
- **定投悖论**：越容易坚持的定投优势越小；越能体现定投优势的过程越难坚持。熊市负责积累，牛市负责结算。
- **检验坚持的三个问题**：
  1. 如果今天从零开始，我还会选择这条路吗？
  2. 与一年前相比，出现了哪些支持继续坚持的新证据？
  3. 如果哪些情况发生，我愿意承认原来的判断已经错了？
- **长期主义与短期利益并非二选一**：可以调节奏、砍项目、集中资源，但绝不能交出"将来很难赎回的能力"。
