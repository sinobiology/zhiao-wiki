# 谷氨酸棒状杆菌

## 定义
谷氨酸棒状杆菌是一类用于氨基酸工业化发酵生产的核心微生物菌株，属于工业微生物与发酵工程领域。它于1956年被发现，是味精和赖氨酸等氨基酸大规模生产的关键生物催化剂。

## 在知奥体系中的位置
谷氨酸棒状杆菌是知奥体系中连接[[味精]]、[[赖氨酸]]与[[发酵工程]]的技术枢纽。材料显示，它的发现直接开启了[[协和发酵]]在1958年建立赖氨酸发酵工艺，并支撑了[[味之素]]等企业构建"菌株改良+发酵控制+提取纯化+专利布局"的系统性工业壁垒。

在[[味精]]工业史中，谷氨酸棒状杆菌关联[[微生物发酵]]对水解法的替代革命，以及[[生物素限制诱导]]这一核心控制原理——生物素缺乏导致细胞膜结构松弛、谷氨酸外排，使氨基酸得以在发酵液中积累。它同时出现在[[氨基酸]]、[[缬氨酸]]、[[大肠杆菌]]等实体构成的技术网络中，代表工业氨基酸生产的基础底盘菌株。
