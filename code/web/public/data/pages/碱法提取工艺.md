# 碱法提取工艺

## 定义
碱法提取工艺是早期玉米淀粉加工中用于分离淀粉与蛋白质的一种化学方法，属于淀粉工业中的湿法工艺路线。它利用强碱攻击并水解蛋白质长链，使淀粉得以分离，但其代价是破坏了玉米中除淀粉以外的大部分副产物价值。

## 在知奥体系中的位置
碱法提取工艺是[[糖源之战系列]]中玉米加工技术演进的关键一环。它与[[亚硫酸浸泡]]形成直接对比：碱法完成了淀粉分离，却破坏了蛋白质、胚芽等组分的可利用性，因此被后来的[[玉米湿法工艺]]逐步取代。

在产业逻辑上，碱法只满足[[工业闭环]]的第一条判断标准——主产品淀粉有规模化市场；但蛋白进入废水、胚芽无法分离、副产品链条全断，连闭环入口都没有。这与[[亚硫酸浸泡]]三条全通的商业模型形成鲜明对照，解释了为什么碱法最终输给了亚硫酸法。

该工艺与[[托马斯·金斯福德]]所开创的产业化路径相关，但在玉米加工体系中，它代表的是「只取淀粉」的旧工业眼光，而非后来「全组分利用」的新观念。

## 关键数据
- 碱法时代早期工厂玉米非淀粉组分（蛋白、油脂、可溶性成分）损失高达 60%
- 20 世纪初碱法体系一度控制全美 84% 淀粉市场份额
- 碱法在工业闭环中仅满足主产品有规模化市场这一条标准
- 亚硫酸湿磨成熟后总损失降至约 1%–5%，作为碱法时代的对照数据
