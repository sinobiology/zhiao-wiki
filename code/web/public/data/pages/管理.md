# 管理

## 核心逻辑
- 管理的本质不是情绪化的控制（呐喊、骂人、忧虑、苦撑），而是理性的系统运作：整合资源、分解任务、监督落实、持续改进。
- 管理的最高境界是"无事可管"——系统自运转，管理者从执行层抽身。

## 技术/管理要点
- 管理四步法：
  - **整合资源**：将人、财、物等要素合理配置
  - **分解任务**：将目标拆解为可执行的颗粒度
  - **监督落实**：跟踪执行过程，确保交付
  - **持续改进**：形成闭环反馈，不断优化
- 管理的反面模式（需避免）：
  - 声嘶力竭的呐喊——靠音量而非制度
  - 气急败坏的骂人——靠情绪而非方法
  - 愁眉不展的忧虑——靠焦虑而非行动
  - 殚精竭虑的苦撑——靠个人而非体系
