# 实力决定心态

## 核心逻辑
- 决定投资成败的是"持续的场外赚钱能力"，而不是投资技巧。
- 转移注意力不能解决投资焦虑，唯一的办法是让投资这件事对你"无关紧要"。
- 赚钱能力增强后，投资变成数字游戏，不再是生死存亡的问题，心态自然稳定。

## 技术/管理要点
- 投资焦虑的根源不是心理问题，而是实力问题——投入资金占总资产/收入比例过高
- 解决路径：提升场外赚钱能力 → 投资资金占比下降 → 投资成败不影响生活质量 → 心态自然平和
- "无限子弹"思维：当你有持续的收入来源，单次投资的得失就不再致命
