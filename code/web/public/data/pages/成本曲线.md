# 成本曲线

## 定义
将行业内所有生产者按单位生产成本从低到高排列，形成的曲线。在氨基酸发酵行业，成本曲线的位置决定了一家企业在价格战中能撑多久——曲线越靠左（成本越低），在价格下跌时生存空间越大。

## 在知奥体系中的位置
成本曲线是知奥体系的**竞争分析框架**核心，与其他概念关系：

- **驱动因素**：规模（[[规模效应]]）、菌株转化率（[[菌种工程]]）、原料成本（玉米/糖蜜价格）、能耗水平
- **降本路径**（成本决胜系列）：规模→能效→工程降耗→原料替代→碳能解偶联→sCO2能源革命
- **与[[规模效应]]的区别**：规模效应是成本曲线左移的一种机制；成本曲线是对整个行业竞争格局的描述框架
- **成本曲线的天花板**：当所有头部企业都做到极致降本，曲线的最低点趋向边际成本，行业整体利润消失。此时唯一出路是赛道升维（[[规模效应]]的延伸论点）
