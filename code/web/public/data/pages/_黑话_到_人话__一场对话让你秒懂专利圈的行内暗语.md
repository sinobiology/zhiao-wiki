# "黑话"到"人话"：一场对话让你秒懂专利圈的行内暗语

## 核心逻辑
- 专利行业存在极高的术语壁垒，但所有"黑话"都可以用日常逻辑拆解为"想点子→全球占地盘→守规矩通过审查→靠它赚钱→年年交钱保住它"的完整链条。
- 理解专利术语的关键是把握其背后的系统性流程：从技术方案到法律权利，再到商业价值的三级跃迁。
- 同一套专利知识可以按"小白比喻→实习生框架→专家精确表述"三个层次递进理解，适配不同受众。

## 行业洞察
- 专利从业者与非专业人士之间存在严重的沟通鸿沟，术语密度是知识产权行业最大的入门障碍之一。
- 全球专利布局的核心节奏由[[优先权]]的12个月期限驱动，[[PCT]]体系是实现全球化保护的关键通道。
- 专利授权后的商业模式分化为[[专利许可]]（持续收费）和[[专利转让]]（一次性出售）两条路径，实务中许可运营更受青睐。

## 技术/管理要点
- **全球布局路径**：[[首次申请]] → 锁定[[优先权]]日 → 通过[[PCT]]途径进入国家阶段 → 形成[[同族专利]]网络
- **审查核心关卡**：[[新颖性]]（前所未有）+ [[创造性]]（非显而易见），审查员基于[[现有技术]]检索进行判断
- **单一性规则**：一件申请只保护一项发明，违反则需将[[母案]]拆分为[[分案申请]]
- **分案写作红线**：[[分案申请]]的[[权利要求书]]不能超出[[母案]]的[[说明书]]和实施例范围
- **关键日期意识**：技术方案必须在优先权日前固化，以确保新颖性
- **权利维持底线**：按时缴纳[[年费]]是维持[[专利权]]有效的基础工作，遗漏即失权
