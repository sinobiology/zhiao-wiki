# 蚂蚁的逆袭（3）：457次交易——牛市里，我怎么把赚到的钱折腾没了

## 核心逻辑
- 在牛市中，高频率交易（457次）不仅没有带来收益，反而将账面浮盈十万元折腾成净亏损两万余元，核心教训是**"你越勤奋，死得越快"**。
- 买入"消息股"、"专家推荐股"等缺乏个人独立研究的标的，导致**绝对拿不住**，最终陷入"买入—下跌—割肉—追高"的赌徒循环。
- 牛市早期看似靠能力赚到的钱，本质是**"错把趋势当能力"**，它催生了过度自信与FOMO，为后续的亏损埋下隐患。

## 技术/管理要点
- **复盘统计**：51支股票中，操作次数越多的股票亏损越严重，盈利股票的操作次数普遍集中在5次以内；亏损榜首的梅花生物操作96次，盈利榜首的香梨股份仅操作5次。
- **成本侵蚀**：以梅花生物为例，频繁做T和波段操作将平均买入成本从不足七元抬升至八元以上，而平均卖出价不足八元，交易费用（印花税、佣金、过户费）如蚂蚁搬家般吞噬本金。
- **"集邮式炒股"**：分散买入51支股票的本质是用"分散"掩盖"无知"，因不敢在任何单只股票上建立真正的认知仓位。
- **决策依附**：从依赖职场小道消息到付费荐股群，两种路径的共同点是**不愿意为自己的决策负全责**，将判断权外包给消息源或"专家"。
