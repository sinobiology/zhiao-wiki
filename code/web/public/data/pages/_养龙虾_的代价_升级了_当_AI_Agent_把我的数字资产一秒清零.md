# 「养龙虾」的代价，升级了｜当 AI Agent 把我的数字资产一秒清零

## 核心逻辑
- **AI Agent 最危险的地方不是不会执行，而是执行得太彻底**——它不会在命令和后果之间停顿一秒问你「这个文件夹里有几十万的钱包，你真的要删吗？」，只会一刀切下去然后给你一个完美的执行成功绿钩。
- **AI Agent 只需要一秒钟就能把你的生产环境彻底砸碎，人类想把它拼回来可能需要几小时甚至几天高强度的肉眼死磕。**
- 上一篇的结论是「能动嘴的，绝不动手」；这次的教训是权限边界比操作技巧更重要。

## 行业洞察
- **Web3 乃至现代科技最冰冷的一面：没有控制权，就没有资产。** AI 冲掉了初始登录态，人类管理员又从规则上拒绝任何特权恢复——求助官方管理员得到的答复相当于给资产判了死刑。
- **自动化 ≠ 正确**：打着「智能再平衡机制」旗号的组合，在 BTC、ETH、SOL 单边下跌时，自动化低买高卖的物理惯性反而**加速了亏损**。理财黑盒策略在牛市里能放大利润，在熊市里同样能加速收割——**它的「聪明」是建立在市场配合的前提下的。**
- 两笔实战资金的清算结果：YieldMax（USDC 稳健池）存入 10,000 USDC → 10,256.19（+2.56%，Net APY 4.04%），已全部提现；LarryCopy（智能再平衡）存入 2,040 USDC → 1,111.09（**−45.53%**，−$928.90）。

## 技术/管理要点
- **事故过程**：因给 OpenClaw（「小龙虾」）授予最大权限，在执行批量自动化操作时发生逻辑误判——一次自动化清理/重置口令下，它忠实执行底层脚本，**瞬间抹去 40 多个 Chrome 浏览器分身和全部插件**（这些分身原本用于分散风险和多策略运行，每个挂载 Web3 钱包插件），配置文件蒸发导致 AI Dog 理财平台里数万元资产的控制权陷入失联。**「问题在于：它没有安全边界，也没有熔断机制。」** 前端看起来干干净净，就像什么都没发生过。
- **救命稻草不是 AI，而是操作系统底层的残留**：Chrome 在前端删除 Profile 时，硬盘目录下往往还留有部分本地缓存和 LevelDB 加密文件（如本地缓存文件夹 mcbpblocgmgfnpjjppndjkmgjaogfceg）。恢复过程只能新建浏览器环境、去 1Password 翻找助记词、历史记录和提示词，一点点肉体恢复 40 多个钱包。
- **密码学的幽默感**：当年为防盗记录助记词时做了「变阵编码」，时间久了连自己设的编码规则都忘了——最后是在一个勉强能运行的残留分身里靠肉眼死磕、人工对齐每一个单词，才把当年脑子里设的编码逻辑「破译」出来。
- **最后的盲区在网络层**：主钱包和衍生子账户全部复活后核心资金仍不显示；交易记录（经 Debank 逐笔核查）都在但余额对不上。原因是**这是一笔走 Base 链的理财资产，而网络环境被 AI 冲刷干净后钱包默认显示主网**——手动切换到 Base 链并重新连接网站，消失数日的数字才出现，随即执行 Withdraw 提出全部资金。
- **三条实话**：
  1. **路径隔离不能靠默认**——运行任何 AI Agent 或自动化清理脚本时，必须通过命令行参数强行给它指定一个孤立、临时、全新的文件夹，与重要资产环境彻底物理隔离。「别让你的『小龙虾』靠近你的『粮仓』。」
  2. **时间面前没有「我不会忘的」**——你以为绝不会忘的密码变阵、助记词规则、提示词逻辑，在时间面前都不堪一击。**不要让当初「为了安全设的防盗规则」成为阻挡你自救的最后一堵墙**；要及时、完整、安全地记录当下发生的重要事件。
  3. **AI 可以帮你跑腿，但核心决策不能外包**——自动化能提高加群、填表、调取数据的速度，但涉及钱、密钥、钱包、链切换、提现和底层网络环境的核心判断，必须收回代理权由人类亲自验明正身。**「把动手的机会留给 AI——但把随时扣动『物理熔断』扳机的权利，死死攥在自己手里。」**
- 「很多真正的教训，不做事、不踩坑，是永远无法遭遇的。」
