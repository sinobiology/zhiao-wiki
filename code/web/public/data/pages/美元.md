# 美元

## 定义
美元是美国的法定货币，也是当前全球最主要的储备货币和信用货币。在知奥体系中，它被作为观察法币贬值、全球资产定价和中美资本博弈的核心参照物。

## 在知奥体系中的位置
美元在知奥体系中主要承担双重角色：一方面，它是[[法币体系]]与[[信用货币]]的代表，被用来解释长期购买力下降和通货膨胀的财富再分配效应；另一方面，它通过[[实际利率]]这一“估值锚”影响全球资产定价，与[[比特币]]、[[黄金]]等稀缺资产形成对照。

在多篇文章中，美元与[[美联储]]、[[尼克松]]、[[金本位]]等实体共同构成了理解现代货币体系的线索。材料指出，1971年美元与黄金脱钩后，法币完全脱离实物约束，仅靠信用支撑，此后美元百年购买力从1.00跌至0.05。与此同时，[[人民币资产]]在中美关系趋稳时会被重新定价，而美元避险需求则会短期下降。

美元也是[[中美关系]]和全球资本版图中的重要变量。当[[实际利率]]因美联储维持高利率而被动攀升时，全球风险资产和无息资产会同步承压。知奥体系因此建议投资者同时持有“美元尺子”与“硬资产尺子”，用双重视角穿越周期。
