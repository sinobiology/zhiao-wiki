# 张雪峰

## 定义
张雪峰是中国教育领域的知名人物，以考研指导和高强度奋斗叙事广为人知。在知奥体系中，他被作为讨论生命算法、奋斗代价与认知蒸馏的案例之一。

## 在知奥体系中的位置
张雪峰在 [[知奥ZHAO]] 的多篇文章中被提及，主要涉及两个方向。一是作为 [[女娲skills]] 与 [[思维蒸馏]] 的潜在对象，出现在其关联实体列表中，与 [[Paul Graham]]、[[张一鸣]]、[[马斯克]]、[[塔勒布]] 等人物并列，暗示其公开表达中可能具备可被提炼的认知框架。
