## 技术/管理要点
- **项目目标拆解法**：将"公众号自动发文"拆解为五个子任务——定时发送、自动选片、头图生成、标题生成、正文生成
- **智能体工作流五大模块**：
  1. **输入模块**：自动选取热门电影并生成毒舌风格影评正文
  2. **标题生成模块**：基于正文生成标题党风格的15字以内主标题
  3. **头图生成模块**：先根据正文生成文生图提示词，再调用图片生成模型产出写实年代感风格头图
  4. **自动排版模块**：将正文转为HTML格式，按中文句号每两句插入换行，适配公众号阅读习惯
  5. **自动发送模块**：通过微信公众平台开发者接口，依次获取Access Token → 上传素材 → 保存草稿 → 定时发布
- **平台选择**：[[扣子Coze]]（www.coze.cn），[[字节跳动]]旗下AI智能体开发平台，支持低门槛拖拽式模块搭建
- **学习路径**：作者参加了"如何用好[[DeepSeek]]"AI课程训练营（费用3200元），课程涵盖工作流搭建等内容
