# 安利一个11万Star的必装插件，能让你的Agent体验直接质变

## 核心逻辑
- 绝大多数Agent天然倾向于拿到任务就写代码，跳过设计、测试、review，产出不可维护的东西；[[Superpowers]]通过在Agent链路中强行插入结构化工作流（规划-拆解-执行-审查-复盘），显著提升任务产出质量。
- 真正卡住大多数人使用Agent的，不是工具能力不够，而是自己没有一套标准的工作流程。
- Superpowers本质是一个由14个Skills组成的工作流系统，不止适用于开发，营销方案、PPT、数据分析等创造性任务都适用。

## 行业洞察
- Agent工具的核心瓶颈正在从"模型能力"转向"流程编排"——用户需要的不只是更强的模型，而是能引导模型按正确流程工作的系统。
- [[Superpowers]]在[[Anthropic]]官方插件市场安装量达23万、排名第二，GitHub 11万Star，说明开发者社区对"Agent工作流规范化"有强烈需求。
- 原生Agent的并行提问模式（一次甩出多个不相关问题）vs Superpowers的[[苏格拉底式提问法]]（串行深挖、逐步追问），后者能真正把需求聊透，避免产出与预期偏差巨大的结果。

## 技术/管理要点
- [[Superpowers]]适配主流Agent工具：[[Claude Code]]、[[Codex]]、[[OpenCode]]、[[Cursor]]均可安装
- 安装方式：直接让Agent执行安装命令，安装后需重启生效（非热加载）
- 14个Skills组合形成完整工作流：规划 → 拆解 → 执行 → 审查 → 复盘
- 对比实验（ADHD中文阅读器案例）：
  - 无Superpowers：Agent问了几个浮于表面的并行问题就直接开干，产出的[[仿生阅读]]方案照搬英文逻辑，中文场景完全不适用，国内平台兼容性差
  - 有Superpowers：一次只问一个问题、串行深挖，主动识别出浏览器扩展形态、主动调研[[ADHD]]阅读辅助的专业方法，需求覆盖度远超原生模式
- 核心理念：创造任何东西的本质流程都是相通的——规划、拆解、执行、审查、复盘
