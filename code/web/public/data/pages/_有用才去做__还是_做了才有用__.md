# "有用才去做"，还是"做了才有用"？

## 核心逻辑
- 人的大脑天生追求确定性、恐惧损失，导致我们习惯性地用"有没有用"来筛选行动，从而主动屏蔽了生命中最美妙的可能性——Serendipity（意外的好运）。
- "有用才去做"是精算师思维，路径清晰但狭窄；"做了才有用"是探险家思维，每一次行动都是在人生网络中埋下节点，Serendipity就发生在节点的连接处。
- 在看不清楚的时候，先干起来再说。只要最坏结果可承受，就值得用行动去换取一次意想不到的幸运相遇。

## 技术/管理要点
- **三大认知困境：**
  - [[认知近视]]：站在今天看不到未来的路，低估长期价值
  - [[损失厌恶]]：对"浪费时间"的恐惧压倒了对"探索可能"的渴望
  - 恐惧惊喜：追求可控路径，本能排斥不确定性中的"弯路"
- **增加 Serendipity 概率的三个方法：**
  1. 先干起来，创造节点——拓展新维度或在已有维度深钻，行动本身就是埋下节点
  2. 保持好奇，常回顾连接——审视看似不相关的节点之间是否存在可以产生惊喜的交集
  3. 相信"无用之用"——放下对"即时有用"的执念，今天的"无用"行动可能成为未来的 Serendipity
- **决策检验公式：** "如果我去做，最坏的结果我能承受吗？而我能获得的，是否可能是一次意想不到的幸运相遇？"
