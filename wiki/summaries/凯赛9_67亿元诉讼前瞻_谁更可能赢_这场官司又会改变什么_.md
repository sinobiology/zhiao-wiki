# 凯赛9.67亿元诉讼前瞻：谁更可能赢，这场官司又会改变什么？

## 核心逻辑
- 判断：凯赛更可能赢得部分诉求，但很难「一口通吃」——**2017 年新链条的胜负仍取决于新的技术比对与来源证据**。
- 这场官司大概率不会给出一个「谁全赢」的句号，而会给出一串分别针对不同被告、不同技术和不同时期的答案。
- **决定胜负的不是成果听起来多先进，而是研发过程能不能被还原。**

## 行业洞察
- **两条责任链必须切开看**：一条已有判决（瀚霖旧链条），一条仍待比对（微生物所 2017 年转让给宁科的技术及宁科今天实际运行的工艺）。把它们混在一起谈胜负反而会看错这场官司。
- **凯赛过去 16 年的问题不是「没有赢过官司」，而是赢了判决却没有彻底阻断生产能力**——这解释了它为什么在新案中同时追求高额赔偿和生产线处置。财新报道披露，王志洲在正式离职前已代表瀚霖参与生产线实施方案和技术交流，多名原生产部门人员随后流向瀚霖；瀚霖之后又有不同经营主体先后进入同一厂区、使用相关生产设施。
- **旧判决不能无限外推**：一方面已审理过的同一当事人、技术、行为和时期不能在新案中简单重来（法院更可能审查生效判决后是否继续实施、是否通过新主体扩大实施、是否出现新的技术传播和使用行为）；另一方面旧判决证明的是瀚霖旧链条中若干**特定技术、特定行为和特定时期**的侵权事实，尚未证明微生物所 2017 年交付的技术包延续了同一套侵权技术。**从旧链条跨到 2017 年新链条，中间还缺一座证据桥。**
- **产学研合作的真正问题不是当年价格是否公平**（常见的误读是「科研机构觉得企业赚了大钱自己拿少了，企业认为钱已付过同一技术怎么又转给别人」），而是：当年到底转让了什么、企业在产业化过程中形成的改进归谁、科研机构后续能转让什么。

## 技术/管理要点
- **法院必须逐项核对的四套技术材料**（「长链二元酸技术来源」这种说法在舆论场好用，进了法庭却太大太虚）：
  1. *凯赛主张保护的具体商业秘密点*——是菌株遗传特征、培养基配方、发酵参数、分离纯化条件、设备配置和控制逻辑，还是这些信息组成的技术组合？何时形成、当时是否公开、采取了哪些保密措施？「生物法生产长链二元酸」或「聚合级产品工艺」都太宽，不能直接成为商业秘密的边界。
  2. *微生物所 2017 年实际交付的技术包*——合同名称叫「第三代技术」还不够，法院要看实际交付的菌株、图纸、工艺包、操作规程、技术服务内容和合同附件，以及它与 2009 年转让给瀚霖的技术有何继承或差异。
  3. *宁科建线阶段形成的工程资料*——一条工业产线不只来自技术转让方，设计院、设备商、工程团队、招聘人员和企业自己的调试都可能加入新的技术内容。
  4. *宁科投产后实际运行的菌株和工艺*——实际生产未必等同于签约时收到的技术包，也未必等同于最初的工程设计；工业发酵需要长期调试，菌株、参数、设备和操作规程都可能继续变化。
  - 由此推出两个对称结论：**即使宁科产线存在侵权，也不等于微生物所 2017 年转让的全部技术都侵权；即使微生物所一直在研究，也不等于宁科今天运行的整套工艺都来自这条独立研发线。**
- **举证责任如何分阶段移动**（商业秘密案件不评选谁的产业贡献更大——投入再多、产业化再成功，也要先说清自己保护什么、对方用了什么）。凯赛首先要搭起五组证据：① 明确具体商业秘密点；② 证明这些信息在相应时间不为公众所知并采取了合理保密措施；③ 提供被诉技术与其秘密相同或实质相同的初步比对；④ 证明被告存在接触、获取或传播相关信息的机会；⑤ 分别说明每名被告实施了获取、披露、转让还是使用行为。若能证明「接触或获取机会＋实质相同」，部分举证责任可能转到被告一边——「凯赛先把桥搭到足够远，随后才轮到对方解释自己为什么没有走过这座桥。」
- **微生物所最有力的抗辩不是「我们研究得更早」，而是一套可连续核验的研发档案**：2009 至 2017 年的菌株保藏与传代记录、项目原始数据、失败实验、参数变更、人员参与情况，以及 2017 年交付清单与早期技术的版本差异。若记录连续可信、能解释被诉技术的独立形成过程，它完全可能赢下核心争议；反之若「第三代技术」只有宣传材料、合同名称和结果指标而中间研发过程断了，「持续研究多年」的分量会迅速下降。
- **凯赛最硬的牌是多份已生效的裁判**（不是院士评价或「全球首次产业化」叙事）：刑事案件确认王志洲违反保密义务将凯赛部分商业秘密带到瀚霖并用于生产；专利权属和发明人署名案件否定了瀚霖将凯赛员工职务成果申报在自己或相关人员名下；后续商业秘密和专利侵权案件认定瀚霖及后来承租生产线的部分企业持续使用了侵权技术。
- **三种判决情景（按概率排序）**：
  1. *凯赛部分胜诉*（概率最高）——法院可能确认若干具体技术秘密受侵害、判令部分被告停止使用并赔偿、对相关资料/菌株/设备/工艺环节采取清除措施；但不支持全部秘密点、不认定十名被告承担同等责任、不会全额支持 9.67 亿元。「部分」并不意味着胜诉意义小——只要法院在 2017 年技术包或宁科实际生产技术中认定了凯赛的关键秘密，本案就会在旧瀚霖链条之外形成**新的责任节点**。
  2. *凯赛赢旧链条、微生物所和宁科赢新链条*（与第一种差距不大）——法院以旧判决认定的事实为基础处理判决后继续实施或通过新主体扩大实施的行为，同时认为凯赛未证明 2017 年技术包和宁科现行工艺使用了相同秘密。这不等于微生物所的全部技术都被确认为原创，只意味着凯赛已有的胜诉边界没有延伸到 2017 年的转让。
  3. *凯赛接近全面胜诉*（不押这个结果）——不仅要求证明 2017 年技术包和宁科生产技术实质使用了自己的秘密，还要分别证明多名被告明知或应知、共同参与，并为 9.67 亿元找到可靠计算基础。
- **9.67 亿元只是原告的诉讼请求，不是法院已查明的损失**。惩罚性赔偿需同时满足故意、情节严重和可计算的赔偿基数。生效裁判后重复实施侵权、或通过关联公司与主体变更规避责任，可能对瀚霖旧链条中的部分主体不利；**但这种恶意状态不能自动传递给 2017 年以后加入的每一名被告**。
- **法院会不会真的销毁整条生产线**：关键不在生产线值多少钱，而在**侵权技术能否从生产系统中剥离**。若删除控制程序、更换局部设备、调整参数、销毁菌株和资料就足以停止侵权，整线销毁通常缺乏必要性；若关键设备、管线和控制系统就是围绕特定秘密工艺定制、局部整改无法阻止继续使用，救济范围才可能扩大到整套生产系统。最高法「蜜胺」技术秘密案提供了尺度——支持处理生产系统中涉及技术秘密的设备，但对未承载秘密的其他设备仍要保护其合法财产权。**处置阶梯**：清除信息 → 销毁菌株和资料 → 拆除关键设备 → 必要时才触及整条生产线。这也是本案比赔偿数字更值得看的地方：知识产权判决能不能不只停在纸面上，而是真正让持续侵害停下来。
