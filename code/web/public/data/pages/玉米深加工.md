# 玉米深加工

## 定义
玉米深加工是将玉米作为原料，通过发酵、淀粉加工、提取纯化等工艺，转化为氨基酸、淀粉糖、生物产品等高附加值产品的产业。它属于农产品加工与生物发酵工业的交叉领域，赖氨酸、苏氨酸等氨基酸产品是其最典型的延伸方向。

## 在知奥体系中的位置
玉米深加工在知奥体系中是一个底层产业逻辑，连接原料、能源与氨基酸竞争。材料显示，赖氨酸生产成本高度集中于玉米淀粉原料与煤炭蒸汽、电力，两者合计占65%—75%，因此玉米深加工的核心不是单纯技术竞赛，而是围绕玉米和能源成本展开的工业算术题。

它与[[赖氨酸]]关系最为紧密：[[ADM]]将赖氨酸视为玉米深加工的自然延伸，[[大成生化]]的崛起也建立在对吉林玉米带的垂直整合之上——把一粒玉米拆解为完整产品树，副产物利润反哺主产品。[[梅花生物]]、[[阜丰集团]]、[[伊品生物]]等中国头部企业，均以玉米深加工为底盘进入氨基酸行业。

在产业选址逻辑中，玉米深加工与[[新疆]]、[[热电联产]]、[[全球可销售成本]]直接相关。由于玉米低价值密度、运费占比高，产业天然倾向“就地加工、就地转化”，新疆的低煤价与玉米产量增长共同构成制造端成本优势，但物流端增加与反倾销壁垒又要求企业重新计算可销售成本。

## 关键数据
- 赖氨酸生产成本中，原料（玉米淀粉）与能源（煤炭蒸汽+电力）合计占65%—75%
- 第一波中国赖氨酸入场潮（2003年前后）由玉米深加工政策红利驱动
- 2025年新疆玉米产量1636.6万吨，同比增长8.5%
- [[阜丰集团]]在哈萨克斯坦江布尔州落地8亿美元玉米深加工项目，已开始产出氨基酸
- 玉米深加工的产品树包括玉米胚芽油、玉米蛋白粉、饲料级麸质粉等副产物
