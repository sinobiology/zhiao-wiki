# 反馈抑制

## 定义
反馈抑制是细胞代谢调控的核心机制：当某一代谢途径的终产物在胞内积累到一定浓度后，会反过来抑制该途径开头关键酶的活性或表达，从而阻止更多产物合成。在工业氨基酸发酵中，它是菌种不愿过量积累目标产物的首要内在障碍，也是代谢工程与合成生物学长期围绕攻克的调控节点。

## 在知奥体系中的位置
反馈抑制贯穿氨基酸发酵七十年的技术演进，是理解工业菌种从「随机诱变」走向「理性设计」的关键线索。在 [[氨基酸]] 育种的第一阶段（1950s–1980s），研究者发现 [[谷氨酸棒杆菌]] 不愿过量积累谷氨酸的根本原因正是反馈抑制——从细胞角度看，它不是故障，而是细胞经济性的体现：任何代谢中间产物的过多生成和排出，都是对自身增长的釜底抽薪。

在具体品种的技术史中，反馈抑制反复成为卡点。[[赖氨酸]] 生产中，早期用结构类似物 AEC 筛选对调节机制「麻木」的突变株，后来升级为精准修改 [[天冬氨酸激酶]]（LysC）调节亚基以解除协同反馈抑制。[[缬氨酸]] 通过突变型 AHAS 获得对产物不敏感的变体，用 α-氨基丁酸抗性筛选突变株。苏氨酸则通过筛选抗 AHV 突变株，拆除 ThrA 酶的产物抑制「刹车片」。这些工作共同指向一个技术目标：把合成闸门永久打开。

反馈抑制的解除并非孤立操作，而是 [[代谢工程]] 中「胞内静态生产能力」的基石。材料1指出，单做反馈抑制解除仍可能因外排瓶颈或代谢流分配问题而失灵，近年突破如 2025 年 Zhao 等将苏氨酸推至 163.2 g/L，依赖的是生物传感器动态调控与代谢网络优化协同，而非仅仅拆除反馈抑制。此外，[[LysE]] 转运蛋白的发现说明，即使解除了合成端抑制，若胞内产物不能及时外排，毒性积累仍会构成新瓶颈。

## 关键数据
- 1957 年协和发酵木下祝郎发现谷氨酸棒杆菌可积累谷氨酸，第一个困惑是「为什么它不愿多产」，答案是反馈抑制。
- 赖氨酸生产中，用赖氨酸响应核糖开关同时调节合成与外排，相比只做反馈抑制解除的对照株，得率提高 89%（Zhou 和 Zeng，2015，C. glutamicum）。
- 缬氨酸反馈抑制解除通过 α-氨基丁酸抗性筛选突变株实现；好氧发酵切换为厌氧发酵后，发酵周期长达 60 小时以上，是好氧的两倍。
- 苏氨酸解除反馈抑制依赖抗 AHV 突变株筛选，拆除 ThrA 酶抑制后配合外排泵工程，产酸能力突破 140 g/L。
- 2025 年 Zhao 等在 E. coli 将苏氨酸推至 163.2 g/L、得率 0.603 g/g，其设计将生物传感器反馈调节与代谢网络优化整合。
