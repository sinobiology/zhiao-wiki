# 卓克

## 定义
卓克是知识服务平台[[得到]]上的科普类内容创作者，擅长以科学思维和还原论视角拆解技术、工程与生命科学议题。他的内容产品包括《[[科技参考4]]》《[[科学思维课]]》等，在库中被多次引用为方法论与思想资源。

## 在知奥体系中的位置
卓克在知奥知识库中主要作为「科学思维 + 知识服务」的参照系出现。他与[[万维钢]]、[[吴军]]、[[薛兆丰]]、[[陈海贤]]等同属[[得到]]内容生态中的关键创作者，共同构成库中「浏览式学习」与「碎片化学习」方法论的背景来源。多篇文章将[[得到]]上的音频学习视为建立初步[[神经连接]]、将「不知道自己不知道」转化为「知道自己不知道」的入口，而卓克正是这一学习路径中反复出现的内容供给者之一。

在具体方法论上，卓克的贡献被直接引用于AI提问与陌生领域学习。材料4提到「要求模型用4种难度梯度递增的方式解释同一知识点」的技巧，明确标注参考[[卓克]]《[[科技参考4]]》第232期。材料8则关联[[卓克]]的《[[科学思维课]]》，用于支撑对发酵罐传质与分子尺度问题的数量级推演。可以说，卓克在库中代表了一种「用硬核科学拆解复杂问题」的认知工具。

在更抽象的哲学层面，卓克与[[还原论]]、[[科学思维]]、[[理性主义]]、[[虚无主义]]等概念紧密相连。多篇文章指出，把一切还原为多巴胺、熵增、生化反应的「去魅」视角，虽然能解释世界，却也容易消解人生意义感。卓克式的科学世界观在这类讨论中既被肯定为认知升级的来源，也被视为需要与「共情」「意义创造」相平衡的思维方式。
