# 聊聊美联储降息，用人人能听懂的方式

## 核心逻辑
- 美联储通过调节联邦基金利率（银行间拆借利率）来控制市场上货币的流动量，加息抑制通胀、降息刺激经济，本质是维持经济天平的平衡。
- 降息意味着市场上流动的钱会多起来，钱一定会流动，关键在于你选择的资产是否离美元足够近。
- 费雪方程式 M×V=P×T 揭示了货币与实际经济的恒等关系：钱变多而东西没变多，东西就会变贵。

## 行业洞察
- 2025年9月18日美联储下调联邦基金利率25个基点至4.00%-4.25%，为2024年12月以来首次降息，标志着货币政策从紧缩周期转向宽松。
- 美联储降息不仅影响美国国内资金流向，也会改变全球资本的流动格局——加息时全球资金流入美国，降息时资金从美国流出寻找更高回报的资产。
- 降息释放的流动性从源头（美元体系）开始逐步向外扩散，离美元越近的资产越先受益。

## 技术/管理要点
- **美联储三大货币政策工具**：
  - 折扣贷款窗口：紧急情况下向银行提供救命钱，利率称为贴现率
  - 储备金率：强制商业银行按比例将存款上交美联储，防止挤兑
  - 公开市场操作：通过买卖国债调节联邦基金利率，即日常所说的"加息/降息"
- **加息逻辑**：经济过热→钱比商品多→通货膨胀→加息→人们存钱减少消费→经济降温
- **降息逻辑**：经济过冷→没人消费投资→失业率上升→降息→人们取钱消费创业→经济升温
- **费雪方程式 M×V=P×T**：
  - M（货币供给量）增加而T（交易总量）不变，则P（物价）上涨，即通胀
  - 央行通过控制M来影响P，前提是V（货币流通速度）相对稳定
- **美联储权力架构**：联邦储备委员会（政府机构）+ 12家联邦储备银行（非营利组织），分权制衡，源于1913年《联邦储备法案》
