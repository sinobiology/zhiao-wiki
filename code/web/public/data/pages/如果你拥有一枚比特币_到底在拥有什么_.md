- **私钥机制**：256位随机数，是比特币所有权的唯一凭证；无法通过地址反推，重复概率接近于零；私钥丢失则资产永久不可恢复
- **区块链账本**：全球分布式账本，每笔交易经算力博弈验证后打包进区块，永久记录；篡改需控制全球51%以上算力（成本千亿美元级别），且修改后仍会被全网节点拒绝

- **去中心化网络**：全球数万节点和矿工共同维护，无CEO、无董事会，靠代码自动运行
