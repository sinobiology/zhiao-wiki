# 异亮氨酸

## 定义
异亮氨酸是一种必需氨基酸，属于支链氨基酸（BCAA）家族，与缬氨酸、亮氨酸共享代谢酶系统。在饲料氨基酸行业中，它是豆粕替代逻辑中的“中间品种”，已被纳入洋葱式替代阶梯，在降低豆粕用量方面发挥作用。

## 在知奥体系中的位置
异亮氨酸在氨基酸发酵行业的“洋葱式替代阶梯”中处于中间位置。根据[[一张图看懂：氨基酸发酵行业的存在哲学]]的论述，在补齐[[赖氨酸]]、[[蛋氨酸]]、[[苏氨酸]]、[[色氨酸]]后，[[豆粕]]用量可从100%降至46%；而[[缬氨酸]]、异亮氨酸等中间品种已跨过成本拐点，实现工业对农业的“降维打击”。

在[[BCAA拮抗效应]]中，异亮氨酸与[[缬氨酸]]、[[亮氨酸]]共享BCAT和[[BCKDH]]酶系统。玉米中亮氨酸含量约为缬氨酸的2.5倍，过量亮氨酸会诱导BCKDH活性升高，可能“拖下水”式过度消耗缬氨酸——这一拮抗关系对异亮氨酸的使用配比构成潜在约束。

此外，异亮氨酸在去商品化趋势中也有所体现。根据[[缬氨酸 (3/5) | 低含量产品是“真降本”还是“降级陷阱”？]]所载，[[牧原]]与[[元素驱动]]合作的[[牧元安粮]]模式，将缬氨酸、异亮氨酸、色氨酸等组合定制为内部配方组件，配合[[低蛋白日粮]]体系系统性替代豆粕，形成“配方前移+供应链前移”的深度绑定方案。

## 关键数据
- 在洋葱式替代阶梯中，异亮氨酸处于中间品种位置，已跨过成本拐点，能够在不触发成本陷阱的前提下为豆粕替代继续降本。
- 缬氨酸与异亮氨酸、亮氨酸同属BCAA，共享BCAT和[[BCKDH]]酶系统；玉米中亮氨酸约为12-13 g/kg，缬氨酸约4-5 g/kg，亮氨酸约为缬氨酸的2.5倍。
- 异亮氨酸在[[理想蛋白质模型]]框架中作为限制性氨基酸之一被纳入考虑。
- 暂无独立产能、价格或产销量数据。
