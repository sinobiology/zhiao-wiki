# 池田菊苗

## 定义
池田菊苗是日本化学家，因于1907年从一碗海带汤中发现「鲜味」并提取出谷氨酸钠而闻名。他由此催生了世界第一瓶味精，属于调味品与食品科学领域。

## 在知奥体系中的位置
池田菊苗的发现是整个味精工业的起点。1907年他从海带汤中识别出鲜味物质，1909年[[味之素]]将这一发现产品化，推出世界第一瓶味精，开创了工业化调味品行业。他的工作直接定义了[[谷氨酸]]作为核心呈味物质的基础，与后来1960年代出现的[[发酵工程]]形成由实验室发现到大规模制造的完整链条。

在知奥对产业演进的分析中，池田菊苗代表的是日本「技术—专利—品牌」一体化路径的原点，与[[吴蕴初]]、[[天厨味精厂]]所代表的中国「资源—地方—规模」路径形成对照。味之素从这一发现出发，逐步积累氨基酸科学能力，最终延伸至[[ABF]]芯片封装材料，而这一长期技术复利正可追溯至池田菊苗对鲜味的原始科学洞察。
