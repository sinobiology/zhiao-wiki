# 氨基酸的贸易救济调查是如何"算"出倾销税的？

## 核心逻辑
- 反倾销调查表面是价格之争，实质是"谁有资格定义你的价格是正常的"——规则承认权之争。
- 税率高低的分水岭往往不在于企业卖得便不便宜，而在于能不能把低成本"讲清楚、证明白、算透彻"。
- 对中国氨基酸企业而言，这场仗的本质是把制造能力翻译成证据能力——财务规范度、数据治理和内控水平决定胜负。

## 行业洞察
- 2026年Q1中国氨基酸行业遭遇多国贸易救济"围剿"：[[欧盟委员会]]对[[缬氨酸]]征收31.3%~53.8%反倾销税，[[美国商务部]]对[[L-赖氨酸]]加征最高80.37%反补贴税，巴西、韩国相继启动立案调查。
- 同一品种、相似出口市场的企业，税率可能差出数倍，核心变量不是出口报价，而是调查机关对"正常价值"基准的认定方式不同。
- 中国氨基酸企业的核心竞争力（极低综合成本）恰恰是反倾销调查中最容易被质疑的点——成本越低，越需要完整的证据链来支撑。

## 技术/管理要点
- **倾销幅度公式**：倾销幅度 =（[[正常价值]] - 出口价格）÷ 出口价格 × 100%，关键争议点在于"正常价值"的认定
- **调查问卷实质**：不是填表报数，而是将企业经营现实翻译为可被外部核查、理解、复算的完整语言体系
- **现场核查三层验证**：
  - 第一层：账能不能对上（总账→明细账→财务报表→成本表→会计凭证的完整勾稽）
  - 第二层：交易能不能穿透（合同→出库单→运输单据→报关单→回款记录→会计入账的完整链路）
  - 第三层：成本能不能还原到生产现场（BOM投料比、公用工程消耗、制造费用归集分摊、联产副产物处理）
- **导致高税率的五大常见问题**：
  1. 数据不完整——底稿、凭证、台账、链条断裂
  2. 数据不一致——问卷、财务、销售、成本口径互相打架
  3. 关联交易说不圆——缺乏公允定价依据
  4. 成本分摊逻辑太粗——多产品共线、联产副产物、公用工程分配不够精细
  5. 程序性配合不到位——材料拖延、解释模糊、补充底稿不足
- **企业应诉核心能力**：财务规范度、数据治理能力、内部控制水平，而非仅依赖律师团队
