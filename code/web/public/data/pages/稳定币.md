# 稳定币

## 定义
稳定币是一种锚定法币（主要是美元）或加密资产的加密货币，旨在提供稳定的计价单位和支付手段，弥补比特币等加密资产价格波动过大的缺陷。它属于加密金融与支付基础设施领域，已从交易所内部货币演变为全球金融体系的一部分。

## 在知奥体系中的位置
稳定币在知奥ZHAO的知识谱系中处于「前沿技术」与「金融基础设施」的交汇点。它不只是加密资产的一类，更被放在货币主权、跨境支付与机器经济的框架下讨论。

在 [[2026年2月总结]] 和 [[2026年7月总结]] 中，稳定币与 [[AI]]、[[氨基酸]]、[[成本边界]] 等并列，作为知奥跨领域关注的信号之一。更关键的是，稳定币与 [[Agent经济]] 直接相关：当 [[AI Agent]] 成为链上经济主体，机器天然需要 7×24 小时、可编程、自动结算的货币，这正是稳定币的结构性优势。[[赵长鹏]] 在香港演讲中把稳定币定位为「支付演进路径」中的桥梁——从法币支付到稳定币支付，再到原生 Crypto 支付，稳定币未必是终点，但它是当下最关键的一环。

在产业层面，知奥通过 [[段永平]] 建仓 [[Circle]] 的观察仓事件，把稳定币的投资逻辑拆解为「出售对储备、监管与赎回能力的信任」。这与知奥一贯的写作方法论一致：不只追结论，而是追「结论背后的边界」——哪些是法律事实、哪些是单方主张。稳定币的监管围剿与「收编」，本质上是在重新定义数字时代的货币主权。
