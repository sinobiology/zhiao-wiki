# 富爸爸穷爸爸

## 定义
《富爸爸穷爸爸》是罗伯特·清崎所著的财商启蒙书籍，通过对比“穷爸爸”和“富爸爸”两种截然不同的金钱观与财富观，向读者传递资产、负债、现金流和被动收入等核心理财概念。它属于个人理财与财商教育领域的入门级经典作品，在知奥体系中多次作为理财认知觉醒的起点出现。

## 在知奥体系中的位置
《富爸爸穷爸爸》是知奥体系中财商启蒙的基础入口。材料中反复出现的 [[现金流象限图]]、[[资产与负债]]、[[被动收入]] 等概念，都直接源于这本书的框架。它不只是单一书籍，更是后续一系列投资实践与复盘的认知源头。
它也连接着 [[罗伯特·清崎]] 的思想体系，以及由这些思想延伸出的 [[杠杆]]、[[复利]]、[[财务自由]] 等进阶概念。在知奥体系中，这本书更像是一个起点：它让人第一次看到象限和现金流，但真正的成长来自之后用 [[复盘]] 和 [[资产配置]] 去补足认知鸿沟。

## 关键数据
- 在材料1中，资产与负债的清崎定义被明确提出：资产是能为你赚钱的东西，负债是拿走你钱的东西。- 在材料3中，作者于2022年1月21日完成首次系统复盘，其复盘方法建立在对书中资产/负债、现金流象限等概念的重新理解之上。
