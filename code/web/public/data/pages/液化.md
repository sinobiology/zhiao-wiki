# 液化

## 定义
液化是淀粉制糖和淀粉深加工中的核心工序，指通过热、酸或酶的作用，把天然淀粉颗粒打开、并将释放出的长链淀粉分子部分水解为较短可溶的糊精，从而快速降低料液黏度、使其能够被泵送、搅拌和换热。它属于工业酶法与连续化生产工艺中的关键环节，介于[[糊化]]与[[糖化]]之间。

## 在知奥体系中的位置
液化在[[糖源之战II系列]]中处于工艺链条的枢纽位置。它解决了天然淀粉“料液流不动”的物理瓶颈：糊化用水和热打开颗粒的半结晶结构后，大量长链分子彼此缠结并束缚水分，黏度急剧上升，工业管道和换热器无法承受；液化用 [[α-淀粉酶]] 在长链内部多点下刀，迅速切成较短糊精，使黏度快速下降。这正是 [[α-淀粉酶]] 承担液化的根本原因，而 [[β-淀粉酶]] 从非还原端逐个释放麦芽糖的机制则决定了它不适合这一环节。

液化的进化和它所需要的设备、酶紧密绑定。[[喷射液化器]] 把升温、糊化和降黏压缩进一条连续管线，改变了从“一罐一罐煮”到“连续进出料”的生产逻辑；但喷射器要求 105–110℃ 的高温环境，传统中温酶在 60–70℃ 就会失活。于是液化成为推动 [[耐高温淀粉酶]] 开发的核心动力，也构成了 [[诺维信]] 旗下 [[Termamyl]] 工艺嵌入的落点——谁能把酶真正装进 105℃ 左右的工业液化工艺，谁就抓住了淀粉糖、酒精、酿造行业共同需要的那块市场。

在工艺顺序上，液化的位置首先由淀粉分子与颗粒结构约束：先糊化打开颗粒，再液化切断长链，之后才进入 [[糖化]] 释放葡萄糖；是否单独设置去分支步骤，则取决于原料、目标糖浓度、酶的特性与经济性。

## 关键数据
- 经典工业喷射液化工艺：淀粉乳在 105–110℃ 经历数分钟热处理，随后迅速降温到约 95℃ 完成液化。
- 喷射液化器的硬性要求是用蒸汽瞬间加热到 105–110℃ 维持 1–2 分钟完成糊化，再闪蒸降温到 90–95℃ 加酶水解。
- 1959 年公布的美国专利 US 2,919,214 已把淀粉乳进料、蒸汽入口、喷射器剖面和自动温控回路画进同一套连续装置。
- 1973 年，Novo 内部科学家在中试中于约 105℃ 液化约 2 小时，得到 DE 12–14 的液化液，随后冷却到约 60℃ 进入糖化，无明显回生。
- 液化与糖化能耗约占淀粉基乙醇生产总能耗的 30%–40%。
- 传统间歇液化的三个瓶颈：生产周期长、高浓度物料传热和搅拌困难、批次波动大不利连续化。
