# 用数据说话：氨基酸赛道的五年投资压力测试（2021-2025）

## 核心逻辑
- 2021-2025年是"生物制造"对"传统消费"的估值逆袭周期：低估值高分红的发酵龙头（梅花、阜丰）资产翻2-3倍，而高估值消费白马（海天）跌去80%。
- 对于低估值、高分红且基本面持续改善的标的，一次性买入（长期持有）是最优策略；定投策略仅在高估值标的的下行周期中体现出摊薄成本的防御价值。
- 分红复投是穿越周期的核心变量——梅花生物股息复投贡献了总收益的三分之一（54%），阜丰集团股息复投贡献32%。

## 行业洞察
- **估值体系重构**：合成生物学爆发（华恒生物上市、凯赛生物扩产）将"发酵行业"从"高污染周期股"重新定义为"生物制造成长股"，估值中枢系统性抬升。
- **行业格局优化**：玉米、煤炭等大宗商品波动考验成本转嫁能力，具备全产业链优势的龙头企业因竞争对手退出而受益，集中度持续提升。
- **港股价值洼地**：阜丰集团以3-4倍PE起步，五年资产接近翻3倍（+196%），港股的极度低估为投资者提供了巨大安全边际。
- **高估值消费股的均值回归**：美联储加息叠加国内增速换挡，80-100倍PE的消费白马经历残酷杀估值，海天味业市值从6000亿腰斩再腰斩。

## 技术/管理要点
- **回测模型设定**：9只标的+沪深300对照，2021.1.4-2025.12.31，单标的10万元，策略A（一次性买入+分红再投资）vs 策略B（月度定投1,666.67元×60个月+分红再投资）
- **价值重估组表现**：
  - [[梅花生物]]：长期持有+171%，定投+166%，长期持有略胜
  - [[阜丰集团]]：长期持有+196%，定投+118%，长期持有大幅胜出
  - [[星湖科技]]：长期持有+74%，定投+39%，并购重组早期持有优势显著
- **成长分化组表现**：
  - [[凯赛生物]]：长期持有-15%，定投-10%，高估值科创股两种策略均亏损
  - [[华恒生物]]：长期持有+104%，定投+90%，真成长股越早买越好
  - [[新和成]]：长期持有+19%，定投+18%，稳健白马两策略差距不大
- **估值回归组表现**：
  - [[海天味业]]：长期持有-37%，定投-34%，泡沫破灭两种策略均巨亏
- **策略选择规则**：低估值高分红选长期持有；震荡市或高估值下行选定投；高估值成长股定投可减损但无法避免系统性回调
