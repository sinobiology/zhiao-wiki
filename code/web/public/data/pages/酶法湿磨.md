# 酶法湿磨

## 定义
酶法湿磨是一种在玉米湿法加工中用酶制剂辅助或替代传统亚硫酸浸泡的技术路线，属于玉米深加工与发酵制糖领域。它试图用更短的时间、更精准的酶解作用打开玉米结构，但长期未能在百万吨级产线上全面替代传统工艺。

## 在知奥体系中的位置
酶法湿磨是《糖源之战》系列的核心话题之一，尤其在时间之战和屏障之战的讨论中被反复审视。它与 [[亚硫酸浸泡]] 构成直接对比：传统 SO₂ 浸泡便宜、宽容、耐波动，而酶法在实验室中更快，却在工厂的成本、稳定性、设备改造和人员经验面前败下阵来。它的现实终局并非「替代 SO₂」，而是作为优化者渗透进 [[玉米湿法工艺]] 的各个环节。

在技术上，酶法湿磨与 [[E-Milling]] 紧密相关，后者是 2000 年代后期走向商业试验的酶法路线之一。它依赖 [[蛋白酶]] 等工业酶制剂打开蛋白网络，但酶的价格、稳定性窗口和实际得率都限制了其普及。[[传质屏障]] 是理解酶法局限的另一把钥匙：真正限制浸泡速度的往往是物理传质而非化学反应，因此单靠加酶难以突破系统性瓶颈。

## 关键数据
- 实验室碱性蛋白酶法可得率达 85%，条件为 pH 11.5、酶活 1000 U/mL、51℃、12 小时
- 工业实际得率仅 68%–72%
- 蛋白酶最适温度窗口通常只有 5–10℃，pH 容差 ±0.5 以内
- 传统 SO₂ 浸泡参数窗口极宽：pH 3–4 波动 10%、温度 50–55℃ 波动 ±2℃ 影响极小
- 工业酶制剂价格是 SO₂ 的数十至上百倍
- 马来西亚 Prai 一条 200 吨/日 E-Milling 产线，得率较传统提高 2.1%–4.6%
- 半湿脱皮 + 低硫酶法组合在新建绿色工厂中值得进入方案比选和中试验证
