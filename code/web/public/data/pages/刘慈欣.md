# 刘慈欣

## 定义
刘慈欣是中国科幻作家，代表作《三体》。在本知识库中，他主要作为科幻思想资源出现，其作品与观点被用于讨论太空探索、文明存续、资源瓶颈、自由与尺度等宏观议题。

## 在知奥体系中的位置
刘慈欣在多篇文章中被引用，作为思考人类文明路径的坐标系。在《一个和十万个地球》与《一个地球，十万个地球》中，他的核心命题——人类是选择做 [[园丁文明]] 还是 [[星舰文明]]——被用来审视 [[环境保护]] 与 [[太空探索]] 之间的资源错配。文中提出环保的技术难度不亚于星际航行，但人类却放弃了太阳系中相当于十万个地球的资源，这一判断直接呼应刘慈欣式的文明尺度观。

在《你以为的自由，都是更大尺度给的》中，刘慈欣与 [[马斯克]]、[[多行星物种]] 等实体并置，用于说明生命在更大尺度约束下的不自由。文章从 [[发酵罐]] 中的细菌谈到银河系，刘慈欣的存在强化了从微观到宏观的尺度链条。在《给时光以生命，而非给生命以时光》中，他通过 [[三体]] 与 [[大低谷]] 被关联到 [[长期主义]] 和意义生成的话题，说明其文本不仅是科幻想象，也被用于支撑对个人创作纪律与时间价值的思考。

他在 [[2025年11月总结]] 中作为关联实体被列出，与 [[段永平]]、[[巴菲特]] 等投资认知类实体并列，显示其在知奥体系中承担着超越纯文学的功能：为行业分析、管理感悟和文明级思考提供想象力的参照系。
