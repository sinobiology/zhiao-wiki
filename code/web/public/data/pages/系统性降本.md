# 系统性降本

## 定义
知奥知识库对氨基酸发酵降本路径的方法论总结，区别于单点优化，强调从规模、工艺、能耗、菌种、原料等多个维度协同推进，形成有层次的"工程路线图"。

## 在知奥体系中的位置
系统性降本是"成本决胜"系列六篇文章的核心框架，代表知奥在发酵行业降本方面的原创方法论：

- **层次一：规模降本**（[[规模效应]]）：扩大发酵罐规模，降低固定成本摊薄
- **层次二：工艺降本**：提升发酵转化率、收率、产品纯度，减少废弃物
- **层次三：能效降本**：降低吨氨基酸综合能耗（蒸汽、电力），包括sCO2新技术
- **层次四：菌种降本**（[[菌种工程]]）：通过基因改造提升产酸率，减少旁路代谢损耗
- **层次五：原料降本**：替代原料开发（非粮食碳源）、副产物变现
- **层次六：超越发酵法**：碳能解偶联、合成生物学路线颠覆
