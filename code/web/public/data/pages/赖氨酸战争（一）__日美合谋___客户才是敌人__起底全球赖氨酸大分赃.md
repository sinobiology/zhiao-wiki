# 赖氨酸战争（一）| 日美合谋——"客户才是敌人"：起底全球赖氨酸大分赃

## 核心逻辑
- 1956年起日本企业通过发酵技术突破与专利壁垒构建了赖氨酸双寡头格局，1991年ADM入局打破旧秩序后，五家企业迅速从价格战转向秘密卡特尔，联手操控全球赖氨酸价格。
- 卡特尔的本质逻辑是"竞争对手是朋友，客户才是敌人"——同行共谋转嫁成本给下游饲料企业和养殖户，9个月内推动价格上涨70%。
- 内部告密者马克·惠特克为FBI录制数百小时犯罪证据，但自身同时涉嫌950万美元欺诈，揭示了"英雄与罪犯一体两面"的复杂人性。

## 行业洞察
- 氨基酸产业的竞争从未局限于技术和成本，专利诉讼、司法战场与价格战交替使用，是跨国巨头的标准打法——从二十年前ADM案到2025年味之素诉梅花集团，逻辑一脉相承。
- 日本企业的真正壁垒不是单一菌株，而是"菌株改良+发酵控制+提取纯化+专利布局"的系统性工业壁垒，后来者必须同时突破技术门槛和知识产权门槛。
- 当行业参与者极少且产品高度同质化时，从价格战滑向卡特尔几乎是一种结构性引力——ADM从挑战者到共谋者的转变仅用了一年。

## 技术/管理要点
- **发酵技术起点**：1956年发现[[谷氨酸棒状杆菌]]，1958年[[协和发酵]]实现赖氨酸发酵工艺建立，开启工业化生产
- **菌株改良路径**：紫外诱变、化学诱变筛选"营养缺陷型"或反馈调控失灵突变株，解除天冬氨酸家族代谢通路对赖氨酸终产物的反馈抑制
- **卡特尔运作机制**：季度会议→基于实际销量数据协商配额→确定价格目标→超额者下季度主动减量，以行业协会/工作组名义掩护
- **反垄断处罚规模**：ADM总罚款1亿美元（赖氨酸7000万+柠檬酸3000万），为当时美国反垄断史上最大单项罚款；欧盟同步处罚
- **ADM的产业逻辑**：作为美国最大农产品深加工巨头，从玉米原料上游向高附加值生物产品延伸，赖氨酸是玉米深加工的自然延伸
