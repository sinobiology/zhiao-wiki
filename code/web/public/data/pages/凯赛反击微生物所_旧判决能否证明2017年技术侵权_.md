# 凯赛反击微生物所：旧判决能否证明2017年技术侵权？

## 核心逻辑
- **旧判决已经回答了瀚霖如何侵权，却没有回答 2017 年技术是否侵权。**
- 旧判决能证明山东瀚霖曾非法取得、使用凯赛的部分技术秘密，也能证明瀚霖当年「技术来自微生物所」的抗辩未被法院支持；但尚不能直接证明微生物所 2017 年转让给宁科的技术包包含凯赛的技术秘密，或经过了瀚霖这条传播路径。
- 要跨过这一步，仍需比较 2017 年技术包、宁夏产线实际使用的技术与凯赛本次主张的具体秘密点。

## 行业洞察
- 交锋背景：7 月 17 日微生物所声明称 2017 年转让给宁夏新日恒力的第三代技术是中科院「十二五」部署项目成果、不侵犯任何第三方知识产权；7 月 19 日凯赛发布《关于长链二元酸技术来源的事实说明》，第一次集中列出刑事、民事和行政案件案号逐项反驳。**微生物所讲的是一条从 1969 年延续至 2017 年的自主研发史，凯赛拿出的是多份生效裁判。**
- 凯赛列出的案号：(2017) 鲁 0891 刑初 134 号、(2019) 鲁 08 刑终 5 号（侵犯商业秘密刑事）；(2012) 高民终字第 3975 号、(2016) 京民终 315 号（署名权及权属）；(2016) 鲁民终 212 号、(2019) 最高法民申 2424 号（专利权属）；(2022) 最高法知民终 445 号（技术秘密）；(2023) 最高法知民终 3178 号（专利侵权）；以及与 ZL95117436.3 专利无效有关的行政案件。**这些裁判的存在使凯赛的回应不能被简单视为企业公关稿。**
- **但「存在多份凯赛胜诉判决」与「这些判决已经认定微生物所 2017 年的转让侵权」是两个不同命题**。旧判决能走多远，关键要看每份判决审理的当事人、技术范围、行为期间和具体诉讼请求。

## 技术/管理要点
- **最有分量的是 (2022) 最高法知民终 445 号判决**（不是 2003 年的专家鉴定会，也不是 2010 年的院士意见）：凯赛最初提出 77 个具体秘密点、后放弃两个，以 75 个作为权利基础；最高法经技术比对认定瀚霖生产线使用了其中 **13 个**秘密点。法院同时认定：王志洲在凯赛任职期间掌握相关技术、离职前后即代表瀚霖向设计院提交项目实施方案；葛明华在凯赛负责生产工艺 SOP 汇编、离职后进入瀚霖；瀚霖与曹务波通过股权、房产等利益促使二人违反保密义务；四方共同侵犯凯赛部分技术秘密。
  - **瀚霖当年已提出过与今天几乎相同的抗辩**（技术从微生物所合法受让、签有转让合同），最高法未采信——判决指出合同中没有记载与 77 个秘密点相关的技术内容，瀚霖也未提交证据证明微生物所实际提供了这些具体技术方案。法院还比较了工业化规模：淄博广通发酵规模 25 立方米，凯赛达 200 立方米——**对微生物发酵工业化技术而言，生产规模不同往往意味着设备和操作参数也会变化**。
  - 核心启示：**「我与中科院签过合同」只能证明交易关系存在，不能证明生产线上使用的每一项技术都来自合同转让。** 技术来源抗辩要成立，至少还要说明合同交付了哪些菌株、文件、参数和工艺包，这些内容与被诉生产技术如何对应，其形成时间是否早于权利人主张的秘密。
- **445 号判决留下的两道口子（凯赛声明可能给公众留下的印象超出了判决实际范围）**：
  1. *法院没有认定陈远童、傅深展侵犯该案技术秘密*——凯赛主张瀚霖将二人列为九项专利发明人、通过申请专利公开凯赛技术秘密，因此应承担共同侵权责任。最高法未支持，原因是凯赛最终主张的 75 个秘密点并没有被这九项专利公开；既然专利文件未披露所保护的具体秘密点，就不能仅凭二人出现在发明人名单中认定侵权。判决最终只判令瀚霖、曹务波、王志洲、葛明华停止侵权并赔偿。**因此凯赛声明中「瀚霖生物的曹务波等个人以及瀚霖生物侵犯凯赛商业秘密」的表述需结合判决主文理解，「等个人」不能当然扩大到该案所有自然人被告。**
  2. *法院没有处理微生物所对技术权利的主张*——微生物所曾向法院出具《关于微生物法生产长链二元酸技术说明的函》主张对相关技术享有权利，但它既未作为原告或第三人参加诉讼，提交材料也未具体载明凯赛主张的秘密点内容，最高法明确表示对其权利主张「不予处理」。**法院否定的是瀚霖当时没有证据证明被诉技术来自微生物所，并没有对微生物所是否拥有另一套独立技术作出实体判决。**
  - 所以 445 号判决解决了「瀚霖能不能用一份微生物所技术转让合同解释其生产线上被认定侵权的 13 个秘密点」（答案：不能），但没有解决「微生物所自己是否另有一条独立研发的技术谱系，以及这条谱系在 2017 年形成的技术包是否包含凯赛秘密」。**2026 年新诉讼第一次把微生物所本身列为被告，正是要补上 445 号判决没有处理的这一环。**
- **刑事判决（(2019) 鲁 08 刑终 5 号）的证明力与边界**：确认五项工业化生产技术构成凯赛商业秘密，认定瀚霖通过王志洲取得、使用相关技术，瀚霖与王志洲均构成侵犯商业秘密罪。最关键的一组证言来自生产线设计环节——设计人员称瀚霖项目的工艺流程、设备选型和参数由王志洲提供，**陈远童没有参加技术座谈**，结合其他证据足以否定「瀚霖整条工业化产线均来自微生物所」。但它认定的是五项具体技术秘密及其传播路径，**不能扩张为双方全部技术历史的总判决**——2000 年微生物所确曾向北京凯赛转让 DC13 至 DC17 系列菌种和相关技术；真正的争议是凯赛后来形成的规模化发酵、提取、精制、设备和 SOP 中，哪些是受让技术、哪些是企业后续形成的独立成果。
- **三组辅助材料的证明力边界**：
  - *专家鉴定和院士评价*——能证明凯赛在聚合级纯度、非水相发酵液分离和规模化生产方面的产业化能力与成果贡献，**却不能直接决定具体技术权属及传播路径**。专家委员会评价的是技术水平和产业效果，法院审查的是具体秘密点由谁形成、如何被取得和使用。
  - *「生产实践应用证明」争议*——该文件真实性和证明力尚有争议。凯赛称只加盖原山东工厂财务章、公司不予认可，相关裁判也未将其作为定案依据。但**「未被采信」不等于已被法院认定为伪造**；即使文件真实，也只能证明当时对受让技术使用效果的评价。
