# Circle

## 定义
Circle 是一家稳定币发行与区块链支付基础设施公司，核心产品是美元稳定币 USDC，属于数字货币与支付结算领域。公司通过连接传统金融体系（美元、美债、银行、监管）与区块链网络，提供可编程的数字现金基础设施。

## 在知奥体系中的位置
Circle 在知奥知识库中主要出现在两条线索中。第一条是稳定币与货币主权议题：它与 [[Tether]] 的 USDT 构成法币储备型稳定币的两大玩家，USDC 在储备透明度、美国监管基础和机构合作能力上更突出，是美欧合规体系较完整的方案。在多篇关于稳定币行业、监管博弈与货币主权数字化战争的分析中，Circle 是理解合规稳定币路线的关键公司。

第二条是 [[Agent经济]] 与机器支付场景：在 AI 代理开始替人花钱的语境下，Circle 的链下聚合加链上批量结算将单笔成本压至几乎为零，其 Nanopayments 方案被列为与 [[Stripe]] MPP、[[AWS]] AgentCore Payments、x402 协议并列的结算层候选方案之一。因此 Circle 在库中既是金融基础设施公司，也是面向未来机器交易和微支付的基础协议提供者。
