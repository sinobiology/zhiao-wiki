# 菌种工程（Strain Engineering）

## 定义
通过基因编辑、代谢工程等手段对微生物菌株进行定向改造，使其更高效地生产目标化合物的技术领域。在氨基酸发酵中，典型操作包括：过表达关键合成酶基因、敲除竞争性分支通路、增强产物外排系统、提升底物耐受性。

## 在知奥体系中的位置
菌种工程是氨基酸产业**技术壁垒的核心来源**，也是专利战的主战场：

- **工具演进**：化学诱变（随机）→ 基因敲除/过表达（靶向）→ CRISPR-Cas9（精准）→ 全基因组合成改造
- **专利核心**：[[味之素]]对[[CJ集团]]的六年专利战，争议焦点正是 yddG 基因（氨基酸外排泵）的过表达方式——谁控制了菌株关键功能的专利，谁就在整个品种上握有议价权
- **与规模效应的关系**：菌种工程提升转化率，是打破[[成本曲线]]僵局的"技术扳手"；但优良菌种本身也是专利保护对象，构成另一条护城河
- **合成生物学**：菌种工程向上延伸至[[合成生物学]]，从改造已有菌株进化为从零设计生命系统
