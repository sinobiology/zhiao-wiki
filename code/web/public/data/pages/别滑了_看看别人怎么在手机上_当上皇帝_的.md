# 别滑了！看看别人怎么在手机上「当上皇帝」的

## 核心逻辑
- 我们面临的核心问题不是信息太少，而是秩序太乱——大脑像杂货铺，什么都进却什么都留不下。
- 「皇帝版手机布局」的本质是一种极致清醒的「生产者思维」：主动定义每个信息工具的用途，让它为你服务，而不是你被它消耗。
- 真正的信息掌控者不只是整理桌面（朝纲），更要用体系化的高浓度知识（御膳房）给自己续命，从信息消费者转变为注意力疆域的统治者。

## 技术/管理要点
- 用古代「三省六部」官制隐喻对手机App进行功能分区：「中书省」管决策、「户部」管财务、「锦衣卫」管安全，实现信息工具的角色化管理
- 区分「消费型信息」与「生产型信息」：碎片推送属于前者，科技/商业/历史/社会学等体系化课程属于后者
- 两步行动法：
  - 第一步「三省手机」：花10分钟给App按用途分「部」，厘清用途，夺回掌控感
  - 第二步「定制御膳」：关掉两个无用推送，订阅或打开一门能系统思考的课程
