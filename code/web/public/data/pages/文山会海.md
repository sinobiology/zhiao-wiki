# 文山会海

## 核心逻辑
- 过度的会议和流程正在系统性地消耗组织的执行力与创造力，形成"文山会海"困局
- 形式化的管理动作（头脑风暴、安全检查、设备培训）反而成为生产和创新的阻碍
- 决策停留在会议室，无法穿透到执行层，导致轻重不分、攻守易势

## 行业洞察
- 企业管理中普遍存在"以会代管"的惯性，会议数量与管理质量呈负相关
- 流程合规性要求（安全检查、设备培训等）若不加节制，会挤占核心生产和研发时间

## 技术/管理要点
- **激情与会议的矛盾**：过多会议消磨团队激情，应严格控制会议频次和时长
- **流程与效率的矛盾**：流程是手段不是目的，需定期审视流程的投入产出比
- **头脑风暴的陷阱**：不加约束的头脑风暴可能分散焦点，延误决策
- **民主决策的代价**：事事民主导致决策效率低下，需区分哪些决策需要共识、哪些需要果断拍板
- **决策穿透力**：决策必须从会议室传导到执行层，否则开会本身毫无意义
