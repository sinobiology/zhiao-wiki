# 味之素（Ajinomoto Co., Inc.）

## 定义
创立于1909年的日本食品化工集团，全球最大氨基酸生产商与专利持有者之一。以味精（MSG）起家，现已演化为涵盖调味料、冷冻食品、氨基酸医药、半导体封装材料（ABF）的跨界巨头。FY2026销售额1.5837万亿日元（约776亿元人民币），归母净利润同比增长91.6%。

## 在知奥体系中的位置
味之素是知奥知识库**最核心的研究对象**之一，代表"从大宗制造到认证曲线"战略升维的极致案例：

- **技术路线演进**：水解法（1909年）→ 直接发酵法（1965年全面转型）→ ABF半导体材料（1999年量产，全球95%市占）
- **商业模式跨越**：从卖味精→卖厨房场景解决方案（HON-DASHI、Cook Do）→ 卖AI芯片不可替代的封装材料
- **专利武器体系**：截至2023年持有4016件全球专利，对韩国CJ发起6年三国专利战，2025年起诉中国梅花生物索赔2.6亿元
- **危机进化史**：味精安全谣言（52年保卫战）→ 赖氨酸卡特尔罚款（1997年，合计逾3000万欧元）→ 印尼清真危机（2001年）→ 每次危机后制度升级
