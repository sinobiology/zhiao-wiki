# 霍尔木兹海峡

## 定义
霍尔木兹海峡是连接波斯湾与印度洋的关键海上通道，全球约20%的石油运输经由该航道。在知奥知识库中，它主要作为地缘政治风险变量出现，通过能源、航运、保险与化工原料链条冲击氨基酸及饲料行业。

## 在知奥体系中的位置
霍尔木兹海峡在库中并非作为地理实体独立存在，而是贯穿多篇文章的地缘风险传导枢纽。在《2026年Q1全球氨基酸发酵行业大事回顾与解析》中，它被直接视为成本端变量：事实性封锁导致能源、物流、保险三重成本挤压，布伦特原油与SCFI运价同步飙升，进而迫使[[梅花生物]]、[[阜丰集团]]、[[星湖伊品]]等头部企业启动涨价。

《导弹之下，饲槽之上》进一步拆解了其“软封锁”机制——无需物理封锁，仅通过金融层保险飙升与规则层港口拒收，即可让航线在商业上失效。这一机制通过石化链传导至[[蛋氨酸]]原料供应，直接影响[[赢创]]、[[安迪苏]]等全球主要厂商的定价与签单策略，并经由粮食链与情绪层在国内采购市场形成“预期自我实现”式上涨。

在宏观层面，霍尔木兹海峡还出现在[[Ray Dalio]]长文解读中，作为“巨大失序期”的现实案例：若封锁，全球20%石油受阻，通胀向全球蔓延。这与库中关于地缘冲突经济冲击波、大周期理论的内容形成呼应，说明该海峡的风险不仅关系到饲料与氨基酸行业，也是一般性全球供应链与通胀研究的信号节点。

## 关键数据
- 霍尔木兹海峡若封锁，全球约20%石油运输受阻
- 2026年Q1事实性封锁/扰动期间，布伦特原油上涨43.7%，SCFI上涨37%
- 材料中提到的三层封锁机制：物理层（水雷/打击）→ 金融层（保险飙升）→ 规则层（港口拒绝无保险船舶）
- 全球蛋氨酸原料高度依赖中东石化链，生产基地集中在欧洲和亚洲（新加坡）
