# 蚂蚁的逆袭（0）：一个黄土地里考出来的理工男，为什么要谈钱？

## 核心逻辑
- 认知水平决定财富上限，超出认知范围赚到的钱最终会凭实力亏掉。
- 勤奋本身不是问题，收入来源的结构才是关键——靠亲自劳动挣钱，人一停收入就停。
- 投资记录与复盘是识别认知漏洞、避免重复犯错的唯一路径。

## 技术/管理要点
- 财商启蒙的核心概念：区分**资产**（为你赚钱的东西）与**负债**（把钱从你口袋里拿走的东西）。
- 现金流象限图（E/S/B/I）：E和S靠个人时间和能力挣钱，B和I靠系统和资产替自己工作；方向选择优先于努力程度。
- 复盘方法论：激活尘封账户→导出历史交易记录→逐笔整理统计→以数据为基础进行自我审视（2022年1月21日完成首次系统复盘）。
