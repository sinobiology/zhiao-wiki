# AI Agent

## 定义
AI Agent 是一种具备自主执行能力的人工智能实体，能从传统的“回答问题”演进为“实际执行任务”——它常驻本地或云端环境，拥有文件读写、浏览器控制、shell 命令、消息收发等系统级权限，在真实生产环境中替用户完成操作。它属于 AI 工程与自动化交叉领域，是 2025–2026 年爆发的新品类。

## 在知奥体系中的位置
AI Agent 在知奥知识库中是一条持续演进的主线，贯穿技术实践、管理反思与金融推演。在技术侧，[[OpenClaw]] 与 [[Codex]] 是两个被反复研究的具体载体，前者强调本地部署与系统级执行权限，后者强调项目/对话分层管理。知奥对 AI Agent 的关注并非工具评测，而是围绕“从会回答到会执行”的范式转变，探讨 [[执行层入口]] 如何取代对话框成为下一代交互入口。

同时，AI Agent 被知奥用来类比管理问题。在“养龙虾”系列中，[[OpenClaw]] 的调教过程被视作管理者培养新人的困境复刻，[[容错成本]] 与 [[Token成本]] 被并置讨论，结论指向 [[权限边界]] 比操作技巧更重要。材料4中，AI Agent 一秒清零数字资产的事故，直接揭示了自动化能力越过安全边界后的破坏性，引出 [[路径隔离]] 与 [[最小权限原则]]。

在金融层面，[[Crypto]] 与 [[比特币]] 等实体通过 AI Agent 产生新关联。材料9和材料10提出 AI Agent 将成为下一代链上经济主体，因其没有法人身份、无法通过 KYC 进入法币体系，天然倾向于基于私钥的 Crypto 体系；当 Agent 数量与交易频次超过人类时，Crypto 可能因使用频率成为事实主流货币。
