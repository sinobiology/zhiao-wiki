# 规模效应

## 定义
在工业发酵中，规模效应指产能越大、单位生产成本越低的经济规律。表现为：大型发酵罐（500-1000吨）的折旧、能耗、人工等固定成本被更多产量摊薄，使头部企业天然具备价格竞争优势。

## 在知奥体系中的位置
规模效应是知奥体系的**核心竞争逻辑**，贯穿赖氨酸、苏氨酸、味精等所有大宗氨基酸产品。它解释了：
- 为什么中国氨基酸企业能用价格战打垮日韩竞争对手
- 为什么行业会陷入"囚徒困境"——没人敢停产，因为停产等于丢市场，而持续扩产又会压垮价格
- 为什么[[成本曲线]]是行业生死的第一判据

规模效应有天花板：当行业内所有玩家都追求规模，最终博弈终点是全行业逼近边际成本。此时，能突破天花板的路径只有两条：技术差异化（[[菌种工程]]）或赛道升维（从大宗品→特种材料，如[[ABF]]）。
