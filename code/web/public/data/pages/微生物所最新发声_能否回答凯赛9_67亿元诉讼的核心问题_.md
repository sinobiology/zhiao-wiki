# 微生物所最新发声，能否回答凯赛9.67亿元诉讼的核心问题？

## 核心逻辑
- **它回答了技术从哪里来，却还没有回答技术是否相同。** 微生物所回答了「为什么它认为技术属于自己」，却还没有回答「2017 年转让的具体技术是否与凯赛主张的技术秘密相同或实质相同，以及是否经过山东瀚霖这条传播路径」。
- 凯赛主张的是一条**技术传播链**，微生物所回应的是一条**自主研发谱系**；两条线是否相同或实质相同，仍需证据回答。
- 商业秘密保护的对象不是「月桂二酸」这个产品名称，也不是「用微生物生产 DC12」这一宽泛思路，而是当事人能够明确指出、具备秘密性和商业价值、并采取了保密措施的**具体技术信息**。

## 行业洞察
- **诉讼请求**：凯赛及凯赛（金乡）以侵害技术秘密为由，将王志洲、葛明华、曹务波、山东瀚霖、陈远童、傅深展、中科院微生物所、山东归源、宁夏中科和中科新材等十方诉至北京高院，请求停止侵害「生物发酵法工业化生产长链二元酸技术」相关技术秘密，销毁有关产线、设备和图纸，并连带赔偿经济损失 96,587.25 万元及合理开支 100 万元（合计约 9.67 亿元）。**经济损失部分以凯赛主张的原告损失为基础，按 5 倍惩罚性赔偿计算。**
- 凯赛公开叙述的事实链：凯赛前员工 → 山东瀚霖 → 中科院微生物所 → 宁夏中科及中科新材。前半段已经过多轮刑事、民事诉讼，后半段是此次新诉讼试图追问的部分。ST 宁科公告称凯赛主张陈远童、傅深展及微生物所「通过山东瀚霖获取涉案技术并对外转让」；凯赛还称 2024 年受邀为中科新材提供技术咨询服务期间，发现其实际使用技术与凯赛技术秘密高度相似。
- **公告未公开的四项关键材料**：凯赛在本案中主张的具体技术秘密点；中科新材实际使用技术与凯赛秘密的检测/鉴定/比对结果；关于微生物所取得、掌握并再次转让相关技术的完整证据；9.67 亿元损失及十方连带责任的详细计算和分配依据。因此现阶段只能比较双方已公开的事实叙述，不能据此判断胜负。

## 技术/管理要点
- **微生物所的技术谱系时间线**：1969 年率先发现微生物能以石油烷烃为原料生成二元酸；1974 年培育出第一代生产菌株；1982 年开始 DC12 和 DC13 中试；1996 年 DC12 生产技术转让给山东淄博广通；1997 年相关生产线实现千吨级发酵工业化生产；2009 年成立长链二元酸第三代技术专业团队，启动菌种合成生物学改造及工艺升级；2017 年将月桂二酸（DC12）第三代核心菌种与发酵技术转让给宁夏新日恒力。
- **两个对微生物所有利的关键事实**：① **2000 年转让给北京凯赛的技术「不含 DC12」**——转让的是 DC13 至 DC17 系列二元酸专利菌株及专有技术，而 2017 年转让给宁夏的正是 DC12 技术；② 微生物所没有把 2017 年转让描述为旧技术的再次许可，而是**定位为第三代核心菌种与发酵技术**，放在 2009 年组建专业团队、启动合成生物学改造之后。抗辩逻辑：很早就拥有 DC12 技术 → DC12 没在 2000 年转让给凯赛 → 2017 年向宁夏转让的是后来独立研发的第三代 DC12 技术 → 不侵犯凯赛技术秘密。这套叙述不是没有分量，它证明微生物所长期从事相关研究，也提出了一条具备时间连续性的独立研发路径。
- **但「谁最早研究 DC12」不是本案的全部问题——最容易出现的概念混淆**：DC12 技术没有转让给凯赛，不等于凯赛此后形成的所有 DC12 工业化技术都与微生物所无关；反过来，凯赛完成了工业化改进，也不等于微生物所此后不能独立研发新的 DC12 技术。**两种事实完全可能同时成立**——微生物所可以是生物法长链二元酸技术的原始策源地，凯赛也可能在此基础上形成新的菌种改造方法、发酵控制参数、生产 SOP、工程设计、设备选型以及提取精制工艺。
- **本案真正需要比较的五个层次**（不是谁的历史更长）：2017 年第三代菌种由什么底盘菌株改造而来？菌种的遗传特征、改造路径和培养方法如何演变？发酵、提取、精制等环节的参数和设备方案从哪里形成？这些内容与凯赛主张的秘密点是否相同或实质相同？如果存在相同之处，是来自公知技术、早期研究积累、独立研发，还是来自凯赛技术的接触和传播？**微生物所的发展简史回答了第一层的历史来源问题，却没有公开能回答第二层技术同一性问题的材料。**
- **445 号判决已审查过一次「技术来自微生物所」的抗辩**：最高法认定瀚霖生产线中部分技术信息与凯赛部分技术秘密相同或实质相同；认定王志洲离开凯赛前后向设计院提交包含凯赛生产工艺及设备选型内容的项目方案，葛明华离职后加入瀚霖并将 SOP 披露给瀚霖；四方构成共同侵权。瀚霖的合法来源抗辩未被采信——合同中没有记载与凯赛主张的具体秘密点相对应的技术内容，瀚霖也未提交证据证明微生物所实际提供给它的技术方案内容。**启示：仅提供一份技术转让合同、或证明微生物所很早就拥有该技术，并不足以完成合法来源抗辩——真正需要证明的是合同实际交付了什么、交付技术如何形成、它与被诉技术及凯赛秘密点之间是什么关系。**
- **445 号判决的三条边界**：① 微生物所不是该案当事人，法院没有判决它构成侵权；② 该案审查的是瀚霖 2008 至 2013 年前后的生产线和行为，**并未直接审查 2017 年向宁夏转让的第三代 DC12 技术**；③ 凯赛当时以陈远童、傅深展被列为专利发明人为由主张共同侵权，最高法认为涉案专利并未公开凯赛最终主张保护的秘密点，该项主张不能成立。**所以 445 号既不能直接证明 2017 年转让侵权，也不能被最新发展简史所绕开**——它留下的真正问题是：2017 年的第三代技术，能否用新的研发证据证明其独立来源。
- **最新发声仍未回答的关键问题：2009 年的两条技术线如何彼此隔离**。发展简史同时记载了 2009 年发生的两件事——微生物所与莱阳江波制药改签专利实施许可合同、受让方变更为山东瀚霖；以及组建第三代技术专业团队启动菌种改造和工艺升级。**两件事同年发生本身不能证明技术混同**，但既然凯赛起诉明确指向「微生物所通过瀚霖获取涉案技术并对外转让」，微生物所就需要进一步说明：第三代研发团队由哪些人员组成、使用了哪些初始菌株和技术资料、项目研发记录从何时开始连续保存。
