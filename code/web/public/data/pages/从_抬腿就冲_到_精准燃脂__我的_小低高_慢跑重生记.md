# 从"抬腿就冲"到"精准燃脂"：我的"小低高"慢跑重生记

## 核心逻辑
- 大多数人跑步受伤的根源不是意志力不够，而是方法错误——用"自杀式冲刺"代替了科学的中低强度持续运动，既伤膝盖又燃脂效率极低。
- "小低高"慢跑法（小步幅、低心率、高步频）配合数据化监控，是普通人安全高效跑步的核心解法。
- 健身的终极目的不是跑得快，而是构建强大的心血管系统，让你在高强度工作后仍有精力享受生活。

## 技术/管理要点
- **"小低高"慢跑法三要素**：
  - 小步幅：控制在身高的 0.3-0.4 倍，从源头减少膝盖和脚踝冲击
  - 低心率：通过[[卡氏公式]]计算专属心率区间（燃脂区 35%-55% 强度，心肺强化区 55%-65% 强度）
  - 高步频：控制在 180 步/分钟以上，用节拍器辅助建立节奏感
- **卡氏公式**：目标心率 = [(220 − 年龄) − 静态心率] × 运动强度 + 静态心率，比"220-年龄"更精准
- **关键指标 [[最大摄氧量]]（VO₂max）**：直接反映心肺功能，男性低于 40、女性低于 36 意味着健康风险
- **燃脂真相**：脂肪消耗需要氧气参与，上气不接下气时主要供能的是糖而非脂肪，所以高强度冲刺反而燃脂效率低
- **数据化装备**：[[小米手环]]实时监控心率 + [[Keep]] 节拍器控制步频，用数据替代感觉
- **作者实践数据**：平均心率 137 次/分钟（落在强心区间），步频 194 步/分钟，最大摄氧量 46（良好水平），从 3 公里气喘吁吁进步到轻松完成 5 公里且膝盖无不适
