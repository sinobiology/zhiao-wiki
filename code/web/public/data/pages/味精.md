# 味精

## 定义
味精是一种以谷氨酸为主要成分的鲜味调味品，核心有效成分为谷氨酸钠。它属于工业发酵产业，是中国氨基酸发酵体系中最先实现大规模工业化的品类，也是后续赖氨酸、蛋氨酸等氨基酸产业的先行者。

## 在知奥体系中的位置
味精在知奥体系中是[[发酵工业]]和[[氨基酸]]产业的核心历史样本。材料将其定义为“中国整个工业发酵产业的黄埔军校”，其技术路径从[[水解法]]到[[发酵法]]的转变，为[[赖氨酸]]、[[蛋氨酸]]、[[苏氨酸]]等后续赛道输送了方法、人才和组织经验。[[味精战争]]一文梳理了从200家到3巨头的四十年收敛史，揭示[[规模效应]]与产能出清如何塑造寡头格局。

在技术层面，味精与[[生物素限制诱导]]、[[谷氨酸棒状杆菌]]、[[微生物发酵]]等概念深度绑定，并出现在[[背压式汽轮机]]的适用场景中——味精工厂因热负荷大而采用“以热定电”的能源策略。在产业实体层面，它连接[[味之素]]、[[莲花味精]]、[[阜丰集团]]、[[梅花生物]]、[[沈阳味精厂]]等公司，以及[[红梅牌味精]]、[[双桥牌味精]]等品牌。

## 关键数据
- 中国味精行业四十年从200多家企业整合到3巨头寡占。
- 1965年微生物发酵法取代小麦面筋水解法，吨耗从30吨小麦降至6吨，成本降低50%。
- 1987年FAO/WHO取消味精摄入量限制，同年中国味精产量增速达45.7%。
- 1983年中国味精年产量达6.1万吨，年出口约2000吨，销往新加坡、法国、澳大利亚等国。
- 1983年[[沈阳味精厂]]以4800吨/年产能居行业第一。
- 1989—1994年行业大洗牌，200多家企业被清洗至约60家。
- 味精工厂因热负荷大，适合采用[[背压式汽轮机]]，缺点是“以热定电”。
