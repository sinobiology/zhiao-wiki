# 人生写意

## 核心逻辑
- 人生的本质是对立面的共存：升落、圆缺、阴晴、暑寒，皆为常态
- 幸运与艰难同路，悲泪与喜泪同脸——苦乐从不分离，而是交织并行
- 接纳人生的全貌，而非只期待单一的美好，才是真正的写意
