# OpenClaw

## 定义
OpenClaw 是一个本地运行的 AI 智能体平台（Agent Platform）。它让用户在自己电脑上搭建 AI 助理并接入飞书、Telegram 等日常工具，数据不经第三方服务器，核心突破是从"会回答"到"会执行"，真正替用户完成任务。

## 在知奥体系中的位置
OpenClaw 是 [[知奥ZHAO]] 知识库中 AI 工具与认知升级主线的重要实体，被多次转载和深度拆解。它与 [[女娲skills]] 共同构成自主 Agent 生态的核心讨论样本，在《从会回答到会执行》和2万字保姆级教程中被完整定义。

OpenClaw 同时也是管理反思的载体。在《「养龙虾」的代价》系列中，OpenClaw 被昵称为"小龙虾"，用来讨论 [[权限边界]]、[[容错成本]] 与控制权转换——它像管理一个能力很强但刚入职的员工，给任务但不给无限授权。

在产业层面，OpenClaw 的出现推动了本地 AI 代理这一新品类的爆发，[[腾讯]]、[[字节跳动]]、[[百度]] 等大厂同步押注执行层入口。它还与 [[Crypto]] 产生关联：自主 Agent 天然只能使用 Crypto 进行经济活动。
