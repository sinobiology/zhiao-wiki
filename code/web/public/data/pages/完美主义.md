# 完美主义

## 定义
完美主义是一种心理倾向，表现为既想要完美的结果，又接受不了不完美的过程，最终往往连过程都放弃。在知奥体系中，它被视作迟迟不行动、拖延和不敢开始的核心根因之一，属于个人成长与执行心理层面的概念。

## 在知奥体系中的位置
完美主义在 [[知奥ZHAO]] 的多篇文章中被反复讨论，主要作为阻碍行动的心理障碍出现。在《2025年9月总结》中，它与「没人推一把」并列为迟迟不行动的两大根因，解法是「缩小主题」（narrow your topic），避免想得太宏大而无法下笔。

在《AI才是完美主义者和拖延症的天然解药》中，完美主义被进一步拆解为「既想要完美结果又接受不了不完美过程」的核心矛盾，并提出 AI 是天然解药——让完美主义负责判断，[[AI辅助执行]] 负责落地，从而保住自我人设又推动任务前进。这与 [[拖延症]]、[[多巴胺]] 的心理机制紧密关联。

在《困在结局，还是困在开头？》中，完美主义被描述为最隐蔽的拖延借口，并归纳出三重陷阱：目标膨胀症、准备强迫症、结果恐惧症。破局之道是 [[微习惯]] 策略，通过小到不可能失败的行动撕开开口，配合 [[神经可塑性]] 和 [[破窗效应]] 形成正向循环。
