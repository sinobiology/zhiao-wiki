# 从0到1带你速通Codex，我整理的终极保姆教程来了。

## 核心逻辑
- 转载自「数字生命卡兹克」的 Codex 工具教程（2026-06-02）。原作者二月份写过一版，但几个月内 Codex 进入爆更模式，「几乎是两个产品了」，故重写。
- 教程用一个网页和一个 App 两个例子串起全流程。
- 核心工程实践：**项目/对话分层管理避免上下文污染 + AGENTS.md 分层约束体系。**

## 行业洞察
- **工具厂商的用户迁移战**：Codex 支持从 Claude Code 和 Cowork 直接导入所有内容、一键继承之前的全部配置。「之前 Claude 支持导入记忆来挖 ChatGPT 用户，现在 Codex 直接反手一刀挖你 Claude Code 用户。」
- 额度与 ChatGPT 会员挂钩（作者用 100 美刀会员，200 刀在 Claude 那边；轻度使用 20 美刀勉强能用），也可用 API key。

## 技术/管理要点
- **安装**：前提是有魔法和 ChatGPT 账号，从 OpenAI Codex 官网下载（Mac 和 Windows 都有）。
- **界面结构**：中间是对话区；左侧栏管理所有对话和项目，分两个目录——
  - *对话*：适合不需要绑定特定文件夹的任务（调研、规划等零碎小任务）。
  - *项目*：**真正的主战场**。选一个本地文件夹作为项目目录，Codex 以此为工作区间，所有生成文件自动存入。一个项目可开多个对话，**每条对话是独立任务线，共享同一文件夹的文件但记录互相隔离**。
  - **关键实践**：如果所有事情都堆在同一个对话里，记录越来越长，**上下文污染会很严重**。最好是同一方向的任务放同一个项目，具体的每件事开一条新对话推进。「前期的分类我是真的觉得挺重要的，不然到后期真的会很抓狂。」
- **三档权限（对话框左下角）**：*默认权限*（动个啥都需审批，保守）；*自动审查*（适合日常开发，碰到有风险的操作会拦一下，如删除大量文件、访问敏感目录）；*完全访问权限*（不再每次征求同意，全部自动运行）。原作者选完全访问的理由：非开发出身，弹出来的东西看不懂。（**注：与《「养龙虾」的代价，升级了》一文的权限教训形成对照——完全访问权限正是那次数字资产被清零的前置条件。**）
- **模型与推理等级（右下角）**：模型无脑选最强的 GPT-5.5；推理等级日常用高、硬活开超高；速度分快速（1.5 倍速度、2 倍 token 消耗）和标准——**token 不是可以无限烧的情况下推荐标准**（速度差别不大）。自带语音输入体验较差（录完要等好几秒才转写），推荐直接用豆包语音输入法。
- **额度查看**：左下角设置→剩余额度，可看 5 小时内剩余、本周剩余、刷新时间。
- **必须先改的设置（不能跳）**：常规设置里的三项全部打开；**「跟进行为」改成「引导」**——这样中途想修改时可以直接插入，而不必等任务做完才能开始新一轮对话。若开头忘了导入 Claude Code 内容，此处可补导入。
- **AGENTS.md：从上往下分层穿透的约束体系（「你给 Codex 设置的家法」）**：
  - *第一层：全局生效的 AGENTS.md*——在个性化设置的自定义指令里修改，是为 Codex 提供的全局通用规则。**设好之后不管以后开多少个新对话它都会记得。**
  - 推荐使用 Karpathy 的模板（可直接复制粘贴），其核心是「减少常见 LLM 编码错误的行为准则」，并明确权衡取向：**这些准则偏向谨慎而非速度，对琐碎任务需自行判断**；第一条原则是「Think Before Coding — Don't assume」（编码前先思考，不要假设）。
